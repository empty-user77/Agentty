**⌘,** で設定が開きます。変更はすぐ反映され、`~/.agentty/settings.json` に保存されます。

サイドバーはページを **一般**、**AI**、**作業**、**接続とデータ**、**システム** に分けています。上の検索ボックスは、すべてのページの設定を名前や説明から探します。結果を選ぶとそのページに移り、該当する設定が示されます。

## 一般

言語（English、한국어、日本語、中文）、**外観**（システム・ダーク・ライト）、そして日々出会う挙動です。外観をシステムにすると、macOS の設定が切り替わるのに合わせて変わります。ターミナルはどの外観でもターミナルスタイルで選んだテーマのままです。

| 設定 | 役割 |
|---|---|
| アイデアから作る | スタート画面と + メニューでアイデアのページを提案 |
| 閉じる前に確認 | 使用したペイン・タブ・ワークスペースを閉じる前に尋ねる |
| セッションごとのワークツリー | 作業中のプロジェクトの 2 つ目のセッションに専用の git ワークツリー |
| ワークスペース一覧に検索欄を表示 | ワークスペース名と、その中の会話を検索 |
| 完了した作業スペースを一番上に移動 | オフにすると、自分で並べた順序のまま |
| 閉じるときサーバーを停止 | ペインを閉じると、そこで起動したローカルサーバーを終了 |
| 匿名の利用統計の送信に同意 | [使用統計](/docs/telemetry) を参照 |
| メニューバーのアイコン | ウィンドウを閉じても Agentty を動かし続ける（macOS） |
| スリープ防止 | **オン** はマシンを起こしたままにします（常に、または 1〜72 時間）。**エージェント** はエージェントの作業中だけ、**オフ** は通常どおりスリープします。ステータスバーのカップからも変更できます |

## AI 設定

Agentty がエージェントのセッションに加える機能です。

| 設定 | 内容 |
|---|---|
| Claude Advisor | 新しい Claude タブが使う [Advisor](/docs/advisor) |
| ステータスバーに Advisor を表示 | 既定はオフ。オンにすると Claude タブのステータスバーに Advisor が表示され、そのタブだけ変更できます |
| AI CLI ステータスバー | AI ペインの上のバーと、ターミナルの上下どちらに置くか |
| エージェントに Agentty の使い方を伝える | ここで起動したエージェントに Agentty のコマンド案内をコマンドラインで渡す |
| 並列タスク | エージェントが分割ペインでタスクを始めるよう依頼できる。依頼ごとに確認 |

## エージェント

このコンピュータのエージェント CLI です。**エージェントの権限** は Claude Code と Codex のタブを YOLO（Bypass）モードで起動するかを決めます。**インストール済み** は見つかったエージェントをバージョンとコマンド付きで一覧します。**オフ** にするとランチャー、スタート画面、コマンドパレットから外れます（インストールはそのまま）。新しく入れたら **再検出** を押してください。**インストール可能** は CLI を入れれば Agentty から起動できるエージェントです。**インストール** を押すと提供元の公式インストールコマンドが新しいターミナルタブで実行され、リンクは公式サイトを開きます（公式のコマンドがないエージェントはサイトへのリンクだけです）。

**Claude Code** を開くと、Claude Code のユーザー設定（`~/.claude/settings.json`、または `$CLAUDE_CONFIG_DIR`）に保存される機能が並びます。**エージェントチーム**（リードのセッションがメンバーのセッションを起動してまとめる。実験的機能）、**常に思考する**、**自動アップデート** です。スイッチが表すキーだけを書き込み、ファイルの残りはそのままです。正しい JSON でないファイルには触れません。新しい Claude Code セッションから使われます。**Codex** からは `~/.codex/config.toml` を開けます。

## 連携

Agentty が連携する外部サービスです。サービスごとのカードに接続状態が表示され、カードを開いて設定します。

- **GitHub** — プルリクエスト、クローン、同期は GitHub CLI（`gh`）とそのサインインを使います。Agentty には何も保存しません。**ターミナルでサインイン** は新しいタブで `gh auth login` を実行します。
- **Slack、Discord、Telegram** — 通知の送り先です。Webhook URL やボットトークンはシステムの資格情報ストアに保存されます。**ここに通知を送る** でサービスごとにオン・オフします。送る内容は 通知 で決めます。
- **Jira** — 開発ボードがチケットを取り込むサイト、メール、API トークンです。

## プロジェクト

新しいタブが始まる場所、Agentty が探すハーネスのパターン、ハーネスのプロンプトをすぐ送るか、どのエージェントがハーネスの作業を始めるか。**エディタで開く**が使うエディタもここです。ファイルエディタの言語サーバーの一覧と、未インストールのものを入れるボタンもここにあります。 行末の問題表示、入力中の補完、ポインタの下の型表示といったファイルエディタのオプションもここで切り替えます。

## ウィンドウ

Agentty のウィンドウ（**⇧⌘N** で新しく開く）は、それぞれ独自のワークスペース一覧を持ちます。このページには、開いているウィンドウと最近閉じたウィンドウが、中のワークスペースと実行中のターミナルの数とともに並びます。ワークスペースをクリックするとそこへ移動します。**前面に表示**は開いているウィンドウを表示し、**もう一度開く**は閉じたウィンドウを開き直し、**削除**は確認のうえウィンドウを閉じて中のワークスペースを削除します。会話はセッション一覧に残ります。メインウィンドウは削除できません。

## アカウント

新しい Claude Code・Codex タブのサインイン方法です。既定は何も変えず、エージェント自身のログインを使います。代替手段と資格情報の保管場所は[拡張・MCP・コネクタ](/docs/mcp-and-connectors)を参照してください。

## 外観

テーマ、フォント、フォントサイズ、行の高さ、字間、太字、背景・文字・カーソル・選択範囲の自分で選ぶ色、カーソルの形と点滅、余白、スクロールバック。エージェントのステータスバーに何をどの順で出すかもここです。[テーマとフォント](/docs/themes)を参照してください。

## キーボードショートカット

全一覧で、お使いのプラットフォームの表記で表示されます。[キーボードショートカット](/docs/keyboard-shortcuts)を参照してください。

## 通知

システム通知、Agentty が前面にあるときも通知するか、そしてチャットサービスに送る内容（完了の通知、依頼の内容、画面に出ているセッション）を決めます。Slack、Discord、Telegram の接続は **連携** で行います。[エージェントの状態](/docs/agent-status) を参照してください。

## 同期

ワークスペースとエージェントのセッションを、自分の非公開 Git リポジトリ（`gh` 経由の GitHub、または任意の SSH URL）を通して複数のコンピュータで続けられます。空か、すでに同期に使っている非公開リポジトリだけが一覧に出ます。ワークスペースは、エージェントがターンを終えたとき、タブを閉じたとき、何も起きなければ 5 分ごと、**今すぐ同期**を押したときに同期され、失敗した同期は自動で再試行します。

**このコンピュータ（SQLite）**は、リポジトリもアカウントもインストールも不要です。すべてが `~/.agentty/sessions.sqlite` というファイル 1 つに入ります（macOS と Linux に標準で入っている SQLite を使い、Windows では Agentty に組み込まれています）。このコンピュータのセッションのバックアップなので、エージェントのフォルダ（`~/.claude`、`~/.codex`）からセッションが消えても、同期ポップオーバーの**続ける**でファイルから戻せます。設定 → 同期にファイルのサイズと**フォルダで表示**があります。別のコンピュータへ移すには、ファイルをそのコンピュータの `~/.agentty` にコピーして**このコンピュータ（SQLite）**を選ぶと、セッションが戻ります。接続を解除してもファイルは残ります。他のコンピュータとは自動では共有されないので、共有するには Git リポジトリを使ってください。両方を使うには、リポジトリを接続した状態で **SQLite にも保存**をオンにします。同期のたびにリポジトリの内容（すべてのコンピュータのセッション）が同じファイルにも保存され、リポジトリがなくてもバックアップとして使えます。

**設定を同期**をオンにして**保存**を押すと、設定、カスタムコマンド、コネクタ、読み込んだテーマ、プラグインの設定もそろい、最新の変更が優先されます。新しく接続したコンピュータは、リポジトリにすでにある設定を受け取ります。シークレット（API キー、トークン、パスワード）は同期されないので、コンピュータごとに一度入力してください。シークレットのような内容を含む部分（トークンを書いたカスタムコマンドなど）はそのコンピュータに残り、他のコンピュータのもので置き換えられることもなく、同期ポップオーバーにどの部分かが表示されます。

**古いセッションを整理**は、リポジトリが際限なく大きくならないようにします（GitHub の非公開リポジトリの容量は無制限ではありません）。30・90・180・365 日（または自分で決めた期間）変更のないセッションは同期されなくなり、リポジトリから削除する前に同期ポップオーバーで確認します。期間はリポジトリ単位なので、すべてのコンピュータが同じ値を使います。

コンピュータは Agentty が `~/.agentty/computer-id` に作る ID で区別します（ハードウェアの情報は読みません）。`~/.agentty` を削除すると新しいコンピュータとして表示されます。ワークスペースを**同期データも削除**で削除すると、すべてのコンピュータから消えます。リポジトリにすべての版が残るので、バックアップにもなります。リポジトリは非公開である必要があり、公開中は同期が止まります。

## バックアップ

**構成をエクスポート**は、構成全体を 1 つの `.agenttyconfig` ファイルに保存します。設定、カスタムコマンド、コネクタ、データベース接続、エージェントのサインイン方法、読み込んだテーマ、インストール済みプラグインの一覧とその設定が入り、パネルの大きさや最近のフォルダなど 1 台のコンピュータ固有のものは含みません。**シークレットを含める**をオンにすると、資格情報ストアの API キー、トークン、パスワードと、シークレットを含むプラグインの設定を自分で決めたパスワードで暗号化して含めます（PBKDF2 + AES-256-GCM）。Agentty はこのパスワードを保存しません。

**構成をインポート**は、ファイルの構成でこのコンピュータの構成を置き換えます。設定はファイルの値が優先され、このコンピュータのパネルの大きさや最近のフォルダはそのままです。コマンドやコネクタなどのファイルは丸ごと置き換わります。パスワードを空にするとシークレット以外をインポートします。足りないプラグインはマーケットプレイスまたは Git リポジトリからインストールできます。インポート前の構成は毎回 `~/.agentty/backups/` に残ります。

## Agentty について

バージョン、更新の確認、そして[プライバシーポリシー](https://www.agentty.run/privacy-policy)、[利用規約](https://www.agentty.run/terms-of-service)、[使用許諾契約](https://www.agentty.run/eula)へのリンクです。

**ビルド**には、この Agentty が何かが表示されます：バージョン、コミット、ビルド日、プロファイル（release / debug）、ターゲット、Rust のバージョン、デバイス上の音声認識の有無、そして Agentty が提供するインターフェースの API バージョン（プラグイン API、マーケットプレイスの一覧、MCP、シェル連携、設定のバックアップファイル、セッション同期の形式）です。**ビルド情報をコピー**は、これを英語のプレーンテキストでコピーし、不具合報告に貼り付けられるようにします。パス、ユーザー名、キーは含まれません。
