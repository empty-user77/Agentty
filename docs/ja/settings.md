**⌘,** で設定が開きます。変更はすぐ反映され、`~/.agentty/settings.json` に保存されます。

## 一般

言語（English、한국어、日本語、中文）と、日々出会う挙動です。

| 設定 | 役割 |
|---|---|
| アイデアから作る | スタート画面と + メニューでアイデアのページを提案 |
| エージェントのステータスバー | AI ペイン上のバーと、ターミナルの上下どちらに置くか |
| 閉じる前に確認 | 使用したペイン・タブ・ワークスペースを閉じる前に尋ねる |
| セッションごとのワークツリー | 作業中のプロジェクトの 2 つ目のセッションに専用の git ワークツリー |
| ワークスペース一覧に検索欄を表示 | ワークスペース名と、その中の会話を検索 |
| 完了した作業スペースを一番上に移動 | オフにすると、自分で並べた順序のまま |
| 並列タスク | エージェントが分割ペインでの作業開始を要求できるようにし、毎回確認 |
| エージェントに Agentty の使い方を伝える | ここで起動したエージェントに Agentty のコマンド案内をコマンドラインで渡す |
| 閉じるときサーバーを停止 | ペインを閉じると、そこで起動したローカルサーバーを終了 |
| 匿名の利用統計の送信に同意 | [使用統計](/docs/telemetry) を参照 |
| メニューバーのアイコン | ウィンドウを閉じても Agentty を動かし続ける（macOS） |
| スリープ防止 | 長時間の自動実行が途切れないようマシンを起こしておく。常に、または 1〜72 時間を指定。電力を多く使う |

## 同期

ワークスペースとエージェントのセッションを、自分の非公開 Git リポジトリ（`gh` 経由の GitHub、または任意の SSH URL）を通して複数のコンピュータで続けられます。空か、すでに同期に使っている非公開リポジトリだけが一覧に出ます。ワークスペースは、エージェントがターンを終えたとき、タブを閉じたとき、何も起きなければ 5 分ごと、**今すぐ同期**を押したときに同期され、失敗した同期は自動で再試行します。

**設定を同期**をオンにして**保存**を押すと、設定、カスタムコマンド、コネクタ、読み込んだテーマ、プラグインの設定もそろい、最新の変更が優先されます。新しく接続したコンピュータは、リポジトリにすでにある設定を受け取ります。シークレット（API キー、トークン、パスワード）は同期されないので、コンピュータごとに一度入力してください。シークレットのような内容を含む部分（トークンを書いたカスタムコマンドなど）はそのコンピュータに残り、他のコンピュータのもので置き換えられることもなく、同期ポップオーバーにどの部分かが表示されます。

**古いセッションを整理**は、リポジトリが際限なく大きくならないようにします（GitHub の非公開リポジトリの容量は無制限ではありません）。30・90・180・365 日（または自分で決めた期間）変更のないセッションは同期されなくなり、リポジトリから削除する前に同期ポップオーバーで確認します。期間はリポジトリ単位なので、すべてのコンピュータが同じ値を使います。

コンピュータは Agentty が `~/.agentty/computer-id` に作る ID で区別します（ハードウェアの情報は読みません）。`~/.agentty` を削除すると新しいコンピュータとして表示されます。ワークスペースを**同期データも削除**で削除すると、すべてのコンピュータから消えます。リポジトリにすべての版が残るので、バックアップにもなります。リポジトリは非公開である必要があり、公開中は同期が止まります。

## バックアップ

**構成をエクスポート**は、構成全体を 1 つの `.agenttyconfig` ファイルに保存します。設定、カスタムコマンド、コネクタ、データベース接続、エージェントのサインイン方法、読み込んだテーマ、インストール済みプラグインの一覧とその設定が入り、パネルの大きさや最近のフォルダなど 1 台のコンピュータ固有のものは含みません。**シークレットを含める**をオンにすると、資格情報ストアの API キー、トークン、パスワードと、シークレットを含むプラグインの設定を自分で決めたパスワードで暗号化して含めます（PBKDF2 + AES-256-GCM）。Agentty はこのパスワードを保存しません。

**構成をインポート**は、ファイルの構成でこのコンピュータの構成を置き換えます。設定はファイルの値が優先され、このコンピュータのパネルの大きさや最近のフォルダはそのままです。コマンドやコネクタなどのファイルは丸ごと置き換わります。パスワードを空にするとシークレット以外をインポートします。足りないプラグインはマーケットプレイスまたは Git リポジトリからインストールできます。インポート前の構成は毎回 `~/.agentty/backups/` に残ります。
