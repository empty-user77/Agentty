title: 設定画面

---

**⌘,** で設定が開きます。変更はすぐ反映され、`~/.agentty/settings.json` に保存されます。

## 一般

言語（English、한국어、日本語、中文）と、日々出会う挙動です。

| 設定 | 役割 |
|---|---|
| アイデアから作る | スタート画面と + メニューでアイデアのページを提案 |
| エージェントのステータスバー | AI ペイン上のバーと、ターミナルの上下どちらに置くか |
| 閉じる前に確認 | 使用したペイン・タブ・ワークスペースを閉じる前に尋ねる |
| セッションごとのワークツリー | 作業中のプロジェクトの 2 つ目のセッションに専用の git ワークツリー |
| ワークスペース一覧に検索欄を表示 | ワークスペース名と、その中の会話を検索 |
| 完了した作業スペースを一番上に移動 | オフにすると、自分で並べた順序のまま |
| 並列タスク | エージェントが分割ペインでの作業開始を要求できるようにし、毎回確認 |
| エージェントに Agentty の使い方を伝える | ここで起動したエージェントに Agentty のコマンド案内をコマンドラインで渡す |
| 閉じるときサーバーを停止 | ペインを閉じると、そこで起動したローカルサーバーを終了 |
| 匿名の利用統計の送信に同意 | [使用統計](/docs/telemetry) を参照 |
| メニューバーのアイコン | ウィンドウを閉じても Agentty を動かし続ける（macOS） |
| スリープ防止 | 長時間の自動実行が途切れないようマシンを起こしておく。常に、または 1〜72 時間を指定。電力を多く使う |

## プロジェクト

新しいタブが始まる場所、Agentty が探すハーネスのパターン、ハーネスのプロンプトをすぐ送るか、どのエージェントがハーネスの作業を始めるか。**エディタで開く**が使うエディタもここです。

## アカウント

新しい Claude Code・Codex タブのサインイン方法です。既定は何も変えず、エージェント自身のログインを使います。代替手段と資格情報の保管場所は[拡張・MCP・コネクタ](/docs/mcp-and-connectors)を参照してください。

## 外観

テーマ、フォント、フォントサイズ、行の高さ、字間、太字、背景・文字・カーソル・選択範囲の自分で選ぶ色、カーソルの形と点滅、余白、スクロールバック。エージェントのステータスバーに何をどの順で出すかもここです。[テーマとフォント](/docs/themes)を参照してください。

## キーボードショートカット

全一覧で、お使いのプラットフォームの表記で表示されます。[キーボードショートカット](/docs/keyboard-shortcuts)を参照してください。

## 通知

システム通知、Agentty が前面にあるときも通知するか、そして Slack・Discord・Telegram への通知です。[エージェントの状態](/docs/agent-status)を参照してください。

## ブラウザ

リンクをアプリ内ブラウザで開くか既定のブラウザで開くか、開発サーバーが自動で開くか、そして検索エンジンです。

## システムチェック

Agentty が使うツールと、その導入状況です。Git、Node.js、エージェント CLI など、足りないものをここから新しいタブで導入できます。

## Agentty について

バージョン、更新の確認、そして[プライバシーポリシー](https://www.agentty.run/privacy-policy)、[利用規約](https://www.agentty.run/terms-of-service)、[使用許諾契約](https://www.agentty.run/eula)へのリンクです。
