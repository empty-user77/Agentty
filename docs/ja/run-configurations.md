---
title: 実行構成
description: プロジェクトの開発サーバーやアプリをボタン一つで起動し、その出力をターミナル横の実行ログで確認します。
---

Agentty は IDE のように、プロジェクトで実行できるものを見つけて、ペインのヘッダーに **実行** ボタンを置きます（タブにペインが一つだけのときはタブバーに）。実行はターミナルに入力しません。出力はターミナルの下にドッキングされる実行ログに表示されます。

## 見つかるもの

| プロジェクト | 実行構成 |
|---|---|
| Node（`package.json`） | ルートパッケージのスクリプトすべて。下位パッケージでは何かを起動するスクリプト（`dev`、`start`、`serve`、`preview`、`watch`、`storybook`）。パッケージマネージャーは `packageManager` かロックファイルで決まります：npm、pnpm、yarn、bun |
| Spring Boot（Gradle または Maven） | アプリケーションごとに一つ。ラッパーがあればラッパーで実行し、マルチモジュールのビルドにも対応します |
| その他 | **コマンドを追加…** で自分で追加したコマンド（名前は任意）。そのプロジェクトに保存されます |

検出はファイルを読むだけで、ビルドツールは実行しません。プロジェクトフォルダーとその下二階層（`web/`、`apps/admin/`）まで調べ、依存関係やビルド出力のフォルダーは飛ばします。

## 実行する

- **実行** で構成が起動します。実行中はボタンが **停止** と **再起動** に変わります。
- ステータスバーに **実行**（または実行中の数）が表示されます。クリックすると、構成ごとの状態とポート、そしてプロジェクトでポートを開いているすべてのプロセスが表示され、それぞれ停止したりブラウザで開いたりできます。Windows ではポートを表示しません。
- ポートが使用中で実行に失敗すると、ログにそのポートを使っているプロセスが表示され、**終了して再実行** を提案します。ただし、そのプロセスがこのプロジェクトのものである場合に限ります。それ以外は、確かな場合に開いているポートの一覧から自分で終了してください。

## 実行ログ

一つのパネルに実行ごとのタブが並びます。できること：

- 単語または正規表現で行を絞り込む（大文字と小文字の区別は選択可）
- あるレベル以上の行だけを表示する（レベルごとの行数つき）
- 長い行の折り返し、最新行への追従、または自由に遡ってスクロール
- アドレスを Cmd-クリック（Ctrl-クリック）して開く

色はそのまま保たれ、進捗表示の行は一行にまとめられます。パネル上端をドラッグして高さを変えられ、高さは保存されます。ログを隠しても実行は続きます。

## Agentty を終了すると

実行も一緒に終わります。終了すると実行は停止し、クラッシュで残った実行は次回起動時に停止されます。
