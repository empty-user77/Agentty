---
title: ボット
description: 指示と記憶を持つ名前付きのエージェント。互いに作業を渡し、決まった時刻に始め、Telegram・Slack・Discord からメッセージを受け取ります。
---

ボットは、名前と目的と記憶を持つエージェントです。お使いのコンピュータ上で Claude Code または Codex として動き、すでに利用しているサブスクリプションをそのまま使います。チャットで話しかけられ、ほかのボットが名前を指定して作業を渡せます。決まった時刻や Telegram・Slack・Discord のメッセージで自分から作業を始めることもできます。スマートフォンからも、ボットの状況を見て、オン／オフを切り替え、作業を頼み、報告を受け取れます。

ボットは Agentty が開いている間だけ動きます。Agentty を閉じると何も実行されません。直近 24 時間以内に逃したスケジュールは、次に開いたときに一度だけ実行されます。

## ボットを作る

1. サイドバー下部の **ボット**（ワークスペース一覧の下）の横にある **+** を押します。
2. テンプレートを選ぶか、**ゼロから作る** を押します。日常向け（日常の話し相手、マイPCアシスタント、メール秘書、会議アシスタント、今日の計画）、調査・学習向け（ニュースブリーフィング、リサーチ、文章アシスタント、学習コーチ、買い物比較）、開発向け（レビュアー、バグハンター、CI ウォッチ）のテンプレートがあります。テンプレートはボットのプロンプト、ルール、スキルを入力し、ものによっては自分で始める時刻やウォッチも設定します。
3. キャラクターと色を選び、名前、ハンドル、実行するエージェント、作業するプロジェクトフォルダを確認して **作成** を押します。

ボットにはそれぞれキャラクターがあります。サイドバー、会話、ルーム、アクティビティなど、ボットが出てくるすべての場所に表示されます。キャラクターと色は後からボットの設定で変更でき、設定や **新しいボット** で自分の画像を代わりに使うこともできます（PNG・JPEG・WebP・GIF、5MB まで）。

ボットを使わない場合は、サイドバーのオプションメニューで **ボット機能を使う** をオフにします。ボットの欄が消え、スケジュールとチャンネルが止まります。ボット自体は残ります。

ハンドルは `@` の後ろに書く名前です。英小文字・数字・ハイフンのみ使え、後から変更できません。

サイドバーのボットの行には今していることが表示され、押すとそのボットとのチャットが開きます。自分が書いたものは右、ボットが言ったことは左に並び、その間にボットが自分で始めたきっかけ（スケジュール、ウォッチ、ほかのボット）が表示されます。下の入力欄にメッセージを書いて送ります。チャットはボットのフォルダに保存されるので、再起動しても残ります。上の歯車を押すと、ボットが自分で始めるとき、覚えていること、設定が表示されます。その横のボタンはボットが作業するエージェントセッションを開きます。これはチャットとして表示される通常のセッションで、添付、承認、裏側のターミナルが使えます。ボット専用のワークスペースなので、ワークスペース一覧には表示されません。

## ボットのページ

サイドバーの **ボット** バーを押すと、ボットの欄が折りたたまれます。その横のボタンは、すべてのボット、アクティビティ、ルーム、テンプレートのあるページを開きます。

- **作業を頼む**: ページ上部でボットを選び、やることを書いて Enter を押します。`@ハンドル` で始まるメッセージはそのボットに届きます。
- **各行**には、ボットが今していること、待っているもの、または最後の回答と、次に自分で始める時刻が表示されます。
- **アクティビティ**には、誰が誰に何を渡したかが新しい順に並びます（あなた、スケジュール、チャンネル、ほかのボット）。行を押すとその会話が開きます。

ボットのチャットとルームのメッセージは、通常のチャットと同じく選択・コピーできます。ドラッグして **⌘C** を押すか、選択の上のバーから返信に引用します。右クリックするとメッセージ全体をコピーするメニューが出ます。

## ボットの構成

ボットのチャットを開いて上の歯車を押すと、ボットを構成する 4 つがカードで表示されます。

| カード | 内容 | ファイル |
| --- | --- | --- |
| **プロンプト** | ボットが何をし、どう答えるか | `SOUL.md` |
| **ルール** | 誰に頼まれても必ず守ること: すべきことと、してはいけないこと | `RULES.md` |
| **コンテキスト** | 知っておくべき背景: あなたが誰で、何に取り組んでいるか。ボット自身が書いた記憶も一緒に表示されます | `CONTEXT.md`、`MEMORY.md` |
| **ツール** | できること（権限）と、作業に使うスキル | `skills/` |

カードの **書く** または **編集** を押してその場で書き換え、**保存** を押します。変更はボットの次の会話から反映されます。エージェントは会話の開始時にこれらを読みます。

ボットは人が読んで編集できるファイルの入ったフォルダで、Agentty のデータフォルダの `bots/<ハンドル>/` にあります。上のファイルのほかに `bot.json`（ボットの定義）と `chat.json`（チャット）があり、この 2 つは Agentty が書きます。

ボットは残しておく価値のあることを学ぶと記憶に書き足します。記憶は先頭の 16 KB までが渡されます。ファイルがそれより大きくなると、Agentty がボットに整理を頼み、整理前のファイルを `MEMORY.before-tidy.md` として残します。

## コンピューターを代わりに使うボット

**マイPCアシスタント** テンプレートは、このコンピューターを代わりに操作するボットを作ります。アプリを開いて使い、メッセンジャー（KakaoTalk、メッセージ、Slack、Telegram）を読んで返信を代わりに送り、Mac の iPhone ミラーリングで iPhone を操作し、ファイルを探し、リマインダーを管理します。**コンピューター操作**、**メッセンジャーの読み書き**、**iPhone ミラーリング** のスキルを持って始まり、これらはスキルハブでほかのボットにも渡せます。

- **仕組み**: エージェントが画面（ウインドウの文字、または画面の画像）を見て、一手（クリック、入力、ショートカット）を行い、もう一度見ます。エージェントにコンピューター操作ツールがあればそれを使い、なければシステムのスクリプト機能を使います。
- **macOS が確認すること**: 初回は、Agentty にコンピューターの制御を許可するかを macOS が確認します。システム設定 > プライバシーとセキュリティ > **アクセシビリティ** で Agentty をオンにし、画面の画像のために **画面とシステムオーディオの録音** もオンにします。許可がなければ、ボットは何が足りないかを伝えて止まります。
- **頼まれなければしないこと**: メッセージを送る前に正確な文面と宛先を示し、毎回あなたの許可を待ちます。パスワード、パスコード、支払い情報は入力せず、その手順はあなたに任せます。
- **iPhone**: macOS 15 以降が必要で、iPhone はロックされた状態で Mac の近くにある必要があります。ミラーリングではカメラとマイクは使えません。

ボットがアプリを操作している間、キーボードとポインタはボットが使います。終わったと言うまで触らないでください。

## スキルハブ

スキルは、ある種類の作業のやり方を書いたものです。受信トレイの仕分け方、出典付きの調べ方、変更のレビューの仕方などです。**ツール** カードの **スキルハブ** を押して、ボットにスキルを渡したり外したりします。

- **標準搭載**: Agentty に入っている 19 個のスキルです。PC 操作、日常、仕事、調査、学習、開発向けがあります。
- **自分のスキル**: このコンピューターのエージェントがすでに持っているスキルです（`~/.claude/skills`、`~/.codex/skills`、`~/.agents/skills`）。追加するとボットのフォルダにコピーされ、元のスキルはそのまま残ります。

名前で検索するか、左で種類を選びます。ボットには自分のスキルの名前が伝えられ、該当する作業の前にそのスキルを読みます。スキルは作業のやり方を示すだけで、ボットにできることの範囲を広げることはありません。

## 権限

| モード | ボットができること |
| --- | --- |
| **確認する** | エージェント本来の承認フローです。ボットが尋ね、あなたが答えます。 |
| **読み取り専用** | 作業を判断するのに必要なものを読み、実行します。ファイルは編集しません。 |
| **ファイルのみ** | 自分のフォルダ内のファイルを読み書きします。シェル、ウェブ、その他のツールは使えません。 |

通常のタブの設定がどうであっても、ボットが権限確認を省略した状態で起動されることはありません。権限を変えられるのはボットの設定だけで、メッセージでは変えられません。

## ボット同士で働く

ボットは自分のシェルから別のボットに作業を渡します。

```sh
agentty bot list
agentty bot send reviewer --prompt "Review the parser branch and list what must change."
agentty bot result reviewer
agentty bot status
```

`send` はすぐに戻ります。相手のボットの回答は、後から送った側の会話に `[Agentty]` で始まるメッセージとして届きます。このコマンドはボットに限らず、Agentty 内のどのエージェントセッションからも使えます。

### ルーム

ルームは複数のボットが参加する 1 つの会話です。**新しいルーム** を選び、名前とメンバーを決めます。

- あなたが書いた内容は、`@ハンドル` で指定したボットに、指定がなければ最初のメンバーに届きます。
- ボットの回答に別のメンバーの `@ハンドル` があれば、そのボットが次の番になります。誰も指定しなければ、あなたの番に戻ります。
- 番を受け取るボットには、前回の番以降の発言が一緒に渡されます。

### 上限

| 上限 | 値 |
| --- | --- |
| あなたの発言なしで続くボット間の受け渡し | 8 回 |
| 1 つのボットで待機できるメッセージ | 32 件 |
| 同時に作業するボット | 4 つ |

受け渡しの上限に達した流れは止まり、**要対応** に表示されます。

## ウォッチ

ボットは頼まれなくても、何かが起きたときに自分で作業を始められます。ボットの設定の **ウォッチ** で、見張るものをオンにします。

- ボットのフォルダにあるリポジトリの **新しい Issue**、**新しいプルリクエスト**、**CI の失敗**。GitHub CLI（`gh`）がインストールされ、サインインしている必要があります。
- **リモートの新しいコミット**: リモートのデフォルトブランチが進んだとき。
- **フォルダの新しいファイル**: ボットのフォルダ直下にファイルやフォルダが現れたとき。

Agentty が 5 分ごとに決まった `gh`・`git` コマンドを実行するか、フォルダを読んで確認します。新しいものがあるときだけエージェントを起動するので、動きのないリポジトリではコストがかかりません。最初の確認では、すでにあるものを記録するだけです。確認できない場合（`gh` がない、サインインしていない、リポジトリではない）は、ボットの設定に理由が表示されます。

バグハンター、レビュアー、CI ウォッチのテンプレートは、ウォッチがオンの状態で作成されます。

## スケジュール

ボットの設定で、時刻とやることを追加します。**毎時**、**毎日**、**平日**、**毎週** から選ぶか、`0 9 * * 1-5` のような 5 フィールドの cron 式を入力します。実行の間隔は 15 分以上です。

## Telegram、Slack、Discord

お使いのコンピュータがサービスへ接続し、メッセージを待ちます。ポートは開かず、中継サーバーもありません。

チャンネルは、リストに登録した送信者のメッセージだけを受け取ります。それ以外のメッセージは破棄され、ボットの `audit.log` に記録されます。送信者のリストが空のチャンネルはオフです。

### Telegram

1. [@BotFather](https://t.me/BotFather) でボットを作り、トークンをコピーします。
2. ボットの設定の **Telegram** にトークンを貼り付けて保存します。トークンはシステムのキーチェーンに保管されます。
3. **許可する送信者** に自分の Telegram の数値 ID を入力して保存します。

Telegram を使うボットが複数ある場合は、メッセージを `/ハンドル` で始めてボットを選びます。

### Slack

1. **Socket Mode** を有効にした Slack アプリを作り、`connections:write` を持つアプリトークン（`xapp-…`）と、`app_mentions:read`・`chat:write`・`im:history` を持つボットトークン（`xoxb-…`）を発行します。`app_mention` と `message.im` イベントを購読します。
2. **Slack** に 2 つのトークンを貼り付けて保存します。
3. **許可する送信者** に、書き込みを許可する Slack メンバー ID（`U…`）を入力します。

アプリをメンションしてボットのハンドルを書くか（`@アプリ名 reviewer check the PR`）、アプリに直接メッセージを送ります。回答はスレッドに付きます。

### Discord

1. [Discord Developer Portal](https://discord.com/developers/applications) でアプリケーションを作り、ボットを追加してトークンをコピーします。ボットをサーバーに招待するか、ボットとのダイレクトメッセージを開きます。
2. **Discord** にトークンを貼り付けて保存します。
3. **許可する送信者** に自分の Discord ユーザー ID を書きます（Discord で開発者モードをオンにし、プロフィールの **ユーザー ID をコピー**）。

ボットに直接メッセージを送るか、サーバーでボットをメンションします（`@ボット名 reviewer check the PR`）。読むのは、ダイレクトメッセージとボットをメンションしたメッセージだけです。

### チャンネルからボットを操作する

ボットの送信者リストにいる人は、そのボットたちについて Agentty 自体に尋ねることもできます。次の言葉だけを送ります。前に `/` や `!` を付けてもかまいません。

| メッセージ | すること |
| --- | --- |
| `bots` | すべてのボットの状況 |
| `status <ボット>` | ボット 1 つの状態と最後の返答 |
| `on <ボット>` / `off <ボット>` | オン / オフ。オフのボットは作業を受けず、同じ会話からまたオンにできます |
| `stop <ボット>` | 作業を止める |
| `/<ボット> <メッセージ>` | そのボットに作業を頼む。チャンネルにボットが 1 つだけなら、メッセージだけで届きます |
| `help` | この一覧 |

メッセージがどこから来ても、ボットは Agentty で与えた権限で、このコンピューター上で作業します。エージェントが承認や質問で止まると、何を尋ねているかと番号付きの選択肢が会話に届きます。番号だけを送って答え（`1`）、ボットが複数なら `/<ボット> 1` と送ります。メッセージの内容でボットの権限が広がることはありません。

番号が通るのは、その質問が届いた会話からで、画面の選択肢が届いたものと同じ間だけです。「今後は確認しない」のように効き続ける選択肢はチャンネルには出ず、Agentty で選びます。Agentty が動いていなかった間に送った番号と `on` / `off` / `stop` は、後から実行されません。

### 作業の報告

ボットの回答は、メッセージが来た会話に戻ります。ボットが自分で行った作業（スケジュール、ウォッチ、ほかのボットから戻った作業）は、そのチャンネルの **自分で行った作業もここに報告** がオンのとき、最後にボットへ 1 対 1 で書いた会話に報告します。グループの会話には報告しません。送信者をリストから外すと、報告先も忘れます。

## 要対応

ボットのページの上部には、承認や質問で止まっているボットと、止められた流れがすべて並びます。**回答する** を押すと、尋ねているセッションが開きます。

## スマートフォンから

リモートページのワークスペース一覧の下にボットが並び、それぞれにスイッチがあって、その場でオン／オフを切り替えます。ボットをタップするとチャットが開きます。ボットに送ったメッセージ、ボットの回答、自分で行った作業の報告が並び、下の入力欄で作業を頼みます。作業中は何をしているかが表示され、承認や質問で待っているときは **答える** で尋ねているセッションへ移動します。リモートアクセスから外したワークスペースに会話があるボットは一覧に出ません。

ボットの作成と、プロンプト・ルール・スキル・権限・チャンネルの変更は Agentty でのみ行います。
