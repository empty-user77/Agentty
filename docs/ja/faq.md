title: よくある質問
description: Agentty を使っていて出てくる質問への短い答え。

## Agentty は無料ですか？

はい。アカウントもサブスクリプションも有料プランもありません。エージェントが使った分の費用は各 AI プロバイダーに直接お支払いいただくもので、そこに Agentty は関与しません。

## tmux と何が違いますか？

tmux はターミナルを多重化します。Agentty はその中で動くエージェントを中心に作られています。どれが作業中で、どれが自分を待っていて、それぞれ何を変え、いくらかかったかを把握します。タブも分割も本物のターミナルもそのままに、ペインの中身が AI エージェントのときだけ意味を持つものが加わります。

## 会話はアップロードされますか？

いいえ。セッション一覧、検索、使用量、コンテキスト文書は、すべてすでにコンピュータにあるファイルから作られます。利用者が実行するエージェント CLI は、それぞれのプロバイダーと直接通信します。Claude Code は Anthropic と、Codex は OpenAI と、他のターミナルとまったく同じように、そのプロバイダーの規約のもとでやり取りします。

Agentty 自体が送るものは[使用統計](/docs/telemetry)にまとめてあり、全体像は[プライバシーポリシー](https://www.agentty.run/privacy-policy)にあります。

## + メニューにエージェントが出てきません

Agentty は**ログインシェル**の `PATH` で見つかる CLI だけを提示します。ターミナルでは動くのにここでは出ない場合、`PATH` が対話シェルしか読まないファイルに設定されている可能性が高いです。**設定 → システムチェック**が不足分を挙げ、導入もしてくれます。

## 前の会話をもう一度開くには

**⇧⌘S** がマシン上のすべての Claude Code・Codex セッションを並べ、**⇧⌘O** がタイトル・内容・パスで検索します。セッションはエージェント自身のファイルで、Agentty は読むだけです。[セッション](/docs/sessions)を参照してください。

## ブランチとワークツリーが溜まります

並列セッションごとに `agentty/<名前>` ブランチのワークツリーが 1 つ作られます。[ファイルパネル](/docs/agent-git)（**⌥⌘B**）にすべてのワークツリーが並び、右クリックで削除でき、マージ済みのブランチも一緒に消せます。

1 つのフォルダで作業したい場合は**設定 → 一般 → セッションごとのワークツリー**をオフにしてください。

## 使用量が実際の請求と違います

ローカルの会話ファイルから計算した目安で、内蔵されている価格は Claude のモデルだけです。他のモデルは `~/.agentty/pricing.json` に価格を追加してください（[設定リファレンス](/docs/configuration-reference)参照）。実際の金額はプロバイダーの請求書です。

## エージェントが許可を何度も尋ねます

それは Agentty ではなくエージェント自身の許可の仕組みです。エージェント側で設定してください。Claude Code ならその設定や `/permissions` です。Agentty は利用者の選択をそのまま渡すだけで、勝手に緩めることはありません。

## プラグインが読み込まれません

SDK と必要な `node_modules` を含め、動作に必要なものをすべて同梱してください。Agentty は `npm install` を実行しません。フォルダ名はマニフェストの `id` と一致している必要があります。プラグインカードの**ログ**に実際のエラーがあります。[プラグインを配布する](/docs/plugin-publishing)を参照してください。

## Windows・Linux のビルドはいつ入手できますか？

コードは両方でビルドされ動作し、パッケージの配布も計画しています。現在公開されているダウンロードは macOS だけです。[プラットフォーム](/docs/platforms)を参照してください。

## ソースは公開されていますか？

まだです。公開を予定しており、それまではリリースページが Agentty を入手する方法です。

## それ以外の問題

[トラブルシューティング](/docs/troubleshooting)によくある例をまとめています。それ以外は[イシュートラッカー](https://github.com/empty-user77/Agentty/issues)へどうぞ。セキュリティの問題は公開の issue ではなく非公開で報告してください。
