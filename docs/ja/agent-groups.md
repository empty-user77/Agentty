---
title: エージェントグループ
description: 役割を一つずつ持つエージェントのチームを、一つのプロジェクトでまとめて起動する。
---

エージェントグループは、プロジェクトのタブ一つに複数のエージェントを役割付きで開きます。一つは開発、
一つはレビュー、一つはデプロイ、という具合です。各エージェントはターミナルの上に名前と役割のバッジを
付け、ほかのエージェントの役割を知っていて、最初から互いにつながっているので、一つが行ったことを
ほかも知っています。

## グループを始める

プロジェクトでコマンドパレット（**⇧⌘P**）を開き、**エージェントグループを開始: …** を選びます。
このプロジェクトで使えるグループだけが表示されます。最初のエージェントがメインです。メインのペインは
拡大された状態で始まり、ほかはその横で動きます。

Claude Code がまだ信頼していないフォルダでは、メインのエージェントだけが先に起動します。メインの
ペインでフォルダの確認に答えると、残りは改めて尋ねずに起動します。

## エージェント同士の働き方

- **すべての依頼はそのエージェントの役割として読まれます。** デプロイ担当に「e-ticket をデプロイ
  して」と言えば、このプロジェクトのやり方で e-ticket のデプロイ作業をします。
- **ほかのエージェントの役割の仕事はそのエージェントに渡します。** エージェントが `agentty group
  send "<エージェント>" "<依頼>"` を実行すると、依頼はそのエージェントのターミナルに届き（作業中なら
  今のターンの後）、そこで進み具合を見られます。
- **誰の役割でもない仕事はしません。** グループにどの役割があるかを伝えます。
- **セッションの共有。** Claude Code のエージェント同士は互いに紹介され、Claude Code のセッション
  メッセージで直接やり取りします。ほかのエージェントには双方向のライブ
  [Session Flow](session-flow) 接続が張られます。

`agentty group list` はメンバー、役割、作業中かどうかを表示します。

## グループはパッケージです

グループは JSON ファイル一つです。ファイルを共有すれば、受け取った人はコマンドパレットの
**エージェントグループを読み込む…** で読み込み、すぐに始められます。インストール済みのグループは
`~/.agentty/agent-groups/` にあります（パレットの **エージェントグループのフォルダを開く**）。そこで
ファイルを編集するとグループが変わり、コピーすれば新しいグループになります。出発点としてサンプルの
*Dev team* が入っています。

```json
{
  "name": "E-ticket team",
  "description": "Build and ship the e-ticket service",
  "scope": "acme/eticket",
  "notes": "Deploy with ./scripts/deploy.sh <env>. Staging first.",
  "agents": [
    { "name": "Dev", "role": "Implements features and fixes bugs", "badge": "Build", "agent": "claude" },
    { "name": "Deploy", "role": "Builds and deploys to staging and production", "badge": "Release",
      "agent": "claude", "instructions": "Never deploy to production without the user's OK." }
  ]
}
```

| 項目 | 意味 |
|---|---|
| `name` | グループ名。パレットに表示されます。 |
| `description` | グループの一行説明。 |
| `scope` | すべてのプロジェクト用なら `"any"`、特定のリポジトリ用なら `"owner/repo"`：`origin` リモートがそのリポジトリのプロジェクトでだけ表示されます。 |
| `notes` | 全エージェントが知っておくべきこと：ビルドやデプロイの方法、ファイルの場所など。 |
| `agents` | エージェント 1〜6 体。最初がメインです。 |
| `agents[].name` | ペインに表示され、仕事を渡すときに使う名前。重複できません。 |
| `agents[].role` | このエージェントの仕事を一行で。 |
| `agents[].badge` | 役割バッジの一、二語（16 文字まで）。なければ `role` の先頭。 |
| `agents[].agent` | `claude`（既定）または `codex`。 |
| `agents[].instructions` | このエージェントだけの追加ルール。 |

グループの役割・ノート・指示は、エージェントへの指示になります。人から共有されたグループは、スクリプト
を読むように確かめてから読み込んでください。自分のプロジェクトでエージェントが何をするかを決める
内容です。

## 知っておくこと

- グループのバッジと接続はアプリの起動中だけ保たれます。再起動するとエージェントのタブは戻りますが、
  バッジと接続はありません。新しいチームが必要ならグループをもう一度始めてください。
- エージェントのペインを閉じると、そのエージェントは抜けます。そのエージェントに仕事を渡すと、閉じて
  いると伝えます。
