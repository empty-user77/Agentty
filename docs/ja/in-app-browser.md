---
title: アプリ内ブラウザ
description: ターミナルの横のブラウザパネル、自分で開く開発サーバー、そしてエージェントにページを操作させること。
---

**⇧⌘B** でターミナルの横にブラウザパネルが開きます。macOS では Agentty 内の WebKit ビュー、Windows では Microsoft Edge WebView2（Chromium）ビューで、Linux では既定のブラウザが代わりに開きます。WebView2 は Windows 10・11 に標準で入っており、ない PC ではブラウザを開くときに Microsoft 公式のインストーラーをダウンロードしてインストールするよう案内します。

## 開く方法

- ターミナルのリンクを ⌘-クリック（Windows・Linux は Ctrl-クリック）。
- **設定 → 一般**で、⌘-クリックがアプリ内ブラウザを使うか既定のブラウザを使うかを決めます。
- URL を入力するか、検索語を入力します。検索エンジンは設定で変えられます。

## 開発サーバー

タブで起動したローカルサーバーはワークスペース一覧に `:ポート` のチップとして現れ、ページを返した時点でパネルに開きます。

サーバーを起動したタブを閉じるとサーバーも終了します。どちらの挙動も**設定 → 一般**と**設定 → ブラウザ**でオフにできます。

## レスポンシブモード

アドレスバー横のスマートフォンボタンを押すと、ページをパネルの幅ではなく端末のサイズで表示します。iPhone SE, iPhone 15 Pro, iPhone 15 Pro Max, Pixel 8, Galaxy S24, iPad mini, iPad Air, iPad Pro 12.9", Laptop, Desktop から選ぶか、幅と高さを自分で入力します。ページはパネルの空きに合わせて中央に配置され縮小されるので、幅 1920 のデスクトップレイアウトも狭いパネルで読めます。回転は 2 つの数値を入れ替え、右端や下端をドラッグすれば手で大きさを変えられます。

オフにすると、ページはパネル本来の幅に戻ります。

## エージェントに操作させる

Claude Code と Codex は MCP を通じてこのブラウザを操作できます。クリック、入力、コンソールの読み取り、スクリーンショットです。エージェントが動いているページで自分の作業を確認する方法です。

エージェントが受け取るツールは次のとおりです。

| ツール | 動作 |
|---|---|
| `browser_open` | このターミナルのタブを開く（初回は作成）。必要なら URL を読み込む |
| `browser_navigate` | URL、`ホスト:ポート`、検索語を読み込む |
| `browser_status` | 現在の URL・タイトルと読み込み中かどうか |
| `browser_wait_load` | 読み込みが終わるまで待つ |
| `browser_click` | 要素をクリック |
| `browser_console` | ページのコンソール出力を読む |
| `browser_screenshot` | ページを取り込む |
| `browser_viewport` | 端末サイズ・`WxH`・`off` でページを表示 |
| `browser_close` | このターミナルのタブを閉じる |

Agentty がエージェントを起動するときに一緒に登録するので、導入も設定も要りません。典型的な流れはこうです。エージェントが開発サーバーを立ち上げ、ページを開き、今作った変更をクリックして確かめ、コンソールのエラーを読み、見つかったものを直します。

### ターミナルごとに 1 つのブラウザ

ターミナルごとにブラウザが別にあります。あるターミナルでブラウザを開いてあるサイトを見て、別のターミナルで開いて別のサイトを見ると、ターミナルを選ぶたびにそのターミナルのブラウザが見ていたとおりに現れます。ブラウザを開いたことのないターミナルではパネルは閉じています。見えていないターミナルのページも読み込み、スクリプト、スクリーンショットが動き続けるので、ある作業があなたが見るまで止まることはありません。

- **リンクとサーバーはそのターミナルへ。** ターミナルでクリックしたリンク、そのターミナルが起動したサーバーのポートチップ、ひとりでに開くサーバーのページは、すべてそのターミナルのブラウザに開きます。別のワークスペースのカードのポートチップを押すと、そのターミナルが選ばれます。
- **エージェントはそのターミナルのブラウザの中の自分のタブで働きます。** 最初の `browser_open` で作られ、ターミナルのフォルダと番号（`app #3`）で表示されます。そのエージェントの操作はすべてこのタブだけに届き、ほかのターミナルのページ、自分で開いたページ、プラグインのページは変えません。ページは画面にあってもなくても 1280px（または `browser_viewport` で指定したサイズ）で配置され、表示中はパネルに合わせて縮小されるので、パネルの幅で結果が変わりません。
- **上限で軽く保ちます。** 画面外で動くターミナルのブラウザは最大 6 つ、アプリ内ブラウザの全ページが合わせて使うメモリはこのコンピュータのメモリの最大 30% です（どちらも **設定 → ブラウザ** で設定）。どちらかを超えると、画面外のブラウザをいちばん前に見たものからメモリから外します。画面上のブラウザと、エージェントが直近 2 分以内にコマンドを送ったブラウザは外しません。外したページはアドレスを覚えておき、そのターミナルを選ぶかエージェントがコマンドを送ると読み込み直します（そのときコマンドは読み込みが終わってから実行します）。
- **パネルを閉じるとそのターミナルのブラウザは隠れ**、もう一度開くとそのまま戻ります。**ターミナルを閉じるとそのブラウザも閉じます。**
- **Cookie とサインイン状態は共有**されるので、サイトへのサインインは一度で済みます。エージェントのタブごとに Cookie を分けるには **設定 → ブラウザ → ターミナルごとに Cookie とサインインを分ける** をオンにします（macOS 14 以降、Windows は WebView2 ランタイム 101 以降）。ターミナルを閉じるとその Cookie も消えます。

> [!IMPORTANT]
> このブラウザは利用者がサインイン済みのセッションを保持します。エージェントが操作すれば、そのセッションの中で動きます。必要なときに使い、どのタブが開いているかを把握しておいてください。
