**⌥⌘U** でモニタリングが開きます。ここの数値はすべて利用者のマシンで計算され、どこにもアップロードされません。

## アプリ内ブラウザ

ウィンドウで開いているすべてのアプリ内ブラウザが 1 行ずつ並びます。どのワークスペースのどのターミナル（またはプラグイン）のものか、そのターミナルで何が動いているか、ページの小さなプレビュー、画面に表示中か・画面外で動作中か・閉じたが保持中か・メモリから外したか、ページが使うメモリを示します。上部には、アプリ内ブラウザ全ページのメモリと 設定 → ブラウザ の上限、実行中の数、メモリから外した数が出ます。

- **ターミナルへ移動**: そのワークスペースとターミナルを選び、ブラウザを表示します（メモリから外したものは読み込み直します）。
- **今すぐ閉じる**: そのターミナルのブラウザを閉じてメモリを解放します。

モニタリングはこのページで開きます。プレビューはキャッシュで、このページを開いている間、プレビューがないか 5 分より古いブラウザだけを撮り、Agentty のデータの非公開フォルダに置きます。ブラウザを閉じると一緒に消えます。

## AI 使用量

費用、呼び出し回数、キャッシュヒット率、トークンを、モデル・プロジェクト・ツール別に示します。数値はエージェント CLI がすでにディスクへ書き出した会話ファイルから得ています。

集計は行を足すほど単純ではありません。Claude Code はコンテンツブロックごとに JSONL を 1 行書くため、1 つの API 応答が同じ message id で何度も現れます。これをその id で重複排除します。Codex は応答ごとに使用量レコードを 1 つ、response id で記録します。Agentty はそれぞれの形式に従うので、1 つの応答が一度だけ数えられます。

Claude のモデル価格は内蔵されています。Codex が使うモデルなどそれ以外は、`~/.agentty/pricing.json` に価格を書けば一緒に計算されます。

```json
{
  "some-model": { "input": 1.25, "output": 10.0, "cacheRead": 0.125 }
}
```

価格は 100 万トークンあたりの USD です。`cacheRead`、`cacheWrite`、`cacheWrite1h` は任意で、既定はそれぞれ入力単価の 10%、125%、200% です。

> [!NOTE]
> ローカルのファイルから計算した目安です。実際の金額はプロバイダーの請求書です。

## プロセス

いまマシンで動いている AI プロセスと、それを起動したものを示します。止めたつもりなのにトークンを使い続けているときに役立ちます。

## プロキシ

プロキシは今ではプラグインです。**Proxy Capture** プラグインで、各タブや AI セッションがどこと通信しているかを確認できます。キャプチャを開始し、タブを開き、テキスト・タブ・エンドポイントで絞り込みます。**プラグイン → Git からインストール…** に `https://github.com/empty-user77/agentty-proxy-capture` を貼り付けてインストールします（Node.js 18 以降が必要）。目のアイコンはタブバーの右上にあり、パネルはターミナルの右側にドッキングして開きます。

**キャプチャが有効なときに開いた**ターミナルと AI セッションは、利用者のマシン上で動くプロキシを経由します。**開いているターミナルに適用**は、すでに開いているシェルにも同じ設定を入れます。

キャプチャは次のどちらかの単位で動きます。

- **ターミナル単位**（既定）: キャプチャ中に開いたターミナル（AI セッションでもシェルでも）と、適用したターミナルだけをキャプチャします。それらがすべて閉じると、キャプチャは自動で止まります。
- **ワークスペース単位**（**このワークスペースの作業をすべてキャプチャ**）: 前面のワークスペースのターミナルすべてを、開いているシェルも含めてキャプチャし、その接続だけを表示します。ワークスペースを閉じるか削除すると、キャプチャは自動で止まります。開いていた AI セッションは再起動するとキャプチャされます。

- HTTPS は暗号化されたままです。記録されるのはホスト、ポート、バイト数、時間だけで、証明書は入れず、復号もしません。
- 平文の HTTP は、メソッド、パス、ステータスを記録します。ヘッダーはヘッダー記録をオンにしたときだけ記録し、認証情報は `***` で隠します。
- 記録はメモリ上にだけあり、ディスクには書き込まれません。プラグインを停止すると消えます。

キャプチャを止めると記録が止まります。すでにプロキシを渡されたターミナルは、通信が切れないようそのまま使い続けます。

## ワークツリー管理

この PC のすべての git ワークツリーをプロジェクトごとに表示します。ブランチ、最終作業（最後のコミットか最新の未コミットの変更）、未コミットのファイル、既定ブランチにまだないコミット、プルリクエスト（オープン・マージ済み・クローズ — サインイン済みの GitHub CLI で読みます）、サイズ。

ホームフォルダー以下、Agentty のワークツリーフォルダー、開いているフォルダーから探します。プロジェクトフォルダーしかないプロジェクトは一覧に出しません。

複数にチェックして **削除** を押します。**安全なものを選択** は、未コミットの変更がなくコミットがすでにマージされたツリーをすべて選びます。削除の前に確認します。

- **ブランチも削除** は失うもののないブランチだけを消します。git 自身の確認を通るか、ブランチの最後のコミットのままマージされたプルリクエストがある場合です（スカッシュマージを含む）。それ以外は残ります。
- 未コミットの変更があるツリーは、チェックしない限りスキップします。チェックするとその変更は失われます。
- プロジェクトフォルダー自体と、タブが作業中のツリーは選べません。

## ディスク管理

ディスクの使用状況（使用中・解放可能・空き）と、ホームフォルダーで容量を使っているフォルダー。開くとその中の大きいフォルダーが出ます。

片付けられるのは、自動で作り直されるものだけです。

- **プロジェクトのビルド出力** — プロジェクトごとに **ビルドの不要ファイルを削除**（Cargo `target`、`.next`、Gradle `build`、SwiftPM `.build` など）と **キャッシュを削除**（`.turbo`、`.parcel-cache`、`node_modules/.cache`、pytest・mypy・Ruff のキャッシュなど）。ツールのプロジェクトファイルが隣にあるときだけ対象になり、Cargo の `target` は Cargo が書くタグも必要です。
- **キャッシュ** — 開発ツール自身のキャッシュ: npm、Yarn、Bun、pip、uv、Go、Cargo レジストリ、Gradle、Homebrew、CocoaPods、JetBrains、Xcode DerivedData。
- **その他** — ゴミ箱とログファイル。

`node_modules` や `~/.m2` などの依存関係、プロジェクトの実行に必要なものは対象に出ません。削除は確認してから行い、直前にもう一度確かめ、リンクはたどりません。次のビルドやインストールが少し長くなるだけです。
