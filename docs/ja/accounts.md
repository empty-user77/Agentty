---
title: 複数のアカウント
description: Claude Code と Codex のアカウントに複数ログインし、アカウントごとに専用のウィンドウで同時に動かす方法。
---

Claude Code と Codex のアカウントに複数ログインしておけます。アカウントごとに専用のウィンドウで、それぞれのセッション、使用量、プランの上限で動き、複数のアカウントを同時に動かせます。仕事用と個人用のアカウントを分けたり、あるアカウントの上限に達したときに別のアカウントで続けたりするのに使います。

## アカウントの追加

設定の上にあるアカウントアイコンをクリックすると、アカウントメニューが開きます。**アカウントを追加** で別の Claude Code または Codex のアカウントにログインします。ログインはアカウントごとに保たれます。

もともと `~/.claude` と `~/.codex` にあったログインは **ベースアカウント** として一覧に表示され、そのまま使えます。

## アカウントごとにウィンドウ 1 つ

アカウントメニューでアカウントをクリックすると、そのアカウントのウィンドウが前面に来るか、新しく開きます。

| アカウントごとに別 | すべてのアカウントで共有 |
|---|---|
| ウィンドウとその中のワークスペース | 設定 |
| セッション履歴 | スキル、ルール、フック |
| 使用量とプランの上限 | MCP サーバー |
| 同期リポジトリ | |

## どのアカウントで始めるか

複数のアカウントがあるエージェントを起動すると、どのアカウントを使うか毎回たずねます。最初はそのウィンドウのアカウントが選ばれていて、アカウントごとにプランと使用量が表示されます。

- 新しいタブで Claude Code や Codex を開くときにたずねます。
- ターミナル(分割ペインを含む)に `claude` や `codex` と入力しても同じようにたずね、選んだアカウントで実行します。**Esc** で閉じると実行しません。
- アカウントが 1 つだけなら、何もたずねません。

## 別のアカウントで動くペイン

ウィンドウのアカウントと違うアカウントで動くペインには、ステータスバーの先頭にそのアカウントの頭文字が青い丸で表示され、バーの下に青い線が引かれます。丸をクリックすると、そのアカウントのプラン、5 時間・週間の上限とリセットまでの時間、直近 7 日間の使用量が表示されます。

ステータスバーをオフにして [チャット表示](/docs/chat-view) で見ると、同じ丸が入力欄の下に表示されます。

## プランとログイン状態

プランは Pro、Max、Ultra として、アカウントメニュー、設定、使用量ページ、メニューバーに表示されます。ログアウトしている、またはログインが 2 日以内に切れるアカウントはそう表示され、横に **再ログイン** が出ます。

## ワークスペースを別のウィンドウへ移す

ウィンドウが 2 つ以上開いていれば(別のアカウントのウィンドウを含む)、ワークスペースやグループを別のウィンドウへ移せます。

- ワークスペースのメニューの **別のウィンドウへ移動**
- グループのメニューの **グループを別のウィンドウへ移動**

移してもターミナルは動き続け、エージェントは起動したアカウントのまま自分のセッションに残ります。そのため、別のアカウントのウィンドウへ移したペインには上の青い丸が付きます。

ワークスペースのオプション、サイドバーの幅、サイドパネルの幅はウィンドウごとに変えられます。メインウィンドウで変えるとすべてのウィンドウに適用され、あるウィンドウで個別に変えると、**メインウィンドウに合わせる** を押すまでそのウィンドウは自分の値を使います。

## 設定 → アカウント

ログインをエージェントごとにまとめて表示します。ログインを開くと次が表示されます。

- そのアカウントのフォルダー(**開く**、**コピー**)
- エージェントをそのフォルダーに向ける環境変数
- ログイン情報の保存場所
- **再ログイン** と **削除**

アカウントを削除するとログアウトし、このコンピューター上のそのアカウントのセッションも削除します。そのアカウントで動いているペインがあるときは削除できません。ベースアカウントは削除できず、**再ログイン** で別のログインに置き換えます。

## 同期

[同期](/docs/settings#同期) もアカウント単位です。ウィンドウはその Claude Code アカウント、なければ Codex アカウントについて専用のリポジトリへ同期し、2 つのアカウントが 1 つのリポジトリを共有することはできません。そのウィンドウにある別のアカウントのセッションは、このリポジトリには同期されません。

## スマートフォンから

[リモートアクセス](/docs/remote-access) のページには、ワークスペースごとにアカウントが表示されます。新しいワークスペースは、開いているウィンドウのアカウントの中から選べます。
