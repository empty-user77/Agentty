---
title: ワークスペース・タブ・ペイン
description: Agentty の構造 — プロジェクトごとのワークスペース、その中のタブ、さらにその中のペイン。
---

Agentty には 3 つの階層があります。**ワークスペース**はプロジェクト、**タブ**はその中の 1 画面、**ペイン**は 1 つのプログラム（シェル、AI エージェント、ファイルエディタ、ブラウザ）です。

## ワークスペース

サイドバー（**⌘B**）の各行がワークスペースで、それぞれ開くフォルダを持ちます。**⌘N** で作成します。

- 行をドラッグして並べ替え、1 つを別の 1 つに重ねると**グループ**になります。グループは折りたためます。グループの見出しを右クリックすると、名前の変更、色、**すべてスリープ**、削除ができます。
- 一覧の上の検索欄は、名前、フォルダ、その中での会話の内容からワークスペースを探します。検索中は一覧が結果表示に変わり、それぞれどこで一致したかを示します — 名前、フォルダ、または検索語に印が付いた会話の 1 行と、それを言ったのが誰か（自分・エージェント・ツール）。**✕** か **Esc** で検索を消すと一覧全体が戻ります。
- 1 つのセッションとしてつないだワークスペースは、つなぎ始めたワークスペースの下にまとまります。そのワークスペースが折りたたんだグループの中にあるときは、ほかのワークスペースは元の場所に表示されたままです。
- 名前をダブルクリックで変更します。
- **⌥⌘↓ / ⌥⌘↑** で移動、**⌘1…⌘9** で直接切り替えます。
- すべてのワークスペースとそのタブ・分割・グループは、再起動後もそのまま戻ります。
- 一覧の見出しの **⚙** で **ワークスペースのオプション** が開きます。カードのレイアウト（詳細・コンパクト、詳細カードに実行中のサブエージェントを出すか — 最大 5 件、残りは「+N」にまとめ、押すとサブエージェントのウィンドウが開く）、グループ化（なし・自分のグループ・プロジェクト別 — リポジトリとそのワークツリーをまとめる。プロジェクトもグループと同じく折りたためる）、並べ替え（手動・最近の活動・名前）、フィルター（スリープ中、`main`/`master` ブランチ、プラグインのワークスペースを隠す）、タブをタイトルバーに置くかを選べます。開いているワークスペースは常に一覧に残ります。

macOS ではタブがウィンドウボタンの横のタイトルバーにあり、その隣にサイドバーボタン（**⌘B**）があります。タイトルバーの空いた所をダブルクリックするとウィンドウが拡大します。タブの行を別にするには、ワークスペースのオプションで **タブをタイトルバーに置く** をオフにします。

ワークスペースの行にはその中のエージェントの状態が出るので、開かなくてもどのプロジェクトが自分を待っているか分かります。

### ワークスペースのメニュー

ワークスペースを右クリックするか **⋯** を押すとメニューが開きます。フォルダを扱う項目は、そのワークスペースで選択中のペインのフォルダを使います。

| 項目 | 内容 |
|---|---|
| 次で開く › | このコンピュータにあるエディタや IDE（VS Code、Cursor、Zed、JetBrains の IDE、Xcode など）または Finder でフォルダを開きます |
| パスをコピー | フォルダのパスをコピーします |
| ワークツリー名をコピー / ブランチ名をコピー | 専用のワークツリーならその名前を、そうでなければブランチ名をコピーします |
| 固定 | ワークスペースをグループの一番上に置きます |
| 未読にする | 開くまでカードに通知マークを表示します |
| 新しいグループ、グループへ移動 ›、グループから外す | ワークスペースをグループに整理します |
| 親ワークツリーを設定… | 選んだワークスペースの下にインデントして表示します。グループを移すと一緒に移ります |
| スリープ | ワークスペースのプログラムをすべて終了し、状態はそのまま残します。カードは月のマーク付きで薄く表示されます。Agentty の起動後まだ開いていないワークスペースも同じように表示されます。開き直すとタブが起動し、エージェントのセッションが続きます |
| ワークツリーを削除 | ワークスペースを閉じ、そのワークツリーとブランチを削除します。未コミットの変更や他にないコミットは残します |

## タブ

**⌘T** でターミナル、**⌥⌘C** で Claude Code、**⌥⌘X** で Codex のタブが開きます。**+** メニューには同じ項目に加えて、選べるモデルと、マシン上で見つかった他のエージェント CLI が並びます。

- **⇧⌘] / ⇧⌘[** または **⌃Tab** でタブを移動、**⌃1…⌃9** で直接切り替えます。
- **⇧⌘W** でタブ、**⌘W** でペインを閉じます。
- タブ領域の空白をダブルクリックすると新しいタブが開きます。
- タブを右クリックして **後で作業する** を選ぶと、タブを脇に置きます。中で動いていたものは止まり、スタートページのタブの横の **TODO** ボタンに並びます。そこでクリックすると再開し、エージェントは続きから作業します。

新しいタブはワークスペースのフォルダで始まります。**設定 → 一般**で毎回フォルダを尋ねるようにもできます。

## ペイン

**⌘D** で右に、**⇧⌘D** で下に分割します。**⌘] / ⌘[** でペインを移動し、境界をドラッグしてサイズを変えます。

エージェントのペインには、モデル、コンテキストウィンドウ、利用上限、ブランチ、フォルダ、そしてそのペインで動いているローカルサーバーのポートを示すステータスバーがあります。位置（ターミナルの上か下か）と表示項目は**設定 → 外観**で決めます。

そのバー（状態の部分、またはドラッグに使うアイコン）をダブルクリックすると、そのペインがタブ全体に広がります。もう一度ダブルクリックすると、元の分割に戻ります。

ペインのヘッダーにはフォルダ名だけが表示されます。フルパスはステータスバーにあります。

## サイドパネル

ターミナルの横に並ぶパネルは、いずれも端をドラッグしてサイズを変えられます。

| パネル | ショートカット |
|---|---|
| ファイルとワークツリー | ⌥⌘B |
| アプリ内ブラウザ | ⇧⌘B |
| Docker | ステータスバーの 🐳 |
| プラグインパネル | タブ領域のボタン |

## ミニモード

**⌃⌘M** はウィンドウを画面端の小さな常時表示パネルに畳みます。作業を終えたエージェントが吹き出しで現れ、クリックすると元のウィンドウに戻ります。

macOS ではメニューバーのアイコンがエージェントの稼働中に動き、一覧を表示し、ウィンドウを閉じても Agentty を動かし続けます。

メニューバーのポップオーバーには、ミニモードボタンの横にコンピュータの **CPU** と **RAM** の負荷も表示されます。ポップオーバーを開いているあいだ 2 秒ごとに更新され、85% 以上になるとオレンジ色になります。
