---
title: チャット表示
description: CLI を動かしたまま、エージェントのペインをデスクトップアプリのようなチャットで表示します。
---

チャット表示は Claude Code、Codex、Antigravity、Gemini CLI のペインをデスクトップのチャットアプリのように描きます。CLI はペインの中で動き続けるので、チャットとターミナルを切り替えてもセッションと内容はそのままです。

## オンにする

- ペインのタイトルバーの吹き出しをクリックするか、**表示 → チャット表示**を選ぶか、**⇧⌘J** を押します。どれも手前のペインだけを切り替えます。
- **設定 → AI 設定 → エージェントの開き方**で、新しいエージェントが始まるモード（ターミナルまたはチャット）を選びます。オンボーディングでも選べます。前のエージェントが終了したあと同じペインで起動し直したエージェントも、このモードで開きます。

## 会話

- 返信は整形され、コードブロック・コマンド・ファイルの読み込みはエディタの構文色で表示されます。
- ツールの手順は下に開くカードにまとまり、ToDo リストはチェックリストとして表示されます。
- 番号付きの承認や質問はチャットから答えられます。エージェントが独自のメニューや設定画面を出している間は、ターミナルが前に出ます。
- 段落やコードをまたいでテキストを選択し、**⌘C** でコピーできます。選択の上に出るバー（または右クリック）から、引用して返信したり、その内容についてサイドチャットを始めたりできます。
- **+** またはドラッグ＆ドロップでファイルを添付すると、サムネイルとチップで表示されます。
- **停止**は実行中のターンを中断します。停止後にエージェントが入力欄に戻したメッセージは、作成欄に戻ります。

## スタート画面

新しいセッションでは、エージェントとモデル、フォルダ（ファイルパネルを開く）、ブランチ（Git を開く）、送信せずに作成欄を埋めるいくつかの始め方、そしてこのフォルダでのエージェントの過去のセッションが表示され、クリックで再開できます。
