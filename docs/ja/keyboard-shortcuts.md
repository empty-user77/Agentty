全一覧は**設定 → キーボードショートカット**にもあり、お使いのプラットフォームの表記で表示されます。

## ショートカットを変更する

**設定 → キーボードショートカット**でショートカットをクリックし、使いたいキーを押します。ほかの操作がすでに使っているキーなら、その操作の名前が表示され、保存するとその操作からそのキーがなくなります。**ショートカットなし**はキーをほかに割り当てずに空けるだけで、**デフォルトに戻す**（または変更したショートカットの横の矢印）はプリセットのキーに戻します。

**プリセット**は基本にするショートカットを選びます。**Agentty**（下の表）と、Visual Studio Code のキーに合わせる **VS Code** があります。自分で変更したショートカットはどちらのプリセットでも残ります。**すべてデフォルトに戻す**は、確認のうえ Agentty プリセットに戻し、変更をすべて消します。

| VS Code プリセット | macOS |
|---|---|
| 新しいターミナル | ⌃⇧`（⌘T も有効） |
| 右 / 下に分割 | ⌘\ / ⌥⌘\ |
| 次 / 前のペイン | ⌥⌘→ / ⌥⌘← |
| ファイル | ⇧⌘E |
| ワークスペース | ⌥⌘B |
| Git | ⌃⇧G |

コピーや貼り付けなどの文字編集、⌘1…⌘9、⌃1…⌃9、フォントサイズ、検索、ファイルエディタのショートカットはそのままで、これらのキーをほかの操作に割り当てることはできません。シェルが使う Ctrl+文字も同じです。変更はシステムごとに保存されます（`settings.json` の `shortcuts`）。Mac で押すキーと Windows・Linux で押すキーは違うためです。

## Windows と Linux

ショートカットは macOS 基準で定義し、変換しています。Ctrl+文字が必ずシェルに届くようにするためです。

| macOS | Windows / Linux |
|---|---|
| ⌘X | Ctrl+Shift+X |
| ⇧⌘X | Ctrl+Alt+Shift+X |
| ⌥⌘X | Ctrl+Alt+X |
| ⌘1…⌘9 | Alt+1…Alt+9 |
| ⌘= / ⌘- / ⌘0 | Ctrl+= / Ctrl+- / Ctrl+0 |
| ⌘-クリック | Ctrl-クリック |

テキスト入力欄、ファイルエディタとその表ビュー、チャットの文章、diff は通常の Ctrl を使います（Ctrl+C / V / X / A / Z、Ctrl+S、Ctrl+Y、単語単位の Ctrl+←/→、Ctrl+Home / End）。

### コピーと貼り付け

| 場所 | コピー | 貼り付け |
|---|---|---|
| ターミナル（macOS） | ⌘C | ⌘V |
| ターミナル（Windows） | Ctrl+Shift+C、または文字を選択した状態で Ctrl+C | Ctrl+Shift+V または Ctrl+V |
| ターミナル（Linux） | Ctrl+Shift+C | Ctrl+Shift+V |
| テキスト入力欄、ファイルエディタ、表 | ⌘C / Ctrl+C | ⌘V / Ctrl+V |
| チャットの文章 | ⌘C / Ctrl+C（Ctrl+Shift+C も可） | ⌘V / Ctrl+V: メッセージ欄に入ります |
| diff | ⌘C / Ctrl+C（Ctrl+Shift+C も可） | |

- Windows と Linux では、どこでも **Ctrl+Insert** でコピー、**Shift+Insert** で貼り付けできます。テキスト入力欄はターミナルの Ctrl+Shift+C / Ctrl+Shift+V も受け付けます。
- ターミナル、ファイルエディタの文章、diff を**右クリック**すると、コピー、ペースト、すべてを選択のうち、その場所で使えるものが出ます。選択できない文章（エラー、ログの行、パス、コミットメッセージ、クエリ結果）は右クリック → **コピー**でコピーします。
- チャットの文章で **⌘A / Ctrl+A** を押すと、これまでに表示された文章がすべて選択されます。マウスを自分で読み取るプログラム（vim、tmux）では右ボタンと中ボタンはそのプログラムに渡り、**Shift** を押しながらクリックすると Agentty のメニューと貼り付けが使えます。
- **Linux**: ポインタで選択した文章は、ターミナル、テキスト入力欄、ファイルエディタで中クリックして貼り付けます。
- コピーしたファイルや画像をターミナルに貼り付けるとパスが入り、チャットのメッセージ欄に貼り付けると添付されます。

## US 以外のキーボード配列

ショートカットは使っているキーボード配列に従い、配列を切り替えると一緒に変わります。

- **macOS のショートカット**: Option を押さないと打てないキーのショートカットは、macOS 自身のメニューが移す位置に移ります。ドイツ語配列では ⌘[ / ⌘] が ⌘Ö / ⌘Ä に、⇧⌘[ / ⇧⌘] が ⇧⌘Ö / ⇧⌘Ä になります。メニューと **設定 → キーボードショートカット** には配列に合ったキーが表示されます。
- **ターミナルの Option**（macOS）: **Option キーを Meta として使う**（設定 → ターミナル）がオンでも、配列が Option で必要な文字を打つキーではその文字が入力されます。`[ ] { } @ | \ ~` などコードの文字（ポルトガル語の ⌥8 は `[`、ドイツ語の ⌥L は `@`）と、その言語の文字（ポーランド語 Pro の ⌥A は `ą`、トルコ語 Q の ⌥S は `ş`）です。それ以外の Option キーは Meta で、US 配列ではすべての Option キーが Meta のままです。
- **Windows の AltGr**: AltGr でそのキーの文字を打つ配列（クロアチア語の AltGr+B は `{`）では、同じキーの Ctrl+Alt ショートカットを外し、文字が入力されるようにします。

ファイルエディタにフォーカスがあるとき、⌘D、⌘] / ⌘[、⇧⌘↩、⌥⌘↑ / ⌥⌘↓ は VS Code と同じくテキストに使われます。ペインの分割・移動・拡大やワークスペースの切り替えにはターミナルをクリックしてから使います。

質問ダイアログ（新しい worktree か同じ場所か、再開など）では、**↩** で青い回答を選び、**Esc** で閉じます。赤い回答が ↩ で選ばれることはありません。開いている右クリックメニューも **Esc** で閉じます。

## ターミナルとエディタ

| 操作 | ショートカット |
|---|---|
| スクロールバック内を検索 | ⌘F |
| フォントの拡大 / 縮小 / リセット | ⌘= / ⌘- / ⌘0 |
| コピー / 貼り付け / 全選択 / クリア | ⌘C / ⌘V / ⌘A / ⌘K |
| Git ページ: コミット / push / fetch / 再読み込み | ⌘↩ / ⌘P / ⇧⌘T / ⌘R |
| ファイルエディタ: ファイル内を検索 / 次へ / 前へ | ⌘F / ↩ または ⌘G / ⇧↩ |
| ファイルエディタ: 保存 / 整形 / ファイルを閉じる | ⌘S / ⇧⌥F / ⌘W |
| ファイルエディタ: マークダウンプレビューの切り替え（macOS） | ⇧⌘V |
| ファイルエディタ: マークダウンプレビューを横に表示の切り替え（macOS） | ⌥⌘V |

タイトルバーをダブルクリックするとウィンドウが拡大し、タブ領域の空白をダブルクリックすると新しいタブが開きます。

## 自分のコマンド

コマンドパレット（**⇧⌘P**）には、プロジェクトの `agentty.json` や `~/.agentty/commands.json` で定義した項目も並びます。予約語も使えます。ターミナルで `claude yolo` と入力すると `claude --dangerously-skip-permissions` に展開されます。
