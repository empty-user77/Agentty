全一覧は**設定 → キーボードショートカット**にもあり、お使いのプラットフォームの表記で表示されます。

## Windows と Linux

ショートカットは macOS 基準で定義し、変換しています。Ctrl+文字が必ずシェルに届くようにするためです。

| macOS | Windows / Linux |
|---|---|
| ⌘X | Ctrl+Shift+X |
| ⇧⌘X | Ctrl+Alt+Shift+X |
| ⌥⌘X | Ctrl+Alt+X |
| ⌘1…⌘9 | Alt+1…Alt+9 |
| ⌘= / ⌘- / ⌘0 | Ctrl+= / Ctrl+- / Ctrl+0 |
| ⌘-クリック | Ctrl-クリック |

テキスト入力欄とファイルエディタは通常の Ctrl を使います（Ctrl+C / V / X / A / Z、Ctrl+S、Ctrl+Y、単語単位の Ctrl+←/→、Ctrl+Home / End）。

## タブとペイン

| 操作 | ショートカット |
|---|---|
| 新しいターミナル / Claude Code / Codex タブ | ⌘T / ⌥⌘C / ⌥⌘X |
| 新しいワークスペース | ⌘N |
| 右 / 下に分割 | ⌘D / ⇧⌘D |
| 次 / 前のペイン | ⌘] / ⌘[ |
| 次 / 前のタブ | ⇧⌘] / ⇧⌘[、⌃Tab |
| 次 / 前のワークスペース | ⌥⌘↓ / ⌥⌘↑ |
| ペイン / タブを閉じる | ⌘W / ⇧⌘W |
| ワークスペース / タブ 1–9 へ | ⌘1…⌘9 / ⌃1…⌃9 |

## パネルとページ

| 操作 | ショートカット |
|---|---|
| サイドバーの表示切り替え | ⌘B |
| ワークスペース / ローカルセッション | ⇧⌘E / ⇧⌘S |
| Git / 拡張機能 | ⇧⌘G / ⇧⌘X |
| Session Flow / モニタリング / 設定 | ⇧⌘F / ⌥⌘U / ⌘, |
| アプリ内ブラウザ / ファイルパネル | ⇧⌘B / ⌥⌘B |
| コマンドパレット / 未読へ移動 | ⇧⌘P / ⇧⌘U |
| ローカルセッションの検索 | ⇧⌘O |
| ミニモード | ⌃⌘M |

## ターミナルとエディタ

| 操作 | ショートカット |
|---|---|
| スクロールバック内を検索 | ⌘F |
| フォントの拡大 / 縮小 / リセット | ⌘= / ⌘- / ⌘0 |
| コピー / 貼り付け / 全選択 / クリア | ⌘C / ⌘V / ⌘A / ⌘K |
| Git ページ: コミット / push / fetch / 再読み込み | ⌘↩ / ⌘P / ⇧⌘T / ⌘R |
| ファイルエディタ: 保存 / 整形 / ファイルを閉じる | ⌘S / ⇧⌥F / ⌘W |

タイトルバーをダブルクリックするとウィンドウが拡大し、タブ領域の空白をダブルクリックすると新しいタブが開きます。

## 自分のコマンド

コマンドパレット（**⇧⌘P**）には、プロジェクトの `agentty.json` や `~/.agentty/commands.json` で定義した項目も並びます。予約語も使えます。ターミナルで `claude yolo` と入力すると `claude --dangerously-skip-permissions` に展開されます。
