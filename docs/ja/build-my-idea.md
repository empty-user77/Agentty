---
title: アイデアから作る
description: 数行の説明と添付を、エージェントがすぐ作り始められるプロジェクトフォルダに変える。
---

「アイデアから作る」は、まだプロジェクトが存在しない段階のための機能です。作りたいものを短いやり取りで説明し、手元の資料を添えると、Agentty がエージェントの出発点になるフォルダを用意します。

スタートページ、**+** メニュー、コマンドパレットから開けます。提案そのものが不要なら**設定 → 一般**でオフにします。

## 作られるもの

新しいフォルダ（既定では `~/AgenttyProjects` の下）に次が入ります。

| パス | 内容 |
|---|---|
| `docs/idea/IDEA.md` | 書いた内容を順に |
| `docs/idea/attachments/` | 添付したファイルの複製 |
| `docs/idea/BUILD_GUIDE.md` | 進め方：まず計画し、作り、その場で確認する |
| `.claude/settings.json` | コマンドごとに尋ねずにパッケージを入れ、開発サーバーを動かせる権限 |

それ以外は空のままです。そうすることで `create-next-app` や `create vite` などのプロジェクト生成ツールがそのフォルダをそのまま受け入れます。

添付は 20 個まで、1 つあたり 20MB までです。

## その後

Agentty がそのフォルダでエージェントを開き、最初のプロンプトまで用意します。出来上がっていく様子は[アプリ内ブラウザ](/docs/in-app-browser)で確認できます。**開発方法**で誰が作るかを選びます。

- **エージェントチーム**（Claude Code か Codex が作り、設定でオーケストレーションがオンのときの既定）: エージェントが[オーケストレーション](/docs/session-flow)を率います。チームはアイデアからコードまで一段ずつ進み、各段階が次の段階のための文書を `docs/design/` に残します。
  1. アイデア分析: 課題、ユーザー、代替手段、リスク、置いた仮定
  2. アイデア導出: 価値、機能の優先順位、デモの範囲
  3. 企画（PRD）: 受け入れ条件付きのユーザーストーリー、画面とフロー
  4. HLD（上位設計）: スタック、アーキテクチャ、データモデル、ページ
  5. LLD（詳細設計）: ファイル、コンポーネントとインターフェース、開発単位に分けた作業
  6. エージェント構成: プロジェクトのハーネスと、開発単位ごとの開発者
  7. 開発: まず基盤、開発単位は並行して、最後にブラウザでの品質確認と PRD に照らしたレビュー

  一つの段階の中では複数のエージェントが並行して働き（例: 分析段階のユーザー・市場・実現可能性）、段階同士は順に引き継ぎます。オーケストレーション画面にウェーブとして表示されます。
- **エージェント 1 つ**: エージェントが一人で計画して作ります。

公開する準備ができたら [Launch](/docs/launch) が配信します。
