## 설계

| 결정 | 내용 · 이유 |
|---|---|
| 실행 모델 | 플러그인 = 폴더(`agentty-plugin.json` + 프로그램). 별도 프로세스로 실행하고 stdin/stdout JSON-RPC 2.0(한 줄에 한 메시지)로 통신. VS Code/LSP와 같은 방식이라 언어 제약이 없고, 앱과 격리되어 플러그인이 죽어도 Agentty는 영향 없음 |
| UI 영역 | 플러그인은 직접 그리지 않고 **선언형 UI 트리**(column/row/section/text/button/input/list/choice/toggle/badge/spinner/divider)를 보냄 → Agentty가 네이티브로 렌더링. 터미널 오른쪽 360px 패널 + 탭바 버튼(배지) + 에이전트 상태바/분할창 헤더 버튼 + 명령 팔레트 |
| 권한 | `prompt.inject` · `terminal.write` · `session.read` · `workspace.read`. 매니페스트에 선언한 권한만 호출 가능, 스토어 카드에 표시 |
| 프롬프트 주입 | `target: ask`(기본)면 "보낼 위치 선택" 다이얼로그: 새 워크스페이스(폴더 변경 가능) / 현재 워크스페이스 새 탭 / 열린 워크스페이스(대기 중 에이전트가 있으면 거기로, 없으면 새 에이전트 탭) × Claude Code / Codex / 터미널. 터미널에는 입력만 하고 Enter는 누르지 않음. 6만 바이트 초과는 `~/.agentty/prompts/`(0600) 파일로 넘김 |
| 외부 앱 연동 | `agentty://` URL 스킴 등록(Info.plist). `agentty://plugin/<id>/<path>?…` → 플러그인 `onUrl`, `agentty://prompt?…` → 다이얼로그, `agentty://plugins/<id>` → 스토어. 설치 안 된 기본 플러그인이면 "설치 후 계속" 배너 → 설치 뒤 링크 자동 재실행 |
| 링크 보안 | 링크는 웹페이지에서도 열 수 있으므로: 링크 수신 후 사용자가 그 플러그인을 조작하기 전(최대 60초)에는 프롬프트 주입을 강제로 다이얼로그로 보내고 `terminal/send`는 거부. `prompt` 링크의 `file=`은 절대경로 .md/.txt, 1MB 이하만 |
| 스토어 | 설치됨(사용/중지, 패널 열기, 재시작, 업데이트, 로그, Finder, Claude Code로 수정, 두 번 눌러 제거) · 설치 가능(기본 제공, 앱 감지 시 "추천") · 직접 만들기(AI로 만들기, Git URL 설치, 폴더 설치, 개발용 폴더 연결) |
| AI로 만들기 | 이름+기능 입력 → 템플릿(SDK, 타입, 가이드, `CLAUDE.md`/`AGENTS.md`=AI 지침) 생성 → 그 폴더에서 Claude Code 새 워크스페이스를 프롬프트와 함께 시작 |
| 기본 제공 플러그인 | 바이너리에 `include_str!`로 내장. Agentty가 더 새 버전을 포함하면 시작 시 자동 업데이트(사용 여부 유지) |

## Cosmica 플러그인 (`plugins/cosmica`)

- `~/.cosmica/config.json`에서 **`notes.path`와 서버 포트만** 읽음(토큰/키는 읽지 않음, 테스트로 확인)
- 패널: 연결 상태(실행 중/꺼짐/없음) · 노트 검색 · 최근 노트 목록(행 클릭 또는 전송 버튼 = 이어서 작업하기, 입력 버튼 = 현재 터미널에 넣기) · 세션 저장 버튼 · 저장 폴더 설정(기본 `Agentty`)
- **AI 요약 저장**(에이전트 상태바 노트 아이콘 / 패널 / 팔레트): 대기 중인 에이전트에게 정해진 경로(`Note/Agentty/YYYYMMDD-HHMMSS-xxxx.md`, Cosmica 파일명 규칙)와 형식(frontmatter `source: agentty`, 목표/한 일/변경 파일/결정/다음 할 일)으로 요약 파일을 쓰도록 요청 → 파일이 생기면 Cosmica API로 목록 갱신 후 알림. 작업 중/승인 대기 에이전트는 방해하지 않음
- **대화 기록 저장**(AI 없이): `session/get`으로 대화를 가져와 노트 작성. Cosmica 실행 중이면 로컬 API(`POST /api/notes`)로 저장해 즉시 색인·동기화, 꺼져 있으면 파일로 저장
- `agentty://plugin/cosmica/continue?path=…&title=…`: 노트가 Cosmica 노트 폴더 안의 .md인지 realpath로 확인 후 "보낼 위치 선택" 다이얼로그로 주입. 잠긴 노트는 거부
- UI 문자열 en/ko/ja/zh

## Cosmica 앱 (`~/CosmicaProject/cosmica-desktop`, 커밋 안 함)

- Electron main: Agentty 설치 감지(`agentty://` 핸들러 또는 `/Applications/Agentty.app`), 노트 경로 검증 후 `shell.openExternal('agentty://plugin/cosmica/continue?…')`
- preload: `isAgenttyAvailable()`, `continueInAgentty({ path, title })`
- 사이드바 노트 우클릭 메뉴와 노트 에디터 더보기 메뉴에 "Agentty에서 이어서 작업하기"(설치된 경우에만, 저장 대기 중이면 먼저 저장)
- ko/en 문자열, 터미널 아이콘

## 남은 것 / 제약

- 스토어 카탈로그는 앱에 내장된 목록만(현재 Cosmica). 원격 레지스트리는 추후
- 번들(.app)에서만 `agentty://` 스킴이 등록됨 — `cargo run` 개발 빌드는 디버그 명령 `agentty-link`로 테스트
- Node.js 런타임 필요(없으면 플러그인 카드에 설치 안내 오류 표시)
- 단일 셸 창에는 상태바가 없어 `when: shell` 버튼은 분할창 헤더에만 표시
