title: 실행 구성
description: 프로젝트의 개발 서버나 앱을 버튼 하나로 실행하고, 그 출력은 터미널 옆 실행 로그에서 봅니다.
---

Agentty는 IDE처럼 프로젝트에서 실행할 수 있는 것을 찾아서 페인 헤더에 **실행** 버튼을 둡니다(탭에 페인이 하나뿐이면 탭 줄에). 실행은 터미널에 입력하지 않습니다. 출력은 터미널 아래에 붙는 실행 로그로 갑니다.

## 찾아내는 것

| 프로젝트 | 실행 구성 |
|---|---|
| Node (`package.json`) | 루트 패키지의 스크립트 전부. 하위 패키지에서는 무언가를 시작하는 스크립트(`dev`, `start`, `serve`, `preview`, `watch`, `storybook`). 패키지 매니저는 `packageManager`나 잠금 파일로 정합니다: npm, pnpm, yarn, bun |
| Spring Boot (Gradle 또는 Maven) | 애플리케이션마다 하나. wrapper가 있으면 wrapper로 실행하고, 멀티 모듈 빌드도 포함합니다 |
| 그 밖의 것 | **명령 추가…**로 직접 추가한 명령(이름은 선택). 그 프로젝트에 저장됩니다 |

찾을 때는 파일만 읽고 빌드 도구는 실행하지 않습니다. 프로젝트 폴더와 그 아래 두 단계(`web/`, `apps/admin/`)까지 보고, 의존성 폴더와 빌드 결과 폴더는 건너뜁니다.

## 실행하기

- **실행**을 누르면 구성이 시작됩니다. 실행 중에는 버튼이 **중지**와 **재시작**으로 바뀝니다.
- 상태 바에 **실행**(또는 실행 중인 개수)이 표시됩니다. 누르면 구성별 상태와 포트, 그리고 프로젝트에서 포트를 연 프로세스가 모두 나오고, 각각 중지하거나 브라우저에서 열 수 있습니다. Windows에서는 포트를 표시하지 않습니다.
- 포트가 이미 쓰이고 있어서 실행이 실패하면, 로그에 그 포트를 쓰는 프로세스가 표시되고 **종료하고 다시 실행**을 제안합니다. 단, 그 프로세스가 이 프로젝트의 것일 때만입니다. 다른 프로세스는 확실할 때 열린 포트 목록에서 직접 종료하세요.

## 실행 로그

패널 하나에 실행마다 탭이 하나씩 생깁니다. 할 수 있는 것:

- 단어나 정규식으로 줄 검색(대소문자 구분 선택 가능)
- 특정 레벨 이상의 줄만 보기(레벨별 줄 수 표시)
- 긴 줄 줄바꿈, 최신 줄 따라가기 또는 자유롭게 위로 스크롤
- 주소를 Cmd-클릭(Ctrl-클릭)해서 열기

색은 그대로 유지되고, 진행 표시 줄은 한 줄로 합쳐집니다. 패널 위쪽 가장자리를 끌어 높이를 바꿀 수 있고, 높이는 저장됩니다. 로그를 숨겨도 실행은 계속됩니다.

## Agentty를 종료하면

실행도 함께 끝납니다. 종료하면 실행이 중지되고, 비정상 종료로 남은 실행은 다음에 시작할 때 중지됩니다.
