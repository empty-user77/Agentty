**⌥⌘U**가 모니터링을 엽니다. 여기 있는 모든 수치는 이용자의 컴퓨터에서 계산되며, 어디에도 업로드되지 않습니다.

## AI 사용량

비용, 호출 수, 캐시 적중률, 토큰을 모델·프로젝트·도구별로 보여줍니다. 수치는 에이전트 CLI가 이미 디스크에 기록해 둔 대화 파일에서 나옵니다.

집계는 줄을 더하는 것만큼 단순하지 않습니다. Claude Code는 콘텐츠 블록마다 JSONL 한 줄을 쓰기 때문에 하나의 API 응답이 같은 message id로 여러 번 나타나며, 이를 그 id로 중복 제거합니다. Codex는 응답마다 사용량 레코드 하나를 response id로 기록합니다. Agentty는 각 형식을 따라가므로 한 응답이 한 번만 계산됩니다.

Claude 모델 가격은 내장되어 있습니다. Codex가 쓰는 모델처럼 그 외의 모델은 `~/.agentty/pricing.json`에 가격을 적으면 함께 계산됩니다.

```json
{
  "some-model": { "input": 1.25, "output": 10.0, "cacheRead": 0.125 }
}
```

가격은 100만 토큰당 USD입니다. `cacheRead`, `cacheWrite`, `cacheWrite1h`는 선택이며 각각 입력 단가의 10%, 125%, 200%가 기본값입니다.

> [!NOTE]
> 로컬 파일로 계산한 참고용 추정치입니다. 실제 금액은 제공자의 청구서입니다.

## 프로세스

지금 컴퓨터에서 실행 중인 AI 프로세스와, 무엇이 그것을 시작했는지 보여줍니다. 멈춘 줄 알았는데 토큰이 계속 소모될 때 유용합니다.

## 프록시

각 탭이 무엇과 통신하는지 보여주는 캡처 프록시입니다. 캡처를 켜고, 탭을 열고, 엔드포인트로 필터링하면 됩니다.

- **캡처가 켜진 상태에서 연 탭**은 이용자의 컴퓨터에서 동작하는 프록시를 경유합니다.
- HTTPS는 암호화된 채로 유지됩니다. 호스트, 포트, 전송량, 소요 시간만 기록되며 인증서를 설치하지 않고 아무것도 복호화하지 않습니다.
- 암호화되지 않은 HTTP는 메서드, 경로, 응답 상태만 기록하고 헤더나 본문은 기록하지 않습니다.
- 기록은 메모리에만 있고, 개수가 제한되며, 디스크에 쓰이지 않고, Agentty를 종료하면 사라집니다.

캡처를 끄면 기록이 멈춥니다. 이미 프록시를 받은 탭은 네트워크가 끊기지 않도록 계속 그것을 사용합니다.

## 워크트리 관리

이 컴퓨터의 모든 git 워크트리를 프로젝트별로 보여줍니다. 브랜치, 마지막 작업 시간(마지막 커밋이나 가장 최근의 미커밋 변경), 커밋 안 된 파일, 기본 브랜치에 아직 없는 커밋, PR 상태(열림·병합됨·닫힘 — 로그인된 GitHub CLI로 읽습니다), 용량이 나옵니다.

홈 폴더 아래 폴더, Agentty 워크트리 폴더, 지금 열려 있는 폴더에서 찾습니다. 프로젝트 폴더 하나뿐인 프로젝트는 목록에서 뺍니다.

여러 개를 체크하고 **선택 삭제**를 누르세요. **정리 가능 모두 선택**은 커밋 안 된 변경이 없고 커밋이 이미 병합된 워크트리를 모두 고릅니다. 삭제 전에 먼저 묻습니다.

- **브랜치도 함께 삭제**는 잃을 게 없는 브랜치만 지웁니다. git의 자체 검사를 통과하거나, 브랜치의 마지막 커밋 그대로 병합된 PR이 있는 경우입니다(스쿼시 병합 포함). 나머지 브랜치는 남습니다.
- 커밋 안 된 변경이 있는 워크트리는 따로 체크하지 않으면 건너뜁니다. 체크하면 그 변경은 사라집니다.
- 프로젝트 폴더 자체와 탭에서 작업 중인 워크트리는 선택할 수 없습니다.

## 디스크 관리

디스크가 얼마나 찼는지(사용 중·정리 가능·여유)와 홈 폴더에서 용량을 많이 쓰는 폴더를 보여줍니다. 폴더를 펼치면 그 안의 큰 폴더가 나옵니다.

정리 대상은 스스로 다시 만들어지는 것뿐입니다.

- **프로젝트 빌드 결과** — 프로젝트마다 **빌드 정크파일 제거**(Cargo `target`, `.next`, Gradle `build`, SwiftPM `.build` 등)와 **캐시 제거**(`.turbo`, `.parcel-cache`, `node_modules/.cache`, pytest·mypy·Ruff 캐시 등). 해당 도구의 프로젝트 파일이 옆에 있을 때만 대상이 되고, Cargo `target`은 Cargo가 넣어 두는 태그도 있어야 합니다.
- **캐시 파일** — 개발 도구 자체 캐시: npm, Yarn, Bun, pip, uv, Go, Cargo 레지스트리, Gradle, Homebrew, CocoaPods, JetBrains, Xcode DerivedData.
- **기타** — 휴지통과 로그 파일.

`node_modules`나 `~/.m2` 같은 의존성, 프로젝트 실행에 필요한 것은 정리 대상에 나오지 않습니다. 지우기 전에 확인을 받고, 지우기 직전에 한 번 더 검사하며, 링크는 따라가지 않습니다. 다음 빌드나 설치가 조금 더 걸릴 뿐입니다.
