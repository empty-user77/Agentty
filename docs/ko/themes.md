전부 **설정 → 모양**에 있습니다.

## 테마

Agentty에는 여러 테마가 기본 포함되어 있습니다. **iTerm2 색 프리셋**도 그대로 쓸 수 있습니다. **.itermcolors 가져오기…**를 고르거나 `.itermcolors` 파일을 `~/.agentty/themes/`에 넣으면 목록에 나타납니다. [iterm2colorschemes.com](https://iterm2colorschemes.com/)에 수천 개가 있습니다.

가져온 테마는 확장자를 뺀 파일 이름으로 참조됩니다.

## 글꼴

JetBrains Mono와 그 Nerd Font 패치 버전이 기본으로 들어 있습니다. 그래서 아무것도 설치하지 않아도 Powerlevel10k와 Starship 프롬프트가 제대로 보입니다. 시스템에 설치된 다른 고정폭 글꼴을 써도 됩니다.

글꼴 크기, 줄 높이, 여백, 자간(셀마다 더하는 너비 0–8pt), 굵은 글씨도 같은 화면에서 정합니다. **⌘= / ⌘- / ⌘0**은 현재 페인의 글꼴을 확대·축소·초기화합니다.

## 직접 고른 색

배경·글자·커서·선택 영역은 테마를 그대로 둔 채 하나씩 바꿀 수 있습니다. 나머지 색은 테마 그대로 남고, **테마 기본값**을 고르면 원래 색으로 돌아갑니다. 바꾼 내용은 설정 아래 미리보기에 바로 보입니다.

## 커서와 스크롤백

커서 모양(블록, 막대, 밑줄)과 깜박임, 터미널마다 남겨 둘 스크롤백 줄 수를 정합니다.

## 에이전트 상태 바

AI 페인 위에 어떤 항목을 어떤 순서로 둘지 정합니다. 항목은 모델, 컨텍스트 창, 사용량, 상태, 경과 시간, 링크, 포트, 워크트리, 브랜치, 폴더입니다. 모델·컨텍스트·상태·브랜치는 숨길 수 없습니다.

상태 바를 터미널 위에 둘지 아래에 둘지도 같은 화면에서 정합니다.
