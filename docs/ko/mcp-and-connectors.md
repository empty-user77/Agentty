**⇧⌘X**가 확장을 엽니다. Claude Code와 Codex의 스킬, 서브에이전트, 명령, 플러그인, MCP 서버가 한 목록에 있고, 각 서버의 연결 상태가 실시간으로 표시됩니다.

여기서 공식 MCP 서버를 한 번의 클릭으로 추가하거나, 어느 것이든 활성 에이전트에 삽입하고 실행할 수 있습니다. 에이전트 페인의 상태 바에는 그 에이전트가 실제로 가진 스킬·서브에이전트·MCP 서버가 표시됩니다.

## MCP 서버

Agentty는 서버를 중계하지 않고 에이전트 CLI에 등록합니다. 서버가 프로젝트나 에이전트 자신의 설정에 추가되고, 에이전트가 그 서버와 직접 통신합니다.

서버의 URL이나 인자에 비밀처럼 보이는 값이 있으면 가려서 표시합니다.

## API 커넥터

커넥터는 임의의 HTTP API를 에이전트가 쓸 수 있는 MCP 서버로 만들어 줍니다. 엔드포인트를 한 번 기술하면(메서드, 경로, 파라미터의 의미) 에이전트가 호출할 수 있는 도구를 갖게 됩니다.

- 정의는 `~/.agentty/connectors.json`에 있습니다.
- **비밀 값은 그 파일에 들어가지 않습니다.** 운영체제의 자격 증명 저장소에 보관됩니다. macOS는 키체인, Windows는 자격 증명 관리자, Linux는 Secret Service이며, 그런 서비스가 없으면 이용자 계정만 읽을 수 있는 전용 파일을 씁니다.
- 비밀 값이 포함될 수 있는 항목은 표시되는 모든 자리에서 가려집니다.

## 에이전트 로그인

**설정 → 계정**은 새 에이전트 탭이 로그인하는 방식을 정합니다. CLI 자체 로그인을 쓸 수 없는 환경을 위한 것입니다.

| 에이전트 | 방식 |
|---|---|
| Claude Code | API 키, 게이트웨이 토큰, `claude setup-token` OAuth 토큰, Amazon Bedrock, Google Vertex AI |
| Codex | API 키, 또는 가져온 `auth.json` |

방식과 비밀이 아닌 값은 `~/.agentty/agent-auth.json`에 저장되고, 키와 토큰은 자격 증명 저장소로 갑니다. **테스트**는 키를 제공자의 엔드포인트로 확인합니다.

자격 증명은 에이전트 프로세스에만 전달됩니다. 에이전트가 종료된 뒤 남는 셸에는 남지 않으며, 다른 로그인 방식에 속한 변수는 에이전트에서 제거되므로 셸 프로필에 export해 둔 키가 선택한 방식을 덮어쓸 수 없습니다.

저장된 방식을 쓸 수 없으면(예: 자격 증명 저장소에서 키가 사라진 경우) 페인이 그 사실을 알리고 에이전트는 자체 로그인으로 넘어갑니다.

## 에이전트 하네스

프로젝트가 하네스를 선언하고 있으면, 그 폴더에 들어갈 때 **하네스로 시작**이 제안됩니다. `/implement` 같은 진입점을 고르고 티켓 키나 링크를 붙여 넣으면 에이전트가 그것으로 시작합니다.

다음 중 하나가 있으면 하네스로 인정됩니다. `.harness` 파일, `harness.json` / `.yaml` / `HARNESS.md`, `harness` 또는 `harness-*`라는 이름의 프로젝트 스킬, `agentty.json`의 `harness` 목록, 그리고 **설정 → 프로젝트**에 추가한 패턴입니다.

프로젝트는 자체 진입점을 지정할 수 있습니다.

```json
{
  "harness": [
    { "label": "Start a ticket", "command": "/implement", "input": "Ticket key or URL" },
    { "label": "Fix a bug", "prompt": "Reproduce and fix {input}", "agent": "codex" }
  ]
}
```

`command`는 입력이 뒤에 붙고, `prompt`에서는 `{input}`이 입력으로 치환됩니다.
