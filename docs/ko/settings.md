**⌘,**가 설정을 엽니다. 변경은 즉시 적용되고 `~/.agentty/settings.json`에 저장됩니다.

## 일반

언어(English, 한국어, 日本語, 中文)와, 매일 마주치는 동작들입니다.

| 설정 | 하는 일 |
|---|---|
| 아이디어로 시작하기 | 시작 화면과 + 메뉴에 아이디어 페이지를 제안 |
| 에이전트 상태 바 | AI 페인 위의 바, 그리고 터미널 위·아래 중 어디에 둘지 |
| 닫기 전 확인 | 사용한 페인·탭·워크스페이스를 닫기 전에 묻기 |
| 세션마다 워크트리 | 작업 중인 프로젝트의 두 번째 세션에 전용 git 워크트리 제공 |
| 작업공간 검색바 노출 | 작업공간 이름과 그 안에서 나눈 대화 내용을 검색 |
| 최근 완료 작업 상위로 자동정렬 | 꺼두면 직접 정리한 순서가 그대로 유지 |
| 병렬 작업 | 에이전트가 분할 페인에서 작업을 시작하도록 요청할 수 있게 하되, 매번 확인 |
| 에이전트에게 Agentty 사용법 알려주기 | 여기서 시작한 에이전트에게 Agentty 명령 안내를 명령줄로 전달 |
| 닫을 때 서버 종료 | 페인을 닫으면 거기서 시작한 로컬 서버를 종료 |
| 익명 사용 정보 수집 동의 | [사용 통계](/docs/telemetry) 참고 |
| 메뉴 바 아이콘 | 창을 닫아도 Agentty를 계속 실행(macOS) |
| 슬립 방지 | 긴 자동 작업이 끊기지 않게 기기를 깨워 둡니다. 항상 또는 1~72시간으로 지정. 전력을 더 씁니다 |

## 프로젝트

새 탭이 시작할 위치, Agentty가 찾을 하네스 패턴, 하네스 프롬프트를 바로 보낼지, 어떤 에이전트가 하네스 작업을 시작할지 정합니다. **편집기에서 열기**가 사용할 편집기도 여기 있습니다.

## 워크스페이스

Agentty 창(**⇧⌘N**으로 새 창)마다 워크스페이스 목록이 따로 있습니다. 이 페이지는 열린 창과 최근에 닫은 창을, 창마다 들어 있는 워크스페이스와 실행 중인 터미널 수와 함께 보여 줍니다. 워크스페이스를 누르면 그곳으로 갑니다. **앞으로 가져오기**는 열린 창을 보여 주고, **다시 열기**는 닫은 창을 다시 열며, **삭제**는 먼저 물어본 뒤 창을 닫고 그 안의 워크스페이스를 지웁니다. 대화 기록은 세션 목록에 남습니다. 메인 창은 삭제할 수 없습니다.

## 계정

새 Claude Code·Codex 탭이 로그인하는 방식입니다. 기본값은 아무것도 바꾸지 않으며 에이전트 자신의 로그인을 그대로 씁니다. 대안과 자격 증명 보관 위치는 [확장·MCP·커넥터](/docs/mcp-and-connectors)를 참고하세요.

## 모양

테마, 글꼴, 글꼴 크기, 줄 높이, 자간, 굵은 글씨, 배경·글자·커서·선택 영역의 직접 고른 색, 커서 모양과 깜박임, 여백, 스크롤백. 에이전트 상태 바에 어떤 항목을 어떤 순서로 둘지도 여기서 정합니다. [테마와 글꼴](/docs/themes)을 참고하세요.

## 키보드 단축키

전체 목록이며, 사용 중인 플랫폼 표기로 표시됩니다. [키보드 단축키](/docs/keyboard-shortcuts)를 참고하세요.

## 알림

시스템 알림, Agentty가 맨 앞에 있을 때도 알릴지, 그리고 Slack·Discord·Telegram 알림입니다. [에이전트 상태](/docs/agent-status)를 참고하세요.

## 동기화

작업공간과 에이전트 세션을 내 비공개 Git 저장소(`gh`를 통한 GitHub, 또는 SSH URL)로 여러 컴퓨터에서 이어 씁니다. 비어 있거나 이미 동기화에 쓰는 비공개 저장소만 목록에 나옵니다. 작업공간은 에이전트가 턴을 마쳤을 때, 탭을 닫았을 때, 아무 동작이 없으면 5분마다, 그리고 **지금 동기화**를 누를 때 동기화되며, 실패한 동기화는 알아서 다시 시도합니다.

**설정 동기화**를 켜고 **저장**을 누르면 설정, 사용자 명령, 커넥터, 가져온 테마, 플러그인 설정도 함께 맞춰지며 가장 최근 변경이 우선합니다. 새로 연결한 컴퓨터는 저장소에 이미 있는 설정을 받아 옵니다. 비밀값(API 키, 토큰, 비밀번호)은 동기화되지 않으니 컴퓨터마다 한 번씩 입력하세요. 비밀값처럼 보이는 내용이 든 부분(예: 토큰을 적어 둔 사용자 명령)은 그 컴퓨터에만 남고 다른 컴퓨터의 것으로 바뀌지도 않으며, 동기화 팝업에 어떤 부분인지 표시됩니다.

**오래된 세션 정리**는 저장소가 끝없이 커지지 않게 합니다(GitHub 비공개 저장소 용량은 무제한이 아닙니다). 30·90·180·365일(또는 직접 정한 기간) 동안 바뀌지 않은 세션은 더 이상 동기화하지 않고, 저장소에서 지우기 전에 동기화 팝업에서 확인을 받습니다. 기간은 저장소 단위라 모든 컴퓨터가 같은 값을 씁니다.

컴퓨터는 Agentty가 `~/.agentty/computer-id`에 만들어 두는 ID로 구분합니다(하드웨어 정보는 읽지 않습니다). `~/.agentty`를 지우면 새 컴퓨터로 표시됩니다. 작업공간을 **동기화 데이터도 삭제**로 지우면 모든 컴퓨터에서 지워집니다. 저장소에 모든 버전이 남으므로 백업 역할도 합니다. 저장소는 비공개여야 하며, 공개 상태인 동안에는 동기화가 멈춥니다.

## 백업

**구성 내보내기**는 전체 구성을 `.agenttyconfig` 파일 하나로 저장합니다. 설정, 사용자 명령, 커넥터, 데이터베이스 연결, 에이전트 로그인 방식, 가져온 테마, 설치한 플러그인 목록과 플러그인 설정이 들어가며, 패널 크기·최근 폴더처럼 한 컴퓨터에만 해당하는 값은 빠집니다. **비밀값 포함**을 켜면 자격 증명 저장소의 API 키, 토큰, 비밀번호와 비밀값이 든 플러그인 설정을 직접 정한 비밀번호로 암호화해 넣습니다(PBKDF2 + AES-256-GCM). Agentty는 이 비밀번호를 보관하지 않습니다.

**구성 가져오기**는 파일의 구성으로 이 컴퓨터의 구성을 바꿉니다. 설정은 파일 값이 우선하고 이 컴퓨터의 패널 크기와 최근 폴더는 그대로 두며, 명령·커넥터 등 나머지 파일은 통째로 교체됩니다. 비밀번호를 비워 두면 비밀값만 빼고 가져옵니다. 없는 플러그인은 마켓플레이스나 Git 저장소에서 설치할 수 있습니다. 가져오기 전 구성은 매번 `~/.agentty/backups/`에 보관됩니다.

## 브라우저

링크를 인앱 브라우저에서 열지 기본 브라우저에서 열지, 개발 서버가 스스로 열릴지, 그리고 검색 엔진입니다.

## 시스템 점검

Agentty가 사용하는 도구와 설치 여부입니다. Git, Node.js, 에이전트 CLI 등 빠진 도구를 여기서 새 터미널 탭으로 설치할 수 있습니다.
