title: 설정 화면

---

**⌘,**가 설정을 엽니다. 변경은 즉시 적용되고 `~/.agentty/settings.json`에 저장됩니다.

## 일반

언어(English, 한국어, 日本語, 中文)와, 매일 마주치는 동작들입니다.

| 설정 | 하는 일 |
|---|---|
| 아이디어로 시작하기 | 시작 화면과 + 메뉴에 아이디어 페이지를 제안 |
| 에이전트 상태 바 | AI 페인 위의 바, 그리고 터미널 위·아래 중 어디에 둘지 |
| 닫기 전 확인 | 사용한 페인·탭·워크스페이스를 닫기 전에 묻기 |
| 세션마다 워크트리 | 작업 중인 프로젝트의 두 번째 세션에 전용 git 워크트리 제공 |
| 작업공간 검색바 노출 | 작업공간 이름과 그 안에서 나눈 대화 내용을 검색 |
| 최근 완료 작업 상위로 자동정렬 | 꺼두면 직접 정리한 순서가 그대로 유지 |
| 병렬 작업 | 에이전트가 분할 페인에서 작업을 시작하도록 요청할 수 있게 하되, 매번 확인 |
| 에이전트에게 Agentty 사용법 알려주기 | 여기서 시작한 에이전트에게 Agentty 명령 안내를 명령줄로 전달 |
| 닫을 때 서버 종료 | 페인을 닫으면 거기서 시작한 로컬 서버를 종료 |
| 익명 사용 정보 수집 동의 | [사용 통계](/docs/telemetry) 참고 |
| 메뉴 바 아이콘 | 창을 닫아도 Agentty를 계속 실행(macOS) |
| 슬립 방지 | 긴 자동 작업이 끊기지 않게 기기를 깨워 둡니다. 항상 또는 1~72시간으로 지정. 전력을 더 씁니다 |

## 프로젝트

새 탭이 시작할 위치, Agentty가 찾을 하네스 패턴, 하네스 프롬프트를 바로 보낼지, 어떤 에이전트가 하네스 작업을 시작할지 정합니다. **편집기에서 열기**가 사용할 편집기도 여기 있습니다.

## 계정

새 Claude Code·Codex 탭이 로그인하는 방식입니다. 기본값은 아무것도 바꾸지 않으며 에이전트 자신의 로그인을 그대로 씁니다. 대안과 자격 증명 보관 위치는 [확장·MCP·커넥터](/docs/mcp-and-connectors)를 참고하세요.

## 모양

테마, 글꼴, 글꼴 크기, 줄 높이, 자간, 굵은 글씨, 배경·글자·커서·선택 영역의 직접 고른 색, 커서 모양과 깜박임, 여백, 스크롤백. 에이전트 상태 바에 어떤 항목을 어떤 순서로 둘지도 여기서 정합니다. [테마와 글꼴](/docs/themes)을 참고하세요.

## 키보드 단축키

전체 목록이며, 사용 중인 플랫폼 표기로 표시됩니다. [키보드 단축키](/docs/keyboard-shortcuts)를 참고하세요.

## 알림

시스템 알림, Agentty가 맨 앞에 있을 때도 알릴지, 그리고 Slack·Discord·Telegram 알림입니다. [에이전트 상태](/docs/agent-status)를 참고하세요.

## 브라우저

링크를 인앱 브라우저에서 열지 기본 브라우저에서 열지, 개발 서버가 스스로 열릴지, 그리고 검색 엔진입니다.

## 시스템 점검

Agentty가 사용하는 도구와 설치 여부입니다. Git, Node.js, 에이전트 CLI 등 빠진 도구를 여기서 새 터미널 탭으로 설치할 수 있습니다.
