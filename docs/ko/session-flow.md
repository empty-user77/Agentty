**⇧⌘F**가 Session Flow를 엽니다. 열려 있는 모든 에이전트 세션이 연결 가능한 노드로 표시됩니다.

한 세션에서 다른 세션으로 선을 끌면, 받는 쪽이 보낸 쪽의 컨텍스트를 받습니다. 무엇을 작업 중이고, 무엇을 결정했고, 어디까지 왔는지입니다. Claude Code와 Codex 사이에서도 동작합니다.

## 연결 방식

| 방식 | 동작 |
|---|---|
| 한 번 | 선을 그은 시점의 컨텍스트를 전달 |
| **라이브** | 보낸 쪽의 새 턴이 생길 때마다 받는 쪽으로 전달 |
| 양방향 | 서로에게 전달 — 컨텍스트 터널 |

라이브 연결은 아무것도 복사하지 않고 두 번째 에이전트를 계속 따라오게 합니다. 양방향 연결은 두 에이전트가 같은 문제의 절반씩을 맡으면서 서로가 방금 한 일을 알게 합니다.

## 무엇이 전달되는가

대화의 요약이며, `~/.agentty/handoffs/`에 파일로 쓰인 뒤 받는 에이전트에게 전달됩니다. 프롬프트와 응답을 턴 단위로 재생하지는 않습니다.

## 언제 무엇을 쓰나

- **한 번** — 관련된 작업에 두 번째 에이전트를 시작하면서 맥락을 알고 출발하게 할 때.
- **라이브** — 한쪽이 구현하고 다른 쪽이 리뷰하거나 문서를 쓰거나 테스트를 지켜볼 때.
- **양방향** — 두 에이전트가 기능을 나눠 맡았고 서로 어긋나면 안 될 때.

연결을 끄면 전달이 멈춥니다. 이미 전달된 내용은 받는 쪽의 대화에 남습니다.
