---

에이전트 그룹은 한 프로젝트의 탭 하나에 에이전트 여러 개를 역할과 함께 띄웁니다. 하나는 개발하고,
하나는 리뷰하고, 하나는 배포하는 식입니다. 각 에이전트는 터미널 위에 이름과 역할 배지를 달고, 다른
에이전트의 역할을 알며, 처음부터 서로 연결되어 있어 한 에이전트가 한 일을 다른 에이전트도 압니다.

## 그룹 시작하기

프로젝트에서 명령 팔레트(**⇧⌘P**)를 열고 **에이전트 그룹 시작: …**을 고릅니다. 이 프로젝트에서 쓸
수 있는 그룹만 보입니다. 첫 번째 에이전트가 메인입니다. 메인 창이 확대된 상태로 시작하고 나머지는
옆에서 일합니다.

Claude Code가 아직 신뢰하지 않은 폴더에서는 메인 에이전트만 먼저 시작합니다. 메인 창에서 폴더 신뢰
질문에 답하면 나머지가 다시 묻지 않고 시작합니다.

## 에이전트끼리 일하는 방식

- **모든 요청은 그 에이전트의 역할로 읽힙니다.** 배포 에이전트에게 "이티켓 배포해"라고 하면 이
  프로젝트의 배포 방식대로 e-ticket 배포 작업을 합니다.
- **다른 에이전트 역할의 일은 그 에이전트에게 넘깁니다.** 에이전트가 `agentty group send
  "<에이전트>" "<요청>"`을 실행하면 요청이 그 에이전트의 터미널로 들어가고(작업 중이면 지금 턴이
  끝난 뒤), 거기서 진행을 볼 수 있습니다.
- **누구의 역할도 아닌 일은 하지 않습니다.** 그룹에 어떤 역할이 있는지 알려 줍니다.
- **세션 공유.** Claude Code 에이전트끼리는 서로 소개되어 Claude Code의 세션 메시지로 직접
  주고받습니다. 다른 에이전트는 양방향 라이브 [Session Flow](session-flow) 연결을 받습니다.

`agentty group list`는 멤버와 역할, 작업 중인지를 보여 줍니다.

## 그룹은 패키지입니다

그룹은 JSON 파일 하나입니다. 파일을 공유하면 받은 사람이 명령 팔레트의 **에이전트 그룹
불러오기…**로 불러와 바로 시작할 수 있습니다. 설치된 그룹은 `~/.agentty/agent-groups/`에 있습니다
(팔레트의 **에이전트 그룹 폴더 열기**). 거기서 파일을 고치면 그룹이 바뀌고, 복사하면 새 그룹이
됩니다. 시작용 샘플 그룹 *Dev team*이 들어 있습니다.

```json
{
  "name": "E-ticket team",
  "description": "Build and ship the e-ticket service",
  "scope": "acme/eticket",
  "notes": "Deploy with ./scripts/deploy.sh <env>. Staging first.",
  "agents": [
    { "name": "Dev", "role": "Implements features and fixes bugs", "badge": "Build", "agent": "claude" },
    { "name": "Deploy", "role": "Builds and deploys to staging and production", "badge": "Release",
      "agent": "claude", "instructions": "Never deploy to production without the user's OK." }
  ]
}
```

| 항목 | 뜻 |
|---|---|
| `name` | 그룹 이름. 팔레트에 보입니다. |
| `description` | 그룹 설명 한 줄. |
| `scope` | 모든 프로젝트용이면 `"any"`, 특정 저장소용이면 `"owner/repo"`: `origin` 원격이 그 저장소인 프로젝트에서만 보입니다. |
| `notes` | 모든 에이전트가 알아야 할 것: 빌드·배포 방법, 파일 위치 등. |
| `agents` | 에이전트 1~6개. 첫 번째가 메인입니다. |
| `agents[].name` | 창에 표시되고 일을 넘길 때 쓰는 이름. 서로 달라야 합니다. |
| `agents[].role` | 이 에이전트가 하는 일 한 줄. |
| `agents[].badge` | 역할 배지에 쓸 한두 단어(16자 이내). 없으면 `role`의 앞부분. |
| `agents[].agent` | `claude`(기본) 또는 `codex`. |
| `agents[].instructions` | 이 에이전트만의 추가 규칙. |

그룹의 역할·노트·지시는 에이전트에게 주는 지시가 됩니다. 남이 공유한 그룹은 스크립트를 보듯 읽고
불러오세요. 내 프로젝트에서 에이전트가 무엇을 할지 정하는 내용입니다.

## 알아 두기

- 그룹 배지와 연결은 앱이 켜져 있는 동안 유지됩니다. 다시 시작하면 에이전트 탭은 돌아오지만 배지와
  연결은 없습니다. 새 팀이 필요하면 그룹을 다시 시작하세요.
- 에이전트 창을 닫으면 그 에이전트는 빠집니다. 그 에이전트에게 일을 넘기면 닫혔다고 알려 줍니다.
