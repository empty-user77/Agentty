Agentty는 AI 코딩 에이전트를 돌리는 사람을 위한 터미널입니다. 터미널이 하는 일(셸, 탭, 분할, 스크롤백)을 그대로 하면서, 두 번째 에이전트가 움직이기 시작하는 순간 필요해지는 것들을 더합니다. 프로젝트마다의 자리, 에이전트마다의 상태, 무엇을 바꿨는지 보는 방법, 그리고 누군가 나를 기다릴 때의 알림입니다.

Rust로 작성되고 GPU로 렌더링되는 네이티브 애플리케이션입니다. Electron도, 터미널을 감싼 웹뷰도, 만들어야 할 계정도 없습니다.

## 무엇을 위한 도구인가

에이전트 하나를 돌리는 건 쉽습니다. 터미널에서 `claude`를 실행하고 지켜보면 됩니다. 다섯 개가 되면 터미널이 더는 도와주지 않습니다. 탭은 전부 똑같이 생겼고, 어느 쪽이 답을 기다리는지 놓치고, 두 에이전트가 같은 파일을 고치고, 비용은 청구서가 올 때까지 보이지 않습니다.

Agentty는 그 두 번째 상황을 위해 만들어졌습니다.

- **누가 나를 기다리는지 항상 알 수 있습니다.** 워크스페이스마다 에이전트가 작업 중인지, 끝났는지, 입력을 기다리는지가 표시됩니다. 답이 필요하면 페인 테두리가 켜지고, 다른 일을 하고 있으면 알림이 옵니다.
- **에이전트끼리 부딪히지 않습니다.** 같은 프로젝트의 두 번째 세션은 자기만의 git 워크트리와 브랜치에서 시작하므로, 두 에이전트가 같은 파일을 건드리는 일이 없습니다.
- **작업 내용이 눈에 보입니다.** GitHub Desktop 형태의 git 페이지, 모든 워크트리를 보여주는 파일 패널, 그리고 이미 디스크에 있는 대화 기록으로 만든 사용량 대시보드가 있습니다.

## 핵심 개념

### 워크스페이스 → 탭 → 분할

**워크스페이스**는 하나의 프로젝트입니다. 폴더 하나, 사이드바의 행 하나, 그리고 그 프로젝트를 위해 열어 둔 모든 것입니다. 워크스페이스 안에 **탭**이 있고, 탭은 **분할**해서 여러 페인으로 나눌 수 있습니다. 페인은 셸이거나, AI 에이전트이거나, 파일 편집기이거나, 브라우저입니다.

워크스페이스는 그룹으로 묶고 순서를 바꿀 수 있으며, 재시작하면 떠날 때 모습 그대로 돌아옵니다.

### 페인은 껍데기가 아니라 실제 프로그램입니다

에이전트 페인은 실제 명령줄 도구를 실행합니다. `claude`, `codex`, 또는 설치해 둔 다른 에이전트가 진짜 PTY 위에서 돌아갑니다. Agentty는 상태를 보고받기 위한 훅을 넘기고, 그 도구가 어차피 기록하는 대화 파일을 읽을 뿐입니다. 대화를 중계하지 않고, 설정 파일을 고쳐 쓰지 않으며, 에이전트와 제공자 사이에 끼어들지 않습니다.

그래서 에이전트는 Agentty 안에서도 자신의 터미널에서와 똑같이 동작하고, 에이전트 CLI를 업그레이드하는 데 Agentty의 릴리스를 기다릴 필요가 없습니다.

### 모든 것이 로컬입니다

Agentty에는 백엔드가 없습니다. 세션 목록, 검색, 사용량 수치, 비용 추정, 컨텍스트 문서는 전부 이용자 컴퓨터의 파일로 만들어집니다. 대화와 코드와 자격 증명은 당사의 서버를 거치지 않습니다. 애초에 그런 서버가 없기 때문입니다.

Agentty에 맡긴 비밀 값은 운영체제의 자격 증명 저장소에 들어갑니다. macOS는 키체인, Windows는 자격 증명 관리자, Linux는 Secret Service입니다.

> [!NOTE]
> 이용자가 실행하는 에이전트 CLI는 각자의 제공자와 통신합니다. Claude Code는 Anthropic과, Codex는 OpenAI와, 이용자 본인의 계정으로 컴퓨터에서 직접 통신하며 이는 다른 터미널에서와 완전히 같습니다. Agentty는 그 중간에 서지 않습니다. 중계하지도, 내용을 받지도 않으며, 그 통신은 각 제공자의 약관과 개인정보처리방침이 규율합니다. Agentty 자체가 보내는 것은 [사용 통계](/docs/telemetry)에 정리돼 있습니다.

## 제공하는 기능

| 영역 | 내용 |
|---|---|
| **에이전트 상태** | 워크스페이스별 실시간 상태, 답을 기다리는 페인의 테두리 표시, 알림과 알림 센터, 최근 미확인으로 이동 |
| **세션** | `~/.claude`와 `~/.codex` 세션 탐색·재개, 제목이나 내용으로 검색, Claude와 Codex 사이의 대화 이전 |
| **Session Flow** | 한 에이전트에서 다른 에이전트로 선을 끌어 컨텍스트 공유, 라이브로 지정하면 이후의 모든 턴을 자동 전달 |
| **Git** | 저장소·브랜치 전환, fetch·pull·push, 변경 사항 검토, 선택한 파일만 커밋, 히스토리 탐색, 병합 |
| **워크트리** | 세션마다 하나의 워크트리, 모든 트리와 작업자와 변경 내용을 보여주는 패널 |
| **파일과 편집기** | 프로젝트 트리, 구문 강조와 포매터를 갖춘 편집기, VS Code·Cursor로 열기 |
| **확장** | Claude Code와 Codex의 스킬·서브에이전트·명령·플러그인·MCP 서버를 한자리에서 |
| **모니터링** | 로컬 대화 기록으로 계산한 비용·토큰·캐시 적중률·모델, 실행 중인 AI 프로세스, 각 탭의 통신 대상을 보여주는 캡처 프록시 |
| **플러그인** | 패널, 버튼, 팔레트 명령, 다른 앱에서 오는 `agentty://` 링크 — [플러그인](/docs/plugins-overview) 참고 |

## 지원 플랫폼

Agentty는 macOS, Windows, Linux를 위해 만들어졌으며, 기준 플랫폼은 macOS입니다. 현재 다운로드가 공개된 플랫폼도 macOS뿐입니다. 나머지 둘은 AppKit이나 WebKit에 의존하지 않는 모든 기능을 동일하게 제공하며, 차이는 [플랫폼](/docs/platforms)에 정리돼 있습니다.

## 라이선스

Agentty는 계정도 구독도 없이 무료로 사용할 수 있습니다. 소스 저장소는 아직 공개되지 않았으며, 공개가 예정되어 있습니다.
