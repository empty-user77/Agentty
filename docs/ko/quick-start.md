title: 빠른 시작
description: 빈 창에서 두 에이전트가 동시에 움직이기까지 — Agentty와 보내는 첫 10분.
---

첫 세션을 순서대로 따라갑니다. 프로젝트를 열고, 에이전트를 시작하고, 그 옆에서 두 번째 에이전트를 돌리고, 둘이 일하는 동안 이곳저곳을 익히는 과정입니다.

단축키는 macOS 기준입니다. Windows와 Linux에서는 ⌘이 Ctrl+Shift, ⇧⌘이 Ctrl+Alt+Shift, ⌥⌘이 Ctrl+Alt, ⌘1…9가 Alt+1…9입니다. [키보드 단축키](/docs/keyboard-shortcuts)를 참고하세요.

## 1. 프로젝트 열기

**⌘N**으로 새 워크스페이스를 만들고 폴더를 고릅니다. 그 폴더가 워크스페이스의 기준이 되어, 이후 여는 모든 탭이 거기서 시작합니다.

사이드바(**⌘B**로 토글)에 워크스페이스가 나열됩니다. 드래그해 순서를 바꾸고, 하나를 다른 하나 위에 떨어뜨려 그룹으로 묶고, 이름을 더블클릭해 바꿀 수 있습니다. 다음에 실행하면 전부 그대로 복원됩니다.

> [!TIP]
> 이미 터미널에서 작업하던 프로젝트가 있다면, 예전 Claude Code나 Codex 세션이 있는 폴더로 `cd` 하세요. 그 자리에서 이어서 하겠느냐는 안내가 나타납니다.

## 2. 에이전트 시작하기

탭 영역의 **+** 메뉴를 쓰거나 단축키를 누릅니다.

| 탭 | 단축키 |
|---|---|
| 터미널 | ⌘T |
| Claude Code | ⌥⌘C |
| Codex | ⌥⌘X |

메뉴에는 시작할 모델(Claude Code는 Opus·Sonnet·Haiku, Codex는 최근 쓴 모델)과, 컴퓨터에서 발견된 다른 에이전트 CLI가 함께 표시됩니다.

에이전트는 자신의 터미널에서와 똑같이 실행됩니다. 같은 도구, 같은 설정, 같은 제공자입니다. 요청을 입력하고 맡기면 됩니다.

## 3. 지켜보지 않고 지켜보기

에이전트가 일하는 동안 창을 앞에 둘 필요가 없습니다.

- 사이드바의 워크스페이스 행에 **작업 중**, **완료**, **입력 대기**가 표시됩니다.
- 에이전트가 무언가 물으면 그 페인의 테두리가 켜지고, 클릭할 때까지 유지됩니다.
- 에이전트가 끝나거나 답을 기다리면 알림이 옵니다. 알림을 클릭하면 그 페인이 열립니다.
- **⇧⌘U**는 가장 최근의 미확인 페인으로 이동합니다.
- **⌃⌘M**은 창을 화면 가장자리의 작은 상시 표시 패널로 접습니다. 끝난 에이전트가 말풍선으로 떠오르고, 클릭하면 전체 창이 돌아옵니다.

각 에이전트 페인 위의 상태 바에는 모델, 컨텍스트 창, 사용 한도, 브랜치, 폴더가 표시됩니다.

## 4. 두 번째 에이전트를 안전하게 추가하기

같은 프로젝트에서 **+** 메뉴로 AI 세션을 하나 더 엽니다. Agentty는 이 세션을 프로젝트의 기본 브랜치에서 딴 **새 브랜치의 전용 git 워크트리**에서 시작하므로, 두 에이전트가 같은 파일을 고치는 일이 없습니다.

**파일 패널**(**⌥⌘B**)은 프로젝트 트리, 모든 워크트리, 각 트리에서 누가 일하는지와 무엇이 바뀌었는지를 보여줍니다. 트리를 우클릭하면 그 안에서 터미널을 열거나, 경로를 복사하거나, 브랜치가 병합된 뒤 제거할 수 있습니다.

에이전트에게 작업을 나누라고 시킬 수도 있습니다 — "A, B, C를 병렬로 해줘". 에이전트가 Agentty에 요청하면 한 번 확인하고, 각 작업이 자기 분할 페인과 자기 워크트리에서 시작됩니다.

> [!NOTE]
> 워크트리는 이미 작업 중인 프로젝트에 *두 번째* 세션이 들어올 때만 관여합니다. 이때 Agentty가 새 워크트리를 만들지, 기존 워크트리를 열지 묻습니다. 혼자 작업하는 동안에는 연 폴더에 그대로 머뭅니다.

## 5. 창 정리하기

| 동작 | 단축키 |
|---|---|
| 오른쪽 / 아래로 분할 | ⌘D / ⇧⌘D |
| 다음 / 이전 페인 | ⌘] / ⌘[ |
| 다음 / 이전 탭 | ⇧⌘] / ⇧⌘[ |
| 워크스페이스 / 탭 1–9로 이동 | ⌘1…⌘9 / ⌃1…⌃9 |
| 페인 / 탭 닫기 | ⌘W / ⇧⌘W |

터미널 옆에 붙는 패널(파일, 브라우저, 플러그인, Docker)은 모두 가장자리를 끌어 크기를 조절할 수 있습니다.

## 6. 결과 검토하기

**⇧⌘G**로 git 페이지를 엽니다. 저장소와 브랜치를 바꾸고, fetch·pull·push 하고, 변경 사항을 파일별로 검토하고, 원하는 것만 스테이지해 커밋하고, 히스토리를 보고, 브랜치를 병합할 수 있습니다. 페인 헤더의 브랜치 이름을 클릭하면 브랜치 전환, pull, push, 이름 복사가 됩니다.

파일 패널에서 파일을 클릭하면 터미널 옆 편집기에서 열립니다. 구문 강조, 실행 취소·다시 실행, **⌘S** 저장, **⇧⌥F**로 설치된 포매터를 이용한 정렬을 지원합니다. 에이전트가 바꾼 파일은 자동으로 다시 읽힙니다. 마크다운 파일에는 **뷰어** 버튼(**⇧⌘V**)이 있어 VS Code 미리보기와 같은 방식으로 렌더링해 보여 줍니다. 그 안의 링크는 브라우저에서, 파일 링크는 편집기에서 열립니다. 뷰어는 지금은 macOS에서만 쓸 수 있습니다.

## 7. 비용 확인하기

**⌥⌘U**로 모니터링을 엽니다. 비용, 호출 수, 캐시 적중률, 토큰, 모델, 프로젝트, 도구가 표시되며 전부 디스크에 이미 있는 대화 기록으로 계산합니다. 같은 페이지에서 실행 중인 AI 프로세스와, 각 탭이 어디와 통신하는지 보여주는 캡처 프록시도 볼 수 있습니다.

## 일찍 알아두면 좋은 것

- **⇧⌘P** — 명령 팔레트. `agentty.json`에 정의한 사용자 명령까지 전부 여기 있습니다.
- **⇧⌘O** — 로컬 세션을 제목·내용·경로로 검색합니다.
- **⇧⌘B** — 터미널 옆의 인앱 브라우저. 개발 서버는 `:포트` 칩으로 나타나 응답하는 즉시 여기서 열립니다.
- **⇧⌘X** — 확장: 스킬, 서브에이전트, 명령, 플러그인, MCP 서버.
- **⌘,** — 설정: 언어(English, 한국어, 日本語, 中文), 테마, 글꼴, 그리고 위의 모든 동작.
