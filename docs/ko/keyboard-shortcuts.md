전체 목록은 **설정 → 키보드 단축키**에도 있고, 사용 중인 플랫폼의 표기로 나옵니다.

## Windows와 Linux

단축키는 macOS 기준으로 정의한 뒤 변환합니다. Ctrl+문자 조합이 언제나 셸로 전달되게 하려는 것입니다.

| macOS | Windows / Linux |
|---|---|
| ⌘X | Ctrl+Shift+X |
| ⇧⌘X | Ctrl+Alt+Shift+X |
| ⌥⌘X | Ctrl+Alt+X |
| ⌘1…⌘9 | Alt+1…Alt+9 |
| ⌘= / ⌘- / ⌘0 | Ctrl+= / Ctrl+- / Ctrl+0 |
| ⌘-클릭 | Ctrl-클릭 |

텍스트 입력란과 파일 편집기는 일반 Ctrl을 씁니다(Ctrl+C / V / X / A / Z, Ctrl+S, Ctrl+Y, 단어 단위 Ctrl+←/→, Ctrl+Home / End).

## 미국 배열이 아닌 키보드

단축키는 지금 쓰는 키보드 배열을 따르고, 배열을 바꾸면 함께 바뀝니다.

- **macOS 단축키**: 배열에서 Option을 눌러야만 칠 수 있는 키의 단축키는 macOS 메뉴가 옮기는 자리로 옮겨 갑니다. 독일어 배열에서는 ⌘[ / ⌘]가 ⌘Ö / ⌘Ä로, ⇧⌘[ / ⇧⌘]가 ⇧⌘Ö / ⇧⌘Ä로 바뀝니다. 메뉴와 **설정 → 키보드 단축키**에 내 배열의 키가 표시됩니다.
- **터미널의 Option**(macOS): **Option 키를 Meta로 사용**(설정 → 터미널)이 켜져 있어도, 배열이 Option으로 필요한 문자를 치는 키에서는 그 문자가 입력됩니다. `[ ] { } @ | \ ~` 같은 코드 문자(포르투갈어 ⌥8은 `[`, 독일어 ⌥L은 `@`)와 그 언어의 글자(폴란드어 Pro ⌥A는 `ą`, 터키어 Q ⌥S는 `ş`)입니다. 나머지 Option 키는 Meta이고, 미국 배열에서는 모든 Option 키가 Meta입니다.
- **Windows의 AltGr**: AltGr로 그 키의 문자를 치는 배열(크로아티아어 AltGr+B는 `{`)에서는 같은 키의 Ctrl+Alt 단축키를 빼서 문자가 입력되게 합니다.

## 탭과 페인

| 동작 | 단축키 |
|---|---|
| 새 터미널 / Claude Code / Codex 탭 | ⌘T / ⌥⌘C / ⌥⌘X |
| 새 워크스페이스 | ⌘N |
| 오른쪽 / 아래로 분할 | ⌘D / ⇧⌘D |
| 다음 / 이전 페인 | ⌘] / ⌘[ |
| 다음 / 이전 탭 | ⇧⌘] / ⇧⌘[, ⌃Tab |
| 다음 / 이전 워크스페이스 | ⌥⌘↓ / ⌥⌘↑ |
| 페인 / 탭 닫기 | ⌘W / ⇧⌘W |
| 워크스페이스 / 탭 1–9로 이동 | ⌘1…⌘9 / ⌃1…⌃9 |

## 패널과 페이지

| 동작 | 단축키 |
|---|---|
| 사이드바 토글 | ⌘B |
| 워크스페이스 / 로컬 세션 | ⇧⌘E / ⇧⌘S |
| Git / 확장 | ⇧⌘G / ⇧⌘X |
| 오케스트레이션 / 모니터링 / 설정 | ⇧⌘F / ⌥⌘U / ⌘, |
| 인앱 브라우저 / 파일 패널 | ⇧⌘B / ⌥⌘B |
| 앞에 있는 창의 채팅 보기 | ⇧⌘J |
| 명령 팔레트 / 미확인으로 이동 | ⇧⌘P / ⇧⌘U |
| 음성 입력 (녹음 · ⏎ 전송 · Esc 취소) | ⇧⌘M |
| 로컬 세션 검색 | ⇧⌘O |
| 파일·심볼로 이동 / 선택 영역을 AI에게 지시 (파일 편집기, diff) | ⌘P / ⌘K |
| 정의로 이동 / 사용처 찾기 / 뒤로 (파일 편집기) | F12, ⌘-클릭 / ⇧F12 / ⌃- |
| 구현으로 이동 (파일 편집기) | ⌘F12 |
| 프로젝트 파일에서 텍스트 찾기 (파일 편집기) | ⇧⌘F |
| import 정리 (파일 편집기) | ⇧⌥O |
| 다음 / 이전 문제 (파일 편집기) | F8 / ⇧F8 |
| 빠른 수정 (파일 편집기) | ⌘. |
| 모든 곳 이름 변경 (파일 편집기) | F2 |
| 자동 완성 (파일 편집기) | ⌃Space |
| 파일에서 바꾸기 (파일 편집기) | ⌥⌘F (↩ 하나, ⌘↩ 모두. ⌥⌘C 대소문자 구분, ⌥⌘W 단어 단위, ⌥⌘R 정규식(바꿀 내용에 `$1`로 그룹 사용)) |
| 줄 주석 처리 / 이동 / 복제 / 삭제 (파일 편집기) | ⌘/ / ⌥↑ ⌥↓ / ⇧⌥↑ ⇧⌥↓ / ⇧⌘K |
| 줄 선택 / 아래·위에 새 줄 / 줄 처음까지 지우기 / 앞·뒤 단어 지우기 (파일 편집기) | ⌘L / ⌘↩ ⇧⌘↩ / ⌘⌫ / ⌥⌫ ⌥⌦ |
| 줄 들여쓰기 / 내어쓰기 (파일 편집기) | ⌘] / ⌘[ |
| 다음 같은 단어 / 모든 같은 단어 / 클릭한 곳 / 위·아래 줄에 커서 추가 (파일 편집기, Esc로 하나로) | ⌘D / ⇧⌘L / ⌥-클릭 / ⌥⌘↑ ⌥⌘↓ |
| 짝 괄호로 이동 (파일 편집기) | ⇧⌘\ |
| 커서가 있는 블록 접기 / 펼치기 (파일 편집기, 줄 번호 옆 화살표나 접힌 줄의 `⋯`를 클릭해도 됨) | ⌥⌘[ / ⌥⌘] |
| 파일의 모든 블록 접기 / 펼치기 (파일 편집기) | ⇧⌥⌘[ / ⇧⌥⌘] |
| 미니 모드 | ⌃⌘M |

파일 편집기에 포커스가 있을 때 ⌘D, ⌘] / ⌘[, ⇧⌘↩, ⌥⌘↑ / ⌥⌘↓는 VS Code처럼 텍스트에 쓰입니다. 패널 분할·이동·확대나 작업공간 전환에 쓰려면 터미널을 클릭하세요.

## 터미널과 편집기

| 동작 | 단축키 |
|---|---|
| 스크롤백에서 찾기 | ⌘F |
| 글꼴 확대 / 축소 / 초기화 | ⌘= / ⌘- / ⌘0 |
| 복사 / 붙여넣기 / 전체 선택 / 지우기 | ⌘C / ⌘V / ⌘A / ⌘K |
| Git 페이지: 커밋 / push / fetch / 새로 고침 | ⌘↩ / ⌘P / ⇧⌘T / ⌘R |
| 파일 편집기: 파일에서 찾기 / 다음 / 이전 | ⌘F / ↩ 또는 ⌘G / ⇧↩ |
| 파일 편집기: 저장 / 정렬 / 파일 닫기 | ⌘S / ⇧⌥F / ⌘W |
| 파일 편집기: 마크다운 뷰어 켜기 / 끄기 (macOS) | ⇧⌘V |
| 파일 편집기: 마크다운 뷰어를 글 옆에 켜기 / 끄기 (macOS) | ⌥⌘V |

제목 표시줄을 더블클릭하면 창이 확대되고, 탭 영역의 빈 공간을 더블클릭하면 새 탭이 열립니다.

## 내가 만든 명령

명령 팔레트(**⇧⌘P**)에는 프로젝트의 `agentty.json`이나 `~/.agentty/commands.json`에 정의한 항목도 함께 나열됩니다. 예약어도 동작합니다. 터미널에 `claude yolo`를 입력하면 `claude --dangerously-skip-permissions`로 펼쳐집니다.
