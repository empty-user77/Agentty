전체 목록은 **설정 → 키보드 단축키**에도 있으며, 사용 중인 플랫폼 표기로 표시됩니다.

## Windows와 Linux

단축키는 macOS 기준으로 정의하고 변환합니다. Ctrl+문자는 언제나 셸로 전달되도록 하기 위해서입니다.

| macOS | Windows / Linux |
|---|---|
| ⌘X | Ctrl+Shift+X |
| ⇧⌘X | Ctrl+Alt+Shift+X |
| ⌥⌘X | Ctrl+Alt+X |
| ⌘1…⌘9 | Alt+1…Alt+9 |
| ⌘= / ⌘- / ⌘0 | Ctrl+= / Ctrl+- / Ctrl+0 |
| ⌘-클릭 | Ctrl-클릭 |

텍스트 입력란과 파일 편집기는 일반 Ctrl을 씁니다(Ctrl+C / V / X / A / Z, Ctrl+S, Ctrl+Y, 단어 단위 Ctrl+←/→, Ctrl+Home / End).

## 탭과 페인

| 동작 | 단축키 |
|---|---|
| 새 터미널 / Claude Code / Codex 탭 | ⌘T / ⌥⌘C / ⌥⌘X |
| 새 워크스페이스 | ⌘N |
| 오른쪽 / 아래로 분할 | ⌘D / ⇧⌘D |
| 다음 / 이전 페인 | ⌘] / ⌘[ |
| 다음 / 이전 탭 | ⇧⌘] / ⇧⌘[, ⌃Tab |
| 다음 / 이전 워크스페이스 | ⌥⌘↓ / ⌥⌘↑ |
| 페인 / 탭 닫기 | ⌘W / ⇧⌘W |
| 워크스페이스 / 탭 1–9로 이동 | ⌘1…⌘9 / ⌃1…⌃9 |

## 패널과 페이지

| 동작 | 단축키 |
|---|---|
| 사이드바 토글 | ⌘B |
| 워크스페이스 / 로컬 세션 | ⇧⌘E / ⇧⌘S |
| Git / 확장 | ⇧⌘G / ⇧⌘X |
| Session Flow / 모니터링 / 설정 | ⇧⌘F / ⌥⌘U / ⌘, |
| 인앱 브라우저 / 파일 패널 | ⇧⌘B / ⌥⌘B |
| 명령 팔레트 / 미확인으로 이동 | ⇧⌘P / ⇧⌘U |
| 로컬 세션 검색 | ⇧⌘O |
| 미니 모드 | ⌃⌘M |

## 터미널과 편집기

| 동작 | 단축키 |
|---|---|
| 스크롤백에서 찾기 | ⌘F |
| 글꼴 확대 / 축소 / 초기화 | ⌘= / ⌘- / ⌘0 |
| 복사 / 붙여넣기 / 전체 선택 / 지우기 | ⌘C / ⌘V / ⌘A / ⌘K |
| Git 페이지: 커밋 / push / fetch / 새로 고침 | ⌘↩ / ⌘P / ⇧⌘T / ⌘R |
| 파일 편집기: 저장 / 정렬 / 파일 닫기 | ⌘S / ⇧⌥F / ⌘W |
| 파일 편집기: 마크다운 뷰어 켜기 / 끄기 (macOS) | ⇧⌘V |

제목 표시줄을 더블클릭하면 창이 확대되고, 탭 영역의 빈 공간을 더블클릭하면 새 탭이 열립니다.

## 내가 만든 명령

명령 팔레트(**⇧⌘P**)에는 프로젝트의 `agentty.json`이나 `~/.agentty/commands.json`에 정의한 항목도 함께 나열됩니다. 예약어도 동작합니다. 터미널에 `claude yolo`를 입력하면 `claude --dangerously-skip-permissions`로 펼쳐집니다.
