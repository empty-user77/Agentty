title: 원격 접속

원격 접속을 이용하면 다른 기기 — 휴대폰, 태블릿, 다른 컴퓨터 — 의 브라우저에서 Agentty 워크스페이스를 열 수 있습니다. 자신의 Tailscale 네트워크 안에서 터미널 세션을 보고, 명령을 직접 입력하고, 에이전트에게 프롬프트를 보낼 수 있습니다.

## 화면에 보이는 것

페이지는 Agentty 앱과 같은 구성입니다.

- **홈** — 페이지를 열면 처음 나오는 화면입니다. 답을 기다리는 터미널과 작업 중인 터미널 수, 기다리는 터미널과 그 요청, 작업 중인 에이전트, 모든 워크스페이스(쉬는 것 포함), 플러그인과 그 상태가 한눈에 보입니다. 터미널이나 워크스페이스를 누르면 그리로 갑니다. ☰ 메뉴 맨 위의 **홈**으로 돌아옵니다.
- **☰ 메뉴** — 그룹과 워크스페이스가 사이드바와 같은 순서·색으로, 브랜치와 폴더와 함께 나옵니다. 빨간 숫자는 그 워크스페이스에서 답을 기다리는 터미널 수입니다. 넓은 화면에서는 왼쪽에 항상 펼쳐져 있습니다.
- **탭** — 고른 워크스페이스의 탭이 위에 나란히 나옵니다. 점은 작업 중이거나 답을 기다리는 탭, ▥2는 분할창 2개로 나뉜 탭입니다.
- **분할창** — 탭이 나뉘어 있으면 오른쪽 위 버튼으로 분할창 목록을 열어 각 창의 상태와 요청을 보고, 눌러서 전환합니다.
- **터미널** — 가운데에 고른 창의 실시간 화면이 나옵니다.
- **채팅 작업공간** — [채팅 작업공간](/docs/chat-workspace)은 채팅으로 열립니다. 대화, 요금제 사용량, 리드에게 쓰는 입력창이 보이고, **터미널**로 리드의 터미널로 바꿀 수 있습니다.

**새 탭** — 탭 끝의 **+**(또는 홈의 워크스페이스 옆 **+**)를 누르면 그 워크스페이스에 터미널, Claude Code, Codex 중 하나로 새 탭을 엽니다. 워크스페이스 폴더에서 시작하고, 페이지가 그 탭으로 넘어갑니다.

**쉬는 워크스페이스** — Agentty에서 쉬고 있는 워크스페이스에는 **깨우기**가 나옵니다. 누르면 저장된 탭이 다시 시작되고 페이지에 나옵니다. 어느 쪽도 Mac 화면에 보이는 것은 바꾸지 않습니다.

**플러그인** — 홈에 설치된 플러그인과 상태(실행 중, 멈춤, 오류로 멈춤), 각 자동화가 지금 하는 일이 나옵니다. 보여 주기만 합니다. 플러그인 워크스페이스는 페이지에서 열리지 않고, 페이지에서 플러그인을 켜거나 끌 수 없습니다.

화면의 키 막대를 이용해 Esc, Tab, Shift+Tab, 화살표, Enter, Ctrl+C, 고정된 Ctrl 키, 그리고 에이전트가 답을 요청할 때의 빠른 버튼(1/2/3)으로 터미널에 직접 입력할 수 있습니다. 또는 아래 상자에서 프롬프트를 보낼 수 있습니다. 컴퓨터에서는 Enter를 누르고, 줄을 추가하려면 Shift+Enter를 누릅니다.

페이지의 **알림 받기**를 누르면, 페이지를 띄워 두고 다른 일을 하는 동안 세션이 끝나거나 응답을 요청할 때 브라우저 알림이 옵니다.

웹에서 터미널을 보는 동안에는 터미널이 웹 화면 크기에 맞춰집니다. 화면에 들어가는 만큼의 칸과 줄을 쓰므로 줄이 꺾이거나 옆으로 스크롤되지 않습니다. **A−** / **A+**로 글자 크기를 바꿀 수 있습니다(기기마다 기억). 웹에서 그 터미널을 보는 페이지가 없어지면 앱의 원래 크기로 돌아갑니다. 이 페이지를 홈 화면에 앱으로 추가할 수 있습니다.

Slack·Discord·Telegram 알림을 설정해 두었다면(설정 → 알림), 원격 접속이 켜져 있는 동안 메시지 아래에 **바로 확인하기: <주소>**가 붙습니다. 이 주소를 열면 Tailscale과 웹 비밀번호 확인을 거친 뒤 그 터미널이 바로 열립니다. 이 주소에는 Mac과 tailnet 이름이 들어 있어서, **에이전트 질문 내용 포함**을 켰을 때만 보냅니다.

## 필요한 것

다음이 필요합니다.

- **Tailscale** Mac에 설치되고 연결되어 있음 (다른 기기도 같은 Tailscale 계정으로 로그인)
- **MagicDNS와 HTTPS 인증서** tailnet에 활성화됨 (Tailscale 관리 콘솔 → DNS)
- **Tailscale Serve** tailnet에서 허용됨 — 그렇지 않으면 Agentty가 켜기 버튼을 보여줍니다

## 설정하기

1. 사이드 메뉴의 **원격 접속**(지구본과 모니터 아이콘) 열기
2. **웹 비밀번호** 설정 (8자 이상, 두 번 입력)
3. **원격 접속 켜기** 켜기
4. 나타난 주소 복사 (`https://<machine>.<tailnet>.ts.net:8743/`) 또는 **열기**를 탭해 바로 이동
5. 다른 기기에서 웹 비밀번호로 로그인

완료. 이제 세션이 그 기기에서 보입니다.

## 보안

원격 접속은 Tailscale 네트워크 안에서만 열립니다. 공개 인터넷으로는 절대 나가지 않으며, Agentty의 포트에 Funnel이 켜져 있으면 켜지지 않습니다. 접속하려면 두 가지를 모두 통과해야 합니다.

1. **Tailscale 계정** — 이 Mac의 주인 계정만 들어올 수 있습니다. 같은 tailnet을 함께 쓰는 다른 사람이나 태그된 기기는 거부됩니다.
2. **웹 비밀번호** — 원격 접속 화면에서 정한 비밀번호.

다른 사람의 Tailscale 계정은 같은 tailnet 안에 있어도 들어올 수 없습니다. **내** Tailscale 계정으로 로그인된 기기에서 웹 비밀번호까지 맞힌 경우에만 터미널에 입력할 수 있고, 이는 Mac에서 명령을 실행할 수 있다는 뜻입니다. 그러니 웹 비밀번호는 다른 사람과 공유하지 말고 다른 곳에서 쓰지 않는 것으로 정하고, 필요 없을 때는 원격 접속을 꺼 두세요.

Agentty의 페이지에는 Tailscale만 닿을 수 있습니다. Agentty는 Tailscale의 `serve`만 들어올 수 있는 곳에서 대기합니다. Tailscale이 열 수 있으면 전용 소켓, 아니면 Tailscale에게만 알려 준 비밀 경로가 붙은 로컬 포트입니다. 그래서 Mac 안의 다른 프로그램이나 다른 사용자 계정은 직접 들어올 수 없습니다. 페이지는 Tailscale이 켜져 있는 동안에만 동작합니다. Tailscale이 끊기거나 로그아웃되거나 종료되면 몇 초 안에 페이지를 내리고, 다시 연결되면 자동으로 다시 엽니다.

로그인 실패 시도는 속도 제한이 있습니다. 잘못된 비밀번호 5번 후에는 1분간 잠깁니다. 그 이후의 각 오류는 대기 시간을 2배로 늘립니다. 최대 1시간입니다. 기기가 로그인했을 때와 화면이 잠겼을 때 데스크톱 알림을 받습니다. 내가 잠근 게 아니라면 원격 접속 화면의 **잠금 해제**로 바로 풀 수 있습니다.

비밀번호는 시스템 키체인에 해시로만 저장됩니다. 로그인은 최대 7일 (유휴 12시간)까지 지속됩니다. Agentty를 종료하거나, 비밀번호를 바꾸거나, **모든 기기 로그아웃**을 탭하면 모든 기기가 한 번에 로그아웃됩니다.

## 깨어 있게 하기

원격 접속이 켜져 있는 동안 Agentty는 Mac이 유휴 절전 상태에 빠지지 않게 해서 도달할 수 있게 유지합니다. 디스플레이는 여전히 절전 상태에 빠질 수 있습니다. 선호한다면 이를 끌 수 있습니다.

절전 상태인 Mac이나 닫힌 노트북에는 도달할 수 없습니다.

원격 접속은 재시작 후에도 켜진 상태로 유지되며, 끌 때까지 계속 켜져 있습니다. Tailscale 포트 8743을 사용하고 Tailscale로 제공하는 다른 것을 방해하지 않습니다. 다른 것이 이미 포트 8743을 사용하고 있으면 Agentty가 오류를 보여줍니다.

## Mac 앱에서 음성 입력

앱 안에서도 바로 말로 지시할 수 있습니다. 상태바 오른쪽 끝의 **마이크**를 누르거나 **⇧⌘M**을 누르고 말하세요. 듣는 동안 상태바에 **녹음 중 0:05**와 음량 막대가 보입니다.

- **⏎ Enter** — 멈추고 말한 내용을 터미널에 바로 프롬프트로 전송합니다.
- **마이크 다시 클릭 또는 ⇧⌘M** — 멈추고 입력만 해 둡니다. 확인하거나 고친 뒤 직접 전송하세요.
- **Esc** — 녹음을 취소합니다.

내용은 녹음을 시작할 때 활성화된 터미널에 들어갑니다. 언어는 말소리에서 자동으로 감지하므로 한국어, 영어, 섞어 말하기 모두 됩니다. 처음 한 번 macOS가 마이크 권한을 묻고, 꺼 두었다면 Agentty가 시스템 설정의 마이크 화면을 열어 줍니다. 모델이 아직 없으면 마이크를 눌렀을 때 그 자리에서 모델 설치 화면(아래와 같은 것)이 열립니다.

## 음성으로 프롬프트 보내기

원격 페이지에서는 타이핑 대신 음성으로 프롬프트를 보낼 수 있습니다. 프롬프트 입력창의 마이크를 누르고 말한 뒤 다시 누르면 멈추고, 변환된 문장이 입력창에 들어갑니다. 확인하고 전송하면 됩니다.

음성은 **이 Mac에서** 로컬 모델로 변환되며 외부 서비스로 전송되지 않습니다. 모델은 **설정 → 원격 접속 → 음성 입력**에서 한 번 설치합니다. **Base**(권장) 또는 더 작고 빠른 **Tiny**를 선택하면 Mac으로 내려받아(검증 후 보관) 설치됩니다. 모델이 설치되면 원격 페이지에 마이크 버튼이 자동으로 나타납니다.

브라우저가 처음에 마이크 권한을 묻고, 페이지는 HTTPS로 제공되어야 합니다 — Tailscale을 통해 HTTPS로 제공됩니다.

## 기능 숨기기

원격 접속을 쓰지 않는다면 **설정 → 일반 → 원격 접속 기능 사용**을 끄거나(기본값은 켜짐), 원격 접속 화면의 **원격 접속 비활성** 버튼을 누르세요. 사이드 메뉴에서 아이콘이 사라지고 원격 접속도 꺼집니다. 다시 쓰려면 그 설정을 켜면 됩니다.

특정 작업공간만 웹에서 빼고 싶다면 그 작업공간 카드의 메뉴(우클릭)에서 **원격 접속에서 숨기기**를 고르세요. 웹 페이지 목록에서 사라지고 그 터미널에도 접근할 수 없습니다.

## 문제 해결

**Tailscale이 연결되지 않음**
Mac의 Tailscale 앱에서 연결하세요.

**HTTPS 인증서가 꺼짐**
Tailscale 관리 콘솔(DNS 설정)에서 MagicDNS와 HTTPS를 활성화하세요. 이렇게 하면 tailnet 도메인을 위한 인증서가 생성됩니다.

**Serve가 꺼짐**
Agentty는 설정에서 Serve를 켜는 버튼을 보여줍니다. 탭하면 Tailscale 관리 콘솔이 열립니다.

**이 Tailscale 계정은 이 Agentty를 사용할 수 없음** (로그인 화면에 표시됨)
다른 기기가 다른 Tailscale 계정으로 로그인되어 있습니다. Mac과 같은 계정으로 로그인하세요.

**화면에 잠김이라고 표시됨** (로그인 양식 대신 표시됨)
당신이 비밀번호를 5번 잘못 입력했거나 다른 사람이 입력했습니다. 기다리거나 **원격 접속 → 최근 접속 기록**을 확인해 무엇이 일어났는지 확인하세요. 내가 한 게 아니라면 Mac의 원격 접속 화면에서 **잠금 해제**를 누르세요.
