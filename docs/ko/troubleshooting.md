## 에이전트가 목록에 없거나 시작되지 않습니다

Agentty는 **로그인 셸**의 `PATH`에서 찾을 수 있는 에이전트 CLI만 제안합니다. 터미널에서는 되는데 여기서만 안 된다면, `PATH`가 대화형 셸만 읽는 파일(`.zshrc`, `.bashrc`)에 설정돼 있을 가능성이 큽니다. 로그인 셸이 읽는 위치로 옮기거나, 빠진 것을 나열하고 설치까지 해 주는 **설정 → 시스템 점검**을 확인하세요.

## 페인 상태가 비어 있습니다

상태는 페인이 시작할 때 Agentty가 에이전트에게 전달하는 훅에서 옵니다.

- Windows에서 Claude Code는 훅을 Git Bash로 실행합니다. **Git for Windows**를 설치하세요.
- 이미 열린 셸 안에서 에이전트를 직접 실행했다면 훅이 없습니다. **+** 메뉴에서 여세요.

## 에이전트가 엉뚱한 파일을 고쳤습니다

한 폴더의 두 세션은 충돌합니다. **설정 → 일반 → 세션마다 워크트리**를 켜면 두 번째 세션이 자기 git 워크트리와 브랜치를 갖습니다. [파일 패널](/docs/agent-git)에서 모든 워크트리와 각각의 변경 내용을 볼 수 있습니다.

## 탭을 닫았는데 개발 서버가 계속 돕니다

**설정 → 일반 → 닫을 때 서버 종료**가 페인이 시작한 서버를 함께 종료합니다. 모니터링 → **프로세스**에서 아직 실행 중인 것을 확인할 수 있습니다.

## 사용량 숫자가 이상합니다

디스크의 대화 파일로 계산한 값이며, 내장된 가격은 Claude 모델뿐입니다. 다른 모델은 `~/.agentty/pricing.json`에 가격을 추가하세요([설정 레퍼런스](/docs/configuration-reference) 참고). 이 수치는 추정치이고, 기준은 제공자의 청구서입니다.

## 플러그인이 보이지 않거나 멈춥니다

- JavaScript 플러그인은 로그인 셸의 `PATH`에 **Node.js 18 이상**이 필요합니다.
- 폴더 이름이 `agentty-plugin.json`의 `id`와 같아야 합니다. 복사해 넣은 뒤에는 **새로 고침**을 누르세요.
- 플러그인 카드의 **로그**에 크래시를 포함한 실제 출력이 있습니다. 코드를 고친 뒤 **재시작**을 누르세요.

자세한 내용은 [플러그인 사용하기](/docs/plugins-overview)에 있습니다.

## `agentty://` 링크가 동작하지 않습니다

링크는 설치된 애플리케이션에서 동작하며, 개발용으로 실행한 빌드에서는 동작하지 않습니다. 링크가 지정한 플러그인이 설치·활성화돼 있는지 확인하세요.

## 업데이트가 되지 않습니다

업데이트는 GitHub에서 내려받아 사용 전에 검증합니다. 프록시나 차단된 호스트 때문에 실패한다면 [릴리스 페이지](https://github.com/empty-user77/Agentty/releases)에서 직접 받으세요.

## 그래도 막혔다면

[이슈 트래커](https://github.com/empty-user77/Agentty/issues)에 알려 주세요. Agentty 버전(**설정 → Agentty 정보**), 운영체제, 기대한 동작을 함께 적어 주시면 좋습니다. 로그나 화면을 붙여 넣기 전에 자격 증명은 가려 주세요.

보안 문제는 공개 이슈 대신 비공개로 신고해 주시기 바랍니다.
