Claude Code는 턴 중 중요한 시점에 더 강한 모델에게 조언을 구할 수 있습니다. 큰 리팩터링에 들어가기 전, 판단이 필요한 계획을 세울 때, 막혔을 때입니다. Agentty는 이를 설정 항목으로 노출해, 플래그를 외우지 않아도 되게 합니다.

> [!NOTE]
> Claude Code의 실험적 기능이며 토큰을 추가로 사용합니다. 직접 켜지 않으면 동작하지 않습니다.

## 동작 방식

조언을 수행하는 것은 Agentty가 아닙니다. Agentty는 Claude Code 페인을 시작할 때 명령줄에 `--advisor <모델>`을 덧붙이고, 실제 조언은 Claude Code가 합니다. 따라서

- 어드바이저는 세션의 나머지와 마찬가지로 **이용자 본인의** Claude Code 로그인과 제공자 계정을 사용합니다.
- 설정 파일에는 아무것도 기록되지 않습니다. 선택은 Agentty의 설정에 남고 실행할 때마다 전달됩니다.
- **끔**을 고르면 Claude Code에 설정해 둔 `advisorModel`까지 덮어쓰는 스위치가 전달되므로, 그 페인에서는 확실히 꺼집니다.

## 모델 선택

**설정 → 일반 → Claude Advisor**는 **새로 여는** Claude 탭에 적용됩니다.

| 선택 | 효과 |
|---|---|
| Claude Code 설정 | Agentty가 아무것도 전달하지 않고, Claude Code에 설정된 대로 동작합니다 |
| 끔 | 해당 페인에서 어드바이저를 끕니다. Claude Code 자체 설정보다 우선합니다 |
| Opus | Opus에게 조언을 구합니다 |
| Fable | Fable에게 조언을 구합니다 |

이미 실행 중인 페인은 세션을 다시 시작하지 않고 상태 바에서 바꿀 수 있습니다.

## 켤 만한 때

- **켤 만합니다:** 아키텍처 결정, 여러 파일에 걸친 리팩터링, 가설 세 개가 빗나간 디버깅, 에이전트가 계획을 확정하기 전의 검토.
- **켤 필요 없습니다:** 일상적인 편집, 테스트, 포매팅처럼 작업이 기계적인 경우. 추가 토큰이 아무것도 사지 못합니다.

평소에는 꺼 두고, 신경 쓰이는 결정에 다다랐을 때 상태 바에서 켜는 방식이 무난합니다.
