description: Agentty가 작업을 정리하는 방식 — 프로젝트마다 워크스페이스, 그 안에 탭, 탭 안에 페인.
---

Agentty에는 세 단계가 있습니다. **워크스페이스**는 프로젝트, **탭**은 그 안의 한 화면, **페인**은 하나의 프로그램입니다. 페인은 셸이거나 AI 에이전트이거나 파일 편집기이거나 브라우저입니다.

## 워크스페이스

사이드바(**⌘B**)의 각 행이 워크스페이스이며, 열릴 폴더를 하나씩 가집니다. **⌘N**으로 만듭니다.

- 행을 드래그해 순서를 바꾸고, 하나를 다른 하나 위에 떨어뜨리면 **그룹**이 됩니다. 그룹은 접을 수 있습니다.
- 이름을 더블클릭해 바꿉니다.
- **⌥⌘↓ / ⌥⌘↑**로 이동하고, **⌘1…⌘9**로 바로 갑니다.
- 모든 워크스페이스와 그 탭·분할·그룹은 재시작 후 그대로 돌아옵니다.

워크스페이스 행에는 그 안의 에이전트 상태가 표시되므로, 열어보지 않고도 어느 프로젝트가 나를 기다리는지 알 수 있습니다.

## 탭

**⌘T**는 터미널, **⌥⌘C**는 Claude Code, **⌥⌘X**는 Codex 탭을 엽니다. **+** 메뉴에도 같은 항목과 함께 선택 가능한 모델, 그리고 컴퓨터에서 발견된 다른 에이전트 CLI가 있습니다.

- **⇧⌘] / ⇧⌘[** 또는 **⌃Tab**으로 탭을 이동하고, **⌃1…⌃9**로 바로 갑니다.
- **⇧⌘W**는 탭을, **⌘W**는 페인을 닫습니다.
- 탭 영역의 빈 공간을 더블클릭하면 새 탭이 열립니다.

새 탭은 워크스페이스의 폴더에서 시작합니다. **설정 → 일반**에서 매번 폴더를 묻도록 바꿀 수 있습니다.

## 페인

**⌘D**는 오른쪽으로, **⇧⌘D**는 아래로 분할합니다. **⌘] / ⌘[**로 페인을 이동하고, 경계를 끌어 크기를 조절합니다.

에이전트 페인에는 모델, 컨텍스트 창, 사용 한도, 브랜치, 폴더, 그리고 그 페인에서 돌고 있는 로컬 서버 포트를 보여주는 상태 바가 있습니다. 위치(터미널 위 또는 아래)와 표시 항목은 **설정 → 모양**에서 정합니다.

그 바(상태 표시 부분이나 끌 때 잡는 아이콘)를 더블클릭하면 해당 페인이 탭 전체를 차지합니다. 다시 더블클릭하면 원래 분할로 돌아갑니다.

## 사이드 패널

터미널 옆에 붙는 패널은 모두 가장자리를 끌어 크기를 조절할 수 있습니다.

| 패널 | 단축키 |
|---|---|
| 파일과 워크트리 | ⌥⌘B |
| 인앱 브라우저 | ⇧⌘B |
| Docker | 상태 바의 🐳 |
| 플러그인 패널 | 탭 영역의 버튼 |

## 미니 모드

**⌃⌘M**은 창을 화면 가장자리의 작은 상시 표시 패널로 접습니다. 작업을 마친 에이전트가 말풍선으로 떠오르고, 클릭하면 전체 창이 돌아옵니다.

macOS에서는 메뉴 바 아이콘이 에이전트가 일하는 동안 움직이고, 목록을 보여주며, 창을 닫아도 Agentty를 계속 실행해 둡니다.
