Agentty에는 세 단계가 있습니다. **워크스페이스**는 프로젝트, **탭**은 그 안의 한 화면, **페인**은 하나의 프로그램입니다. 페인은 셸이거나 AI 에이전트이거나 파일 편집기이거나 브라우저입니다.

## 워크스페이스

사이드바(**⌘B**)의 행 하나하나가 워크스페이스이고, 워크스페이스마다 열리는 폴더가 하나 있습니다. **⌘N**으로 만듭니다.

- 행을 드래그해 순서를 바꾸고, 하나를 다른 하나 위에 떨어뜨리면 **그룹**이 됩니다. 그룹은 접을 수 있습니다.
- 목록 위 검색창은 이름, 폴더, 그 안에서 나눈 대화 내용으로 워크스페이스를 찾습니다. 검색하는 동안 목록은 결과 화면으로 바뀌고, 결과마다 어디서 일치했는지 보여 줍니다. 이름이나 폴더일 수도 있고, 검색어가 표시된 대화 한 줄과 그 말을 한 쪽(나·에이전트·도구)일 수도 있습니다. **✕**나 **Esc**로 검색을 지우면 전체 목록이 돌아옵니다.
- 한 세션으로 연결된 워크스페이스는 연결을 시작한 워크스페이스 아래에 모입니다. 그 워크스페이스가 접힌 그룹 안에 있으면 나머지는 원래 자리에 그대로 보입니다.
- 이름을 더블클릭해 바꿉니다.
- **⌥⌘↓ / ⌥⌘↑**로 이동하고, **⌘1…⌘9**로 바로 갑니다.
- 워크스페이스와 그 탭·분할·그룹은 모두 재시작해도 그대로 돌아옵니다.

워크스페이스 행에 그 안의 에이전트 상태가 나오므로 열어 보지 않아도 어느 프로젝트가 나를 기다리는지 알 수 있습니다.

### 워크스페이스 메뉴

워크스페이스를 오른쪽 클릭하거나 **⋯** 를 누르면 메뉴가 열립니다. 폴더를 다루는 항목은 그 워크스페이스에서 선택한 창의 폴더를 씁니다.

| 항목 | 하는 일 |
|---|---|
| 다음에서 열기 › | 이 컴퓨터에 있는 편집기나 IDE(VS Code, Cursor, Zed, JetBrains IDE, Xcode 등) 또는 Finder로 폴더를 엽니다 |
| 경로 복사 | 폴더 경로를 복사합니다 |
| 워크트리 이름 복사 / 브랜치 이름 복사 | 별도 워크트리면 그 이름을, 아니면 브랜치 이름을 복사합니다 |
| 고정 | 워크스페이스를 그룹 맨 위에 둡니다 |
| 읽지 않은 것으로 표시 | 열어 볼 때까지 카드에 알림 표시를 띄웁니다 |
| 새 그룹, 그룹으로 이동 ›, 그룹에서 빼기 | 워크스페이스를 그룹으로 정리합니다 |
| 상위 워크트리 설정… | 고른 워크스페이스 아래에 들여 써서 보여 줍니다. 그룹을 옮기면 함께 옮겨집니다 |
| 잠자기 | 워크스페이스의 프로그램을 모두 끝내고 상태는 그대로 둡니다. 다시 열면 탭을 시작하고 에이전트 세션을 이어 갑니다 |
| 작업 트리 삭제 | 워크스페이스를 닫고 그 워크트리와 브랜치를 지웁니다. 커밋하지 않은 변경과 다른 곳에 없는 커밋은 남겨 둡니다 |

## 탭

**⌘T**는 터미널, **⌥⌘C**는 Claude Code, **⌥⌘X**는 Codex 탭을 엽니다. **+** 메뉴에도 같은 항목이 있고, 고를 수 있는 모델과 컴퓨터에서 찾은 다른 에이전트 CLI도 나옵니다.

- **⇧⌘] / ⇧⌘[** 또는 **⌃Tab**으로 탭을 이동하고, **⌃1…⌃9**로 바로 갑니다.
- **⇧⌘W**는 탭을, **⌘W**는 페인을 닫습니다.
- 탭 영역의 빈 공간을 더블클릭하면 새 탭이 열립니다.

새 탭은 워크스페이스의 폴더에서 시작합니다. **설정 → 일반**에서 매번 폴더를 묻도록 바꿀 수 있습니다.

## 페인

**⌘D**는 오른쪽으로, **⇧⌘D**는 아래로 분할합니다. **⌘] / ⌘[**로 페인을 이동하고, 경계를 끌어 크기를 조절합니다.

에이전트 페인에는 상태 바가 있습니다. 모델, 컨텍스트 창, 사용 한도, 브랜치, 폴더, 그 페인에서 돌고 있는 로컬 서버 포트가 나옵니다. 위치(터미널 위 또는 아래)와 표시 항목은 **설정 → 모양**에서 정합니다.

이 바(상태 표시 부분이나 끌 때 잡는 아이콘)를 더블클릭하면 그 페인이 탭 전체를 차지합니다. 다시 더블클릭하면 원래 분할로 돌아갑니다.

페인 헤더에는 폴더 이름만 표시되고, 전체 경로는 상태 바에 있습니다.

## 사이드 패널

터미널 옆에 붙는 패널은 모두 가장자리를 끌어 크기를 조절할 수 있습니다.

| 패널 | 단축키 |
|---|---|
| 파일과 워크트리 | ⌥⌘B |
| 인앱 브라우저 | ⇧⌘B |
| Docker | 상태 바의 🐳 |
| 플러그인 패널 | 탭 영역의 버튼 |

## 미니 모드

**⌃⌘M**은 창을 화면 가장자리의 작은 상시 표시 패널로 접습니다. 작업을 마친 에이전트가 말풍선으로 떠오르고, 클릭하면 전체 창이 돌아옵니다.

macOS에서는 에이전트가 일하는 동안 메뉴 바 아이콘이 움직이고, 아이콘에서 에이전트 목록을 볼 수 있습니다. 창을 닫아도 메뉴 바 아이콘 덕분에 Agentty는 계속 실행됩니다.

메뉴 바 팝오버의 미니 모드 버튼 옆에는 컴퓨터의 **CPU**와 **RAM** 사용률도 나옵니다. 팝오버가 열려 있는 동안 2초마다 갱신되고, 85% 이상이면 주황색으로 바뀝니다.
