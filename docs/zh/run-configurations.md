---
title: 运行配置
description: 一键启动项目的开发服务器或应用，并在终端旁的运行日志中查看输出。
---

Agentty 会像 IDE 一样找出项目中可以运行的内容，并在窗格标题栏放一个 **运行** 按钮（标签页只有一个窗格时放在标签栏）。运行不会向终端输入任何内容：输出显示在终端下方停靠的运行日志中。

## 能找到什么

| 项目 | 运行配置 |
|---|---|
| Node（`package.json`） | 根包的全部脚本；下级包中会启动东西的脚本（`dev`、`start`、`serve`、`preview`、`watch`、`storybook`）。包管理器由 `packageManager` 或锁文件决定：npm、pnpm、yarn 或 bun |
| Spring Boot（Gradle 或 Maven） | 每个应用一个；有 wrapper 时通过 wrapper 运行，也支持多模块构建 |
| 其他 | 用 **添加命令…** 自己添加的命令（名称可选），保存在该项目中 |

查找时只读取文件，不运行任何构建工具。会查看项目文件夹及其下两层（`web/`、`apps/admin/`），并跳过依赖和构建输出文件夹。

## 运行

- 按钮旁的 **⌄** 列出项目的配置，最近运行过的排在最前。在列表中点选只会选中它并显示在按钮上，要启动请点 **运行**。
- **运行** 启动该配置。运行期间按钮变为 **停止** 和 **重新启动**。
- 状态栏显示 **运行**（或正在运行的数量）。点击后会列出各配置的状态和端口，以及项目中所有正在监听端口的进程，每个都可以停止或在浏览器中打开。Windows 上不显示端口。
- 如果因端口被占用而运行失败，日志会显示占用该端口的进程，并提供 **结束并重新运行**，但仅当该进程属于此项目时。其他进程如确定，请在已打开的端口列表中自行结束。

## 运行日志

一个面板，每次运行一个标签页。你可以：

- 按关键词或正则表达式筛选行（可选区分大小写）
- 只显示某个级别及以上的行（显示各级别的行数）
- 自动换行，跟随最新一行或自由向上滚动
- Cmd-点击（Ctrl-点击）地址将其打开

颜色会保留，进度行会合并为一行。拖动面板上边缘可调整高度，高度会被保存。隐藏日志不会停止运行。

## 退出 Agentty 时

运行会随 Agentty 一起结束：退出时会停止运行，崩溃后遗留的运行会在下次启动时被停止。
