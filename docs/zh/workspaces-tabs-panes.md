---
title: 工作区、标签页与窗格
description: Agentty 的组织方式 —— 每个项目一个工作区，里面是标签页，标签页里是窗格。
---

Agentty 有三层结构：**工作区**是一个项目，**标签页**是其中的一个画面，**窗格**是一个程序 —— shell、AI 智能体、文件编辑器或浏览器。

## 工作区

侧边栏（**⌘B**）中的每一行就是一个工作区，各自带着要打开的文件夹。**⌘N** 新建一个。

- 拖动行可重新排序，把一行拖到另一行上会形成**分组**，分组可以折叠；右键点击分组标题可重命名、设置颜色、**全部休眠**或删除。
- 列表上方的搜索框按名称、文件夹以及其中的对话内容查找工作区。搜索时列表会变成结果视图，每个结果都会说明在哪里匹配——名称、文件夹，或标出搜索词的一行对话以及说这句话的一方（我、智能体、工具）。按 **✕** 或 **Esc** 清除搜索，整个列表就会回来。
- 连接成一个会话的工作区会集中显示在发起连接的工作区下面。如果那个工作区在折叠的分组里，其余工作区会留在原来的位置显示。
- 双击名称即可重命名。
- **⌥⌘↓ / ⌥⌘↑** 在工作区之间移动，**⌘1…⌘9** 直接跳转。
- 所有工作区及其标签页、分屏和分组，重启后都会原样回来。
- 列表标题上的 **⚙** 打开 **工作区选项**：卡片布局（详细、紧凑，以及详细卡片是否列出运行中的子智能体——最多 5 个，其余合并为“+N”，点击打开子智能体窗口）、分组（无、你的分组、按项目——仓库与其工作树放在一起，项目也能像分组一样折叠）、排序（手动、最近活动、名称）、筛选（隐藏休眠的工作区、`main`/`master` 分支、插件工作区），以及标签页是否放在标题栏。当前所在的工作区始终会列出。

在 macOS 上，标签页位于窗口按钮旁的标题栏中，旁边是侧边栏按钮（**⌘B**）；双击标题栏空白处可缩放窗口。若想让标签页单独占一行，在工作区选项中关闭 **标签页放在标题栏**。

工作区那一行会显示其中智能体的状态，所以不用打开就能看出哪个项目在等你。

### 工作区菜单

右键点击工作区，或点它的 **⋯**，即可打开菜单。涉及文件夹的项目使用该工作区中所选窗格的文件夹。

| 项目 | 作用 |
|---|---|
| 打开方式 › | 用本机上的编辑器或 IDE（VS Code、Cursor、Zed、JetBrains IDE、Xcode 等）或访达打开文件夹 |
| 复制路径 | 复制文件夹路径 |
| 复制工作树名称 / 复制分支名称 | 在独立工作树中复制其名称，否则复制分支名称 |
| 置顶 | 让工作区保持在所在分组的最上方 |
| 标记为未读 | 在打开之前，卡片上显示提醒标记 |
| 新建分组、移动到分组 ›、移出分组 | 把工作区整理到分组中 |
| 设置上级工作树… | 将工作区缩进显示在所选工作区下方；移动分组时会一起移动 |
| 休眠 | 结束工作区中的所有程序并保留其状态；卡片会变淡并显示月亮标记，Agentty 启动后尚未打开的工作区也一样。再次打开时会启动它的标签页并继续代理会话 |
| 删除工作树 | 关闭工作区并删除其工作树和分支。未提交的更改和其他地方没有的提交会被保留 |

## 标签页

**⌘T** 打开终端标签页，**⌥⌘C** 打开 Claude Code，**⌥⌘X** 打开 Codex。**+** 菜单里有同样的项，另外还有可选的模型和在你机器上发现的其他智能体 CLI。

- **⇧⌘] / ⇧⌘[** 或 **⌃Tab** 切换标签页，**⌃1…⌃9** 直接跳转。
- **⇧⌘W** 关闭标签页，**⌘W** 关闭窗格。
- 双击标签栏的空白处可新建标签页。
- 右键点击标签页并选择 **稍后处理** 可将其搁置：其中运行的内容会停止，并列在开始页标签旁的 **TODO** 按钮中。在那里点击即可重新启动，代理会接着之前的会话继续。

新标签页从工作区的文件夹开始。也可以在**设置 → 常规**中改为每次询问文件夹。

## 窗格

**⌘D** 向右分屏，**⇧⌘D** 向下分屏。**⌘] / ⌘[** 在窗格间移动，拖动分隔线可调整大小。

每个智能体窗格都有一条状态栏，显示模型、上下文窗口、用量限额、分支、文件夹，以及该窗格中运行的本地服务器端口。它的位置（终端上方或下方）以及显示哪些项，在**设置 → 外观**中设定。

双击这条栏——状态部分，或用于拖动的图标——可让该窗格占满整个标签页。再次双击即可恢复原来的分屏。

窗格标题只显示文件夹名称，完整路径在状态栏中。

## 侧边面板

停靠在终端旁的面板都可以拖动边缘调整宽度：

| 面板 | 快捷键 |
|---|---|
| 文件与工作树 | ⌥⌘B |
| 内置浏览器 | ⇧⌘B |
| Docker | 状态栏的 🐳 |
| 插件面板 | 标签栏中的按钮 |

## 迷你模式

**⌃⌘M** 把窗口折叠成屏幕边缘的小型置顶面板。完成工作的智能体会以气泡弹出，点击即可恢复完整窗口。

在 macOS 上，菜单栏图标会在智能体工作时动起来，列出它们，并在你关闭窗口后让 Agentty 继续运行。

菜单栏弹出面板还会在迷你模式按钮旁显示电脑的 **CPU** 和 **RAM** 负载。弹出面板打开期间每 2 秒刷新一次，达到 85% 及以上时显示为橙色。
