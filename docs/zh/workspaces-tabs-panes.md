---
title: 工作区、标签页与窗格
description: Agentty 的组织方式 —— 每个项目一个工作区，里面是标签页，标签页里是窗格。
---

Agentty 有三层结构：**工作区**是一个项目，**标签页**是其中的一个画面，**窗格**是一个程序 —— shell、AI 智能体、文件编辑器或浏览器。

## 工作区

侧边栏（**⌘B**）中的每一行就是一个工作区，各自带着要打开的文件夹。**⌘N** 新建一个。

- 拖动行可重新排序，把一行拖到另一行上会形成**分组**，分组可以折叠。
- 双击名称即可重命名。
- **⌥⌘↓ / ⌥⌘↑** 在工作区之间移动，**⌘1…⌘9** 直接跳转。
- 所有工作区及其标签页、分屏和分组，重启后都会原样回来。

工作区那一行会显示其中智能体的状态，所以不用打开就能看出哪个项目在等你。

## 标签页

**⌘T** 打开终端标签页，**⌥⌘C** 打开 Claude Code，**⌥⌘X** 打开 Codex。**+** 菜单里有同样的项，另外还有可选的模型和在你机器上发现的其他智能体 CLI。

- **⇧⌘] / ⇧⌘[** 或 **⌃Tab** 切换标签页，**⌃1…⌃9** 直接跳转。
- **⇧⌘W** 关闭标签页，**⌘W** 关闭窗格。
- 双击标签栏的空白处可新建标签页。

新标签页从工作区的文件夹开始。也可以在**设置 → 常规**中改为每次询问文件夹。

## 窗格

**⌘D** 向右分屏，**⇧⌘D** 向下分屏。**⌘] / ⌘[** 在窗格间移动，拖动分隔线可调整大小。

每个智能体窗格都有一条状态栏，显示模型、上下文窗口、用量限额、分支、文件夹，以及该窗格中运行的本地服务器端口。它的位置（终端上方或下方）以及显示哪些项，在**设置 → 外观**中设定。

双击这条栏——状态部分，或用于拖动的图标——可让该窗格占满整个标签页。再次双击即可恢复原来的分屏。

## 侧边面板

停靠在终端旁的面板都可以拖动边缘调整宽度：

| 面板 | 快捷键 |
|---|---|
| 文件与工作树 | ⌥⌘B |
| 内置浏览器 | ⇧⌘B |
| Docker | 状态栏的 🐳 |
| 插件面板 | 标签栏中的按钮 |

## 迷你模式

**⌃⌘M** 把窗口折叠成屏幕边缘的小型置顶面板。完成工作的智能体会以气泡弹出，点击即可恢复完整窗口。

在 macOS 上，菜单栏图标会在智能体工作时动起来，列出它们，并在你关闭窗口后让 Agentty 继续运行。
