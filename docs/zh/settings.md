**⌘,** 打开设置。更改立即生效，并保存到 `~/.agentty/settings.json`。

## 常规

语言（English、한국어、日本語、中文），以及你每天都会碰到的那些行为：

| 设置 | 作用 |
|---|---|
| 从想法开始 | 在起始页和 + 菜单中提供想法页面 |
| 智能体状态栏 | AI 窗格上方的状态栏，以及它位于终端上方还是下方 |
| 关闭前确认 | 关闭用过的窗格、标签页或工作区前先询问 |
| 每个会话独立工作树 | 繁忙项目中的第二个会话获得自己的 git 工作树 |
| 在工作区列表上方显示搜索框 | 搜索工作区名称及其中的对话内容 |
| 将已完成的工作区移到顶部 | 关闭时保留你自行排列的顺序 |
| 并行任务 | 允许智能体请求在分屏窗格中开始任务，每次都要你确认 |
| 告知智能体 Agentty 的功能 | 从这里启动的智能体会通过命令行收到 Agentty 命令的简短说明 |
| 关闭时停止服务器 | 关闭窗格时停止其中启动的本地服务器 |
| 同意收集匿名使用统计 | 参见[使用统计](/docs/telemetry) |
| 菜单栏图标 | 关闭窗口后仍让 Agentty 继续运行（macOS） |
| 防止休眠 | 保持设备唤醒，避免长时间无人值守的任务被中断。可设为始终，或指定 1 至 72 小时。更耗电 |

## 项目

新标签页从哪里开始、Agentty 查找的 harness 模式、harness 提示词是否立即发送，以及由哪个智能体开始 harness 工作。**在编辑器中打开**使用哪个编辑器也在这里。

## 账号

新的 Claude Code 与 Codex 标签页如何登录。默认不改变任何东西 —— 智能体使用它们自己的登录。备选方式以及凭据的存放位置，见[扩展、MCP 与连接器](/docs/mcp-and-connectors)。

## 外观

主题、字体、字号、行高、字间距、加粗文字，背景、文字、光标与选中区域的自定义颜色，光标形状与闪烁、内边距、回滚缓冲。智能体状态栏显示哪些项、按什么顺序也在这里。参见[主题与字体](/docs/themes)。

## 键盘快捷键

完整列表，以你所在平台的表示法显示。参见[键盘快捷键](/docs/keyboard-shortcuts)。

## 通知

系统通知、Agentty 处于前台时是否通知，以及发往 Slack、Discord 或 Telegram 的通知。参见[智能体状态](/docs/agent-status)。

## 浏览器

链接在内置浏览器还是默认浏览器中打开、开发服务器是否自动打开，以及搜索引擎。

## 系统检查

Agentty 所用的工具及其安装情况 —— Git、Node.js、智能体 CLI。缺少的工具可以从这里在新标签页中安装。

版本、检查更新，以及相关链接 —— 包括[隐私政策](https://www.agentty.run/privacy-policy)、[服务条款](https://www.agentty.run/terms-of-service)和[许可协议](https://www.agentty.run/eula)。
