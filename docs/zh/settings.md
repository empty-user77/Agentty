**⌘,** 打开设置。更改立即生效，并保存到 `~/.agentty/settings.json`。

侧边栏把页面分为 **常规**、**AI**、**工作**、**连接与数据** 和 **系统**。上方的搜索框可以按名称或说明查找所有页面中的设置，选择结果即跳到该页面并标出那项设置。

## 常规

语言（English、한국어、日本語、中文、Deutsch）、**外观**（跟随系统、深色、浅色），以及你每天都会碰到的那些行为。外观设为跟随系统时，会随 macOS 设置切换。无论哪种外观，终端都保留在终端样式中选择的主题：

| 设置 | 作用 |
|---|---|
| 从想法开始 | 在起始页和 + 菜单中提供想法页面 |
| 关闭前确认 | 关闭用过的窗格、标签页或工作区前先询问 |
| 每个会话独立工作树 | 繁忙项目中的第二个会话获得自己的 git 工作树 |
| 在工作区列表上方显示搜索框 | 搜索工作区名称及其中的对话内容 |
| 将已完成的工作区移到顶部 | 关闭时保留你自行排列的顺序 |
| 关闭时停止服务器 | 关闭窗格时停止其中启动的本地服务器 |
| 同意收集匿名使用统计 | 参见[使用统计](/docs/telemetry) |
| 菜单栏图标 | 关闭窗口后仍让 Agentty 继续运行（macOS） |
| 防止休眠 | **开启** 让电脑保持唤醒（始终，或 1 到 72 小时），**智能体** 只在智能体工作时保持，**关闭** 按平常休眠。也可以点状态栏的杯子图标切换 |

## AI 设置

Agentty 为智能体会话添加的功能：

| 设置 | 作用 |
|---|---|
| Claude Advisor | 新 Claude 标签页使用的 [Advisor](/docs/advisor) |
| 在状态栏显示 Advisor | 默认关闭。开启后 Claude 标签页的状态栏会显示 Advisor，并可只为该标签页更换 |
| AI CLI 状态栏 | AI 窗格上方的栏，以及放在终端上方还是下方 |
| 告诉智能体 Agentty 的用法 | 在这里启动的智能体会通过命令行收到 Agentty 命令说明 |
| 并行任务 | 智能体可请求在分屏窗格中启动任务；每次请求都需确认 |

## 智能体

这台电脑上的智能体 CLI。**智能体权限** 决定 Claude Code 和 Codex 标签页是否以 YOLO（Bypass）模式启动。**已安装** 列出找到的智能体及其版本和命令；设为 **停用** 后，它不会出现在启动菜单、起始页和命令面板中（仍保持安装）。新装了智能体后请点 **刷新**。**可安装** 列出安装 CLI 后即可在 Agentty 中启动的智能体。点 **安装** 会在新的终端标签页中运行厂商的官方安装命令，链接则打开其官网（没有官方安装命令的智能体只提供官网链接）。

展开 **Claude Code** 可看到保存在 Claude Code 用户设置（`~/.claude/settings.json`，或 `$CLAUDE_CONFIG_DIR`）中的自身功能：**智能体团队**（主导会话启动并协调成员会话，实验功能）、**始终深度思考** 和 **自动更新**。只写入开关对应的键，文件其余部分保持不变；不是有效 JSON 的文件不会被改动。新的 Claude Code 会话开始生效。**Codex** 可打开它的 `~/.codex/config.toml`。

## 集成

Agentty 配合使用的外部服务，每个服务一张卡片并显示是否已连接；展开卡片即可设置。

- **GitHub** — 拉取请求、克隆和同步通过 GitHub CLI（`gh`）及其自身登录完成，Agentty 不保存任何内容。**在终端中登录** 会在新标签页运行 `gh auth login`。
- **Slack、Discord、Telegram** — 通知的发送目标。Webhook URL 或机器人令牌保存在系统凭据存储中；**向这里发送通知** 可逐个开关服务。发送内容在 通知 中设置。
- **Jira** — 开发看板导入工单所用的站点、邮箱和 API 令牌。

## 项目

新标签页从哪里开始、Agentty 查找的 harness 模式、harness 提示词是否立即发送，以及由哪个智能体开始 harness 工作。**在编辑器中打开**使用哪个编辑器也在这里。文件编辑器的语言服务器列表，以及为缺少的语言服务器准备的安装按钮，也在这里。 文件编辑器的选项（行尾显示问题、输入时补全、显示指针下的类型、粘性滚动）也在这里开关。

## 窗口

每个 Agentty 窗口（**⇧⌘N** 打开新窗口）都有自己的工作区列表。此页面列出已打开和最近关闭的窗口，以及每个窗口中的工作区和仍在运行的终端数。点击工作区即可跳转过去。**调到前面**显示已打开的窗口，**重新打开**再次打开已关闭的窗口，**删除**会先询问，然后关闭窗口并删除其中的工作区；对话仍保留在会话列表中。主窗口无法删除。

## 账号

新的 Claude Code 与 Codex 标签页如何登录。默认不改变任何东西 —— 智能体使用它们自己的登录。备选方式以及凭据的存放位置，见[扩展、MCP 与连接器](/docs/mcp-and-connectors)。

## 外观

主题、字体、字号、行高、字间距、加粗文字，背景、文字、光标与选中区域的自定义颜色，光标形状与闪烁、内边距、回滚缓冲。智能体状态栏显示哪些项、按什么顺序也在这里。参见[主题与字体](/docs/themes)。

## 键盘快捷键

完整列表，以你所在平台的表示法显示。参见[键盘快捷键](/docs/keyboard-shortcuts)。

## 通知

系统通知、Agentty 在前台时是否也通知，以及发送到聊天服务的内容（完成通知、请求详情、屏幕上的会话）。Slack、Discord、Telegram 的连接在 **集成** 中完成。参见 [智能体状态](/docs/agent-status)。

## 同步

工作区和智能体会话通过你自己的私有 Git 仓库（通过 `gh` 的 GitHub，或任意 SSH URL）在多台电脑之间延续。列表中只显示空的私有仓库或已用于同步的仓库。工作区会在智能体完成一轮、关闭标签页、空闲时每 5 分钟以及按下 **立即同步** 时同步；同步失败会自动重试。

**这台电脑（SQLite）** 不需要仓库、账号或安装：所有内容都存进一个文件 `~/.agentty/sessions.sqlite`（使用 macOS 和 Linux 自带的 SQLite；在 Windows 上则内置于 Agentty）。它是这台电脑上会话的备份：即使会话从智能体自己的文件夹（`~/.claude`、`~/.codex`）中消失，也可以在同步弹窗中用 **继续** 从文件恢复。设置 → 同步会显示文件大小和 **在文件夹中显示**。要迁移备份，把文件复制到另一台电脑的 `~/.agentty` 并在那里选择 **这台电脑（SQLite）**，会话就会恢复。断开连接后文件仍会保留。它不会自动与其他电脑共享；要共享请使用 Git 仓库。两者同时使用：连接仓库后打开 **同时保存一份 SQLite 副本**，每次同步后仓库的内容（所有电脑的会话）也会保存到同一个文件中，即使没有仓库也能作为备份。

打开 **同步设置** 并按 **保存** 后，设置、自定义命令、连接器、导入的主题和插件设置也会保持一致，以最新的更改为准；新加入的电脑会采用仓库中已有的设置。密钥（API 密钥、令牌、密码）不会同步，请在每台电脑上输入一次。看起来包含密钥的部分（例如写了令牌的自定义命令）只留在那台电脑上，也不会被其他电脑的版本替换，同步弹窗会指出是哪一部分。

**清理旧会话** 防止仓库无限增长（GitHub 私有仓库的容量并非无限）：30、90、180、365 天（或自定义天数）未变化的会话不再同步，从仓库删除前会先在同步弹窗中确认。期限属于仓库，所有电脑使用同一个值。

每台电脑通过 Agentty 保存在 `~/.agentty/computer-id` 的 ID 区分（不读取硬件信息）；删除 `~/.agentty` 后会显示为一台新电脑。用 **同时删除同步数据** 删除工作区，会在所有电脑上删除。仓库会保留每个版本，也可以当作备份。仓库必须保持私有：公开期间同步会停止。

## 备份

**导出配置** 会把整个配置保存为一个 `.agenttyconfig` 文件：设置、自定义命令、连接器、数据库连接、智能体登录方式、导入的主题、已安装插件列表及插件设置。面板尺寸、最近的文件夹等只属于某台电脑的内容不包含在内。打开 **包含密钥** 后，凭据存储中的 API 密钥、令牌、密码以及包含密钥的插件设置会用你设定的密码加密后写入（PBKDF2 + AES-256-GCM）；Agentty 不会保存该密码。

**导入配置** 会用文件中的配置替换这台电脑的配置：设置以文件为准，这台电脑的面板尺寸和最近的文件夹保持不变；命令、连接器等其他文件整体替换。密码留空则导入除密钥以外的全部内容。缺少的插件可以从插件市场或其 Git 仓库安装。每次导入前的配置都保存在 `~/.agentty/backups/`。
