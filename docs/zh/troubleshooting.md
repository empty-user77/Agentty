---
title: 故障排查
description: 常见的出错情形，以及该怎么办。
---

## 智能体没有出现，或启动不了

Agentty 只提供能在你**登录 shell** 的 `PATH` 中找到的智能体 CLI。如果某个工具在终端里能用、在这里却不行，多半是 `PATH` 写在了只有交互式 shell 才读取的文件里（`.zshrc`、`.bashrc`）。把 export 移到登录 shell 会读取的位置，或查看**设置 → 系统检查**，它会列出缺失项并替你安装。

## 窗格状态一直是空的

状态来自 Agentty 在启动窗格时传给智能体的钩子。

- 在 Windows 上，Claude Code 通过 Git Bash 运行钩子 —— 请安装 **Git for Windows**。
- 如果你是在已有的 shell 里自己启动智能体，它没有钩子。请改从 **+** 菜单打开。

## 智能体改错了文件

同一个文件夹里的两个会话必然冲突。打开**设置 → 常规 → 每个会话独立工作树**，第二个会话就会拥有自己的 git 工作树和分支。[文件面板](/docs/agent-git)会显示每个工作树及其改动。

## 关了标签页，开发服务器还在跑

**设置 → 常规 → 关闭时停止服务器**会在你关闭窗格时结束它启动的服务器。监控 → **进程**会列出仍在运行的内容。

## 用量数字看起来不对

它们由磁盘上的会话记录计算得出，且只有 Claude 模型的价格是内置的。其他模型请在 `~/.agentty/pricing.json` 中添加价格 —— 参见[配置参考](/docs/configuration-reference)。这些数字是估算，以提供方的账单为准。

## 插件不出现或停止运行

- JavaScript 插件需要登录 shell 的 `PATH` 中有 **Node.js 18 及以上**。
- 文件夹名必须与 `agentty-plugin.json` 中的 `id` 一致。复制进去后请点**刷新**。
- 插件卡片上的**日志**会显示它输出的内容，包括崩溃。改完代码后点**重启**。

更多内容见[使用插件](/docs/plugins-overview)。

## `agentty://` 链接没有反应

链接在已安装的应用程序中生效，以开发方式启动的构建则不行。请确认链接指定的插件已安装并启用。

## 无法更新

更新从 GitHub 下载并在使用前校验。若因代理或被阻断的主机导致失败，请到[发布页面](https://github.com/empty-user77/Agentty/releases)手动获取安装文件。

## 仍然没解决

请到[问题跟踪](https://github.com/empty-user77/Agentty/issues)反馈，并附上你的 Agentty 版本（**设置 → 关于 Agentty**）、操作系统，以及你期望的行为。粘贴日志或截图前请先遮蔽凭据。

安全问题请私下报告，不要开公开 issue。
