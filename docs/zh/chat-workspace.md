---
title: 聊天工作区
description: 在聊天中与一个主控智能体对话，同时在下方观看它分派工作的最多 4 个工作智能体。
---

聊天工作区上方是对话，下方是一组智能体。你在聊天中与一个 **主控智能体**（Claude Code）对话。它负责规划工作，并把工作拆分交给 **工作智能体**。每个工作智能体在聊天下方网格中的独立终端里运行，你可以一次看到整个团队的进展。

## 打开方式

- 在开始页面（或 **新建工作区**）选择 **聊天 · 团队**，然后选择项目文件夹。
- 或在标签页旁的 **+** 菜单中选择 **新建聊天工作区**。

主控智能体直接在项目文件夹中工作。每个工作智能体都有自己的 git 工作树，位于基于项目默认分支新建的分支上，因此它们不会修改相同的文件。

## 工作方式

1. 在聊天中输入。**Enter** 发送，**Shift+Enter** 换行。
2. 小事主控智能体自己处理。较大的工作，它会先制定计划，再用 `agentty tasks` 启动工作智能体。在聊天工作区中，它们会立即启动，不弹出通常的确认对话框：打开聊天即表示同意。
3. 工作智能体出现在聊天下方的网格中，每行两个，同时最多 **4** 个。四个位置都占满时，最早完成的工作智能体会关闭，为下一个腾出位置。它的分支和会话会保留，可以从会话列表中继续。
4. 工作智能体结束一个回合后，Agentty 会向主控智能体发送简短报告，包括工作智能体的标题、分支、文件夹和最后的回复。主控智能体检查工作后，在聊天中告诉你结果，或者给该工作智能体发送后续指示。

聊天上方的栏显示主控智能体的状态，以及每个工作智能体的标签。点击标签即可跳到该工作智能体的终端。如果某个工作智能体在等你（审批或回答问题），聊天中也会提示。

## 主控智能体的终端

聊天是真实 Claude Code 会话的视图。点击栏上的 **终端** 显示主控智能体的终端，点击 **聊天** 返回。遇到只能在终端中回答的情况时，终端会自动出现：

- 首次运行时确认是否信任文件夹，或需要登录
- 主控智能体请求工具审批或提出问题

在终端中回答后会回到聊天。在此期间到达的工作智能体报告，会等主控智能体空闲时再交给它。

## 主控智能体使用的命令

| 命令 | 作用 |
|---|---|
| `agentty tasks --plan <plan.json>` / `--title … --prompt-file …` | 启动工作智能体（这里不弹对话框） |
| `agentty tasks status` | 列出工作智能体及各自的状态 |
| `agentty tasks send --to <标题> --prompt <内容>` | 给工作智能体发送后续消息 |

`status` 和 `send` 只有聊天工作区的主控智能体能用，且只能用于它自己的工作智能体。

## 须知

- 工作智能体在各自的分支上提交。只有在你向主控智能体提出要求时，才会推送或创建拉取请求。主控智能体只会在你要求，或你批准了包含合并的计划时，才合并分支。
- 每个工作智能体都是完整的智能体会话，四个同时工作会比一个更快消耗套餐额度。
- 拖动聊天与网格之间的分隔线，可以调整两者大小。布局会随工作区一起保存。
- 在设置中关闭 **智能体可启动并行任务**，聊天的主控智能体也将无法启动工作智能体。
