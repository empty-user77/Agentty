插件把 Agentty 与其他应用连起来，并为终端增添工具。插件可以在终端旁放一个**面板**、在智能体窗格上方添加**按钮**、往**命令面板**里加条目，以及把文本作为**提示词**交给智能体。这条提示词发往哪里，除非插件主动问你，否则由插件自己决定——所以卡片上的权限值得一读。

想自己写一个？从[插件快速开始](/docs/plugin-quickstart)开始。

## 插件页面

从活动栏的拼图图标、**视图 → 插件**，或命令面板（⇧⌘P →“插件”）打开。

- **已安装** —— 你拥有的所有插件，以及它们添加了什么、能做什么。
- **市场** —— Agentty 提供的插件列表，包括它自己的。见下文。
- **可用** —— 随 Agentty 附带的插件。若其集成的应用已安装，会标记为**推荐**。
- **自己构建** —— 用 AI 创建插件，或从 Git 仓库、文件夹安装。

每个已安装的插件都有**启用 / 禁用**、**打开面板**、**重启**（改完代码后）、**更新**（内置版本有更新时）、**日志**（插件的输出，包括崩溃）、**在访达中显示**和**卸载**（按两次确认）。

插件在首次被使用时才启动，而不是随 Agentty 启动，因此闲置的插件不占用任何开销。

## 安装

| 来源 | 方式 |
|---|---|
| 市场 | 在*市场*卡片上点**安装** |
| 内置 | 在*可用*卡片上点**安装** |
| Git 仓库 | 在*自己构建*下粘贴 `https://` 地址 → **从 Git 安装** |
| 文件夹 | **从文件夹安装…** 会复制到 `~/.agentty/plugins/` |
| 正在编辑的文件夹 | **链接开发文件夹…** 直接在原地运行；卸载只会解除链接 |

你也可以自己把插件文件夹复制到 `~/.agentty/plugins/`，然后点**刷新**。

## 你在信任什么

安装前，卡片会在**权限**下用完整句子列出这个插件可以做的事：发送 HTTP 请求、启动智能体会话、向终端输入、读取 AI 对话、查看工作区。

**关于 → 运行方式**还会说明它属于截然不同的哪一种：

| | |
|---|---|
| **WebAssembly** | Agentty 自己运行这个模块。它没有自己的文件、进程和网络，**不管怎么写**都只能碰到这些权限允许的东西。 |
| **程序**（`node`、`python`、可执行文件） | 以你的身份运行，拥有和你启动的任何东西一样的访问权限。权限管的是它经由 Agentty 做的事，程序本身没人管。 |

> [!IMPORTANT]
> 程序型插件，只在你信任作者时才安装。市场里的全是前一种，这正是从一份列表里安装二进制文件仍然可靠的原因。

完整的机制见[插件权限](/docs/plugin-permissions)。

## 插件市场

**插件 → 市场**展示 [Agentty-Marketplace](https://github.com/empty-user77/Agentty-Marketplace) 提供的列表。插件通过 pull request 添加，收录的只有**源码公开的 WebAssembly 模块**。Agentty 自己的插件也在那里，条件完全一样——应用里没有内置任何插件。

安装一个插件时：

1. Agentty 通过 HTTPS 读取列表，并在这里重新检查每一条——id、文案、权限、模块来自哪个主机。没通过的条目会被排除在列表之外，而不是照样显示。
2. 卡片会展示它是什么、源码在哪、许可证、模块大小和校验和，以及它能做什么。
3. 按下**安装**后，Agentty 下载模块并与那个校验和比对。**不一致之前，插件文件夹里不会进入任何东西。**

条目里还写明了模块面向的插件协议版本。只懂旧版本的 Agentty 仍会把插件列出来，但会说需要更新 Agentty，而不是让你安装。

只给自己用的插件不必经过那份列表——**从文件夹安装…** 和**从 Git 安装**什么都收。

## 使用

- **面板** —— 带面板的插件会出现一个按钮，位置由插件自己挑：终端上方的标签栏、左侧边缘的活动栏，或底部的状态栏。点击打开面板，再点一次关闭。面板标题栏的 ↻ 会重启插件，齿轮打开插件页面。
- **命令面板** —— ⇧⌘P 的*插件*分组下列出所有插件命令。

### 面板在哪里打开

面板上的布局按钮可以改变它的打开方式，你的选择会被记住：

| | |
|---|---|
| **停靠** | 靠在终端旁边，终端让出位置 |
| **浮动** | 浮在窗口右侧边缘，其他东西不动 |
| **独立窗口** | 单独一个窗口，可移动、可调整大小 |
| **全屏** | 终端和页面所占的整个区域 |

停靠的面板不会大到把窗口其余部分挤扁：拖过可停靠的范围，它就变成浮动面板。

### “发送到…”对话框

当插件或来自其他应用的链接发送提示词时，Agentty 会显示将要发送的内容并让你选择：

- **Claude Code / Codex / 终端**
- **新建工作区**（可更改文件夹）、当前工作区的**新标签页**，或某个**已打开的工作区**——其中空闲的智能体会接收，否则会新开一个智能体标签页
- **立即发送**，或取消勾选以便只输入文本而不按回车

终端只会被输入文本——通过这条路发出的提示词不会替你按回车。在你点击**发送**之前什么都不会发出。

`terminal.write` 是另一回事：拿着这个权限的插件会往已打开的终端里输入**并按下回车**，在 shell 里也一样，那就是执行命令。它前面没有任何对话框，这也正是卡片把它单列出来的原因。

## 来自其他应用的链接

其他应用可以通过 `agentty://` 链接把工作交给 Agentty，例如 Cosmica 的“在 Agentty 中继续”。

| 链接 | 效果 |
|---|---|
| `agentty://plugin/<id>/<path>?key=value` | 启动插件 `<id>` 并调用其 URL 处理器 |
| `agentty://prompt?text=…&title=…&agent=…&cwd=…` | 用该文本打开**发送到…**（`file=` 可附带绝对路径的 `.md` / `.txt`） |
| `agentty://plugins/<id>` | 打开插件页面并定位到该插件 |

若链接需要的内置插件尚未安装，Agentty 会提示安装并随后继续处理该链接。通过这种方式到达的提示词始终会经过**发送到…**。

> [!NOTE]
> 链接在已安装的应用程序中生效。以开发方式启动的构建不会被操作系统注册为 `agentty://` 的处理程序。

## Cosmica

[Cosmica](https://www.cosmica.ink/) 是一款笔记应用。其插件随 Agentty 附带，若已安装 Cosmica 则标记为*推荐*。它只从 Cosmica 的设置中读取笔记文件夹和本地端口。

1. 在 Cosmica 卡片上点**插件 → 安装**，然后从标签栏打开它的面板。
2. **笔记 → 提示词** —— 搜索笔记，插入到当前聚焦的终端，或在你选择的位置继续。
3. **从 Cosmica** —— 右键点击笔记 → **在 Agentty 中继续**。笔记会先保存，然后在 Agentty 中打开**发送到…**。
4. **会话 → Cosmica** —— 在聚焦 Claude Code 或 Codex 窗格时点**保存 AI 摘要**，智能体会把目标、所做的事、改动的文件、决策和下一步整理成摘要写入笔记的 `Agentty/`。**保存对话记录**则不询问 AI，直接保存原始对话。

正在忙的智能体不会被打扰，等这一轮结束后再试。Cosmica 运行时，笔记通过其本地 API 保存并立即建立索引；否则会写成文件，等 Cosmica 下次启动时纳入。

## 出问题时

| 现象 | 处理 |
|---|---|
| “找不到 Node.js” | JavaScript 插件需要登录 shell 的 `PATH` 中有 Node.js 18 及以上。WebAssembly 插件什么都不需要装 |
| 市场安装被拒绝 | 模块与列表里的校验和不一致。什么都没有写入，请告知插件作者 |
| 卡片提示需要更新 Agentty | 这个插件面向的插件协议版本是当前版本不认识的，请更新 Agentty |
| 卡片显示插件因错误停止 | 打开卡片上的**日志**；改好代码后点**重启** |
| 复制进来的插件没有出现 | 点**刷新**，并确认文件夹名与 `agentty-plugin.json` 中的 `id` 一致 |
| 链接点了没反应 | 请使用已安装的应用程序，并确认链接指定的插件已安装并启用 |
| 更新后行为异常 | **重启**，或**禁用**并向作者反馈 |

## 文件位置

| 路径 | 用途 |
|---|---|
| `~/.agentty/plugins/<id>/` | 插件本体 |
| `~/.agentty/plugins/state.json` | 启用状态与开发链接指向 |
| `~/.agentty/plugin-data/<id>/` | 插件自己的设置与缓存 |
| `~/.agentty/plugins/.sdk/` | **开发者指南**解压出的 SDK 与文档 |
| `~/.agentty/prompts/` | 以文件形式交给智能体的长提示词 |

卸载会移除插件，但其数据文件夹会保留到你自己删除为止。
