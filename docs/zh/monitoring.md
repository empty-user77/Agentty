**⌥⌘U** 打开监控。这里的一切都在你的机器上计算，不会上传。

## AI 用量

费用、调用次数、缓存命中率和令牌，按模型、项目和工具细分。数字来自智能体 CLI 已经写在磁盘上的会话记录。

统计并不只是把行加起来。Claude Code 每个内容块写一行 JSONL，因此同一次 API 响应会以相同的 message id 出现多次，这些会按该 id 去重。Codex 则是每次响应一条用量记录，以 response id 为键。Agentty 遵循各自的格式，所以一次响应只计一次。

Claude 模型的价格是内置的。其他模型（例如 Codex 使用的那些）可以在 `~/.agentty/pricing.json` 中填入价格，就会一并计算：

```json
{
  "some-model": { "input": 1.25, "output": 10.0, "cacheRead": 0.125 }
}
```

价格单位是每百万令牌的美元。`cacheRead`、`cacheWrite` 和 `cacheWrite1h` 为可选，默认分别是输入价的 10%、125% 和 200%。

> [!NOTE]
> 这些是根据本地文件计算的估算值，仅供你自己参考。真正的数字以提供方的账单为准。

## 进程

此刻在你机器上运行的 AI 进程，以及是什么启动了它们。当你以为已经停下、token 却还在消耗时很有用。

## 代理

一个抓取代理，列出你的标签页在和谁通信：开始抓取、打开标签页、按端点筛选。

- **在抓取开启期间打开的标签页**会经过运行在你自己机器上的代理。
- HTTPS 保持加密。只记录主机、端口、字节数和耗时 —— 不安装证书，不解密任何内容。
- 对明文 HTTP，只记录方法、路径和状态码，绝不记录头部或正文。
- 记录只存在于内存中，数量有上限，不会写入磁盘，Agentty 退出即消失。

停止抓取即停止记录。已经拿到代理的标签页会继续使用它，以免网络中断。

## 工作树管理

按项目列出这台电脑上的所有 git 工作树：分支、最后工作时间（最后一次提交或最新的未提交更改）、未提交的文件、默认分支还没有的提交、拉取请求（打开、已合并或已关闭 —— 通过已登录的 GitHub CLI 读取）以及大小。

在主文件夹下的文件夹、Agentty 的工作树文件夹以及已打开的文件夹中查找。只有项目文件夹本身的项目不会列出。

勾选多个后按 **删除**；**选择可安全删除的** 会选中所有没有未提交更改、提交也已合并的工作树。删除前会先确认：

- **同时删除分支** 只删除不会丢失任何内容的分支：通过 git 自身的检查，或有一个恰好在分支最后一次提交处合并的拉取请求（包括 squash 合并）。其他分支保留。
- 有未提交更改的工作树会被跳过，除非你勾选让它们也删除 —— 那些更改将丢失。
- 项目文件夹本身以及标签页正在使用的工作树无法选择。

## 磁盘管理

磁盘有多满（已用、可清理、可用），以及主文件夹里哪些文件夹占用空间，展开后可看到其中最大的文件夹。

可清理的只有会自动重新生成的内容：

- **项目构建输出** —— 每个项目都有 **删除构建垃圾**（Cargo `target`、`.next`、Gradle `build`、SwiftPM `.build` 等）和 **清除缓存**（`.turbo`、`.parcel-cache`、`node_modules/.cache`、pytest/mypy/Ruff 缓存等）。只有旁边有对应工具的项目文件时才算数，Cargo 的 `target` 还需要 Cargo 写入的标记。
- **缓存** —— 开发工具自己的缓存：npm、Yarn、Bun、pip、uv、Go、Cargo 注册表、Gradle、Homebrew、CocoaPods、JetBrains 以及 Xcode DerivedData。
- **其他** —— 废纸篓和日志文件。

`node_modules` 或 `~/.m2` 等依赖，以及项目运行所需的任何内容，都不会列出。每次删除都会先确认，并在执行前再检查一次，且从不跟随链接。下次构建或安装只是会稍慢一些。
