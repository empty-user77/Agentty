title: 编排
description: 查看智能体把工作分给子智能体、按波次推进的过程，并连接会话以共享上下文。

**⇧⌘F** 打开编排。（在文件编辑器中，⇧⌘F 是搜索项目文件；编排也可以从 **视图** 菜单打开。）它有两个标签页：**工作流** 显示一个会话的工作如何拆分、进展到哪里，**会话连接** 把会话连起来共享上下文。

## 开始编排

写下目标，编排者智能体会完成其余工作：为目标组建智能体团队并展示计划，按波次执行，最后让结果接受审查。

可以从主页的 **编排**、标签页右键菜单的 **新建编排标签页**、新工作区的开始页面，或本页右上角的 **新建编排** 开始。在对话框中：

- **目标** — 团队要完成的事。下方的示例可一键填入：市场调研、通过使用网页应用制作教程、实现功能并审查、修复失败的测试。
- **模型** — 均衡（Sonnet 干活，Opus 审查）、最佳质量（全程 Opus）或经济（Haiku 干活，Sonnet 审查）。计划会为每个智能体写明模型。
- **文件夹** — 团队工作的位置。
- **团队中的 AI** — Claude Code 始终参与，本机安装的其他智能体（Codex、Gemini CLI、Antigravity CLI）可以逐个开关。计划会把每部分工作交给擅长的智能体（精确改代码和审查交给 Codex，超大输入交给 Gemini），并且不会关闭它们的权限检查。

新工作区会放进首次创建的 **编排** 分组，也可以移到任何分组。开始后本页显示它的工作流。计划就绪时会出现提示条：**查看计划** 打开编排者的面板，**要求修改** 发送消息，**开始** 执行计划。需要独立分支的工作交给并行会话（`agentty tasks`）；最后由审查智能体对照目标检查结果，编排者以报告收尾。

## 跟进、继续与停止

编排者面板顶部有一条状态栏，用与本页相同的说法显示：规划中、计划就绪（**开始**）、运行中（工作中的智能体数和完成数）、已完成、已中断、已停止。点 **查看工作流** 回到本页；侧边栏和菜单栏会用编排图标、按状态的颜色标出它的工作区。

编排在重启后依然保留。如果运行中 Agentty 退出（或崩溃），智能体会随之停止：状态栏和本页显示 **已中断**，点 **继续** 会在需要时重新打开会话，保留已完成的工作，只执行剩下的部分。**全部停止**（确认后）会停止编排者当前的工作和所有仍在运行的智能体，之后可以用 **继续** 接着做。**删除** 会把编排从列表中移除（若在运行会先停止），也可以同时关闭它的终端；生成的文件会保留。

相关设置在 **设置 → AI 设置 → 编排**：是否使用、新编排的默认模型、默认使用的其他 AI、展示计划后是否等待 **开始**，以及在新工作区还是新标签页中打开。

## 工作流

左边是线程列表：Agentty 中正在运行的每个智能体会话，带有表示状态颜色的圆点，以及智能体用 `agentty tasks` 启动的并行任务。选中一个即可看到它的工作流：

- 顶部：你最后交给它的任务（`$ …`）和会话名称。
- 编排器一行：主智能体的状态、波次数、已完成的子智能体数、正在使用的模型数。**打开** 跳到它的面板，**消息** 像在面板里输入一样发送一行，**中断** 停止当前回合（等同于在面板中按 Esc）。
- 图：先是编排器，然后是按波次排列的子智能体。一起启动的子智能体为一个波次，正在工作的波次带下划线。每张卡片显示运行中、已完成或等待中以及用时、智能体类型和模型，以及当前步骤或最后一句话。通向运行中波次的线会流动。点击卡片打开该子智能体的记录。
- 底部：子智能体的最新步骤实时滚动。

并行任务以一个波次显示其任务，每个任务带有分支（或文件夹）和面板状态；点击即可跳到该面板。

拖动图中的空白处（或滚动滚轮）可以移动；按住 ⌘ 或 Ctrl 滚动，或用右下角的按钮缩放，**适应窗口** 可显示全部。

## 会话连接

从一个会话拉一条线到另一个，接收方就会得到发送方的上下文 —— 它在做什么、决定了什么、进展到哪里。这在 Claude Code 与 Codex 之间同样有效。

两个 Claude Code 会话之间的连接是直接的，无论是在这里画线，还是用终端的链接按钮选择窗格：两个会话会互相发消息。发起连接的会话会被告知，把属于对方项目的工作交给对方，而不是自己做；对方完成后会汇报结果。刚启动或仍在恢复中的会话会等待几秒；如果两者仍无法互相发消息，就只单向传递对话内容，并提示你。

会话较多时可以移动视图：滚动或拖动空白处即可平移，**⌘** + 滚动以指针为中心缩放。右下角的按钮可以缩小、放大、恢复 100%，以及让所有会话都显示在视图中。

### 连接方式

| 方式 | 行为 |
|---|---|
| 一次 | 在画线的那一刻发送上下文 |
| **实时** | 发送方每产生一轮新对话就转发给接收方 |
| 双向 | 双方互相转发 —— 一条上下文隧道 |

实时连接让第二个智能体保持同步，而你不用复制任何东西。双向连接让两个智能体各做同一问题的一半，同时知道对方刚做了什么。

### 发送的是什么

对话的摘要，写入 `~/.agentty/handoffs/` 并作为文件交给目标智能体。不会逐轮重放提示词与回复。

### 何时用哪种

- **一次** —— 你要为相关工作启动第二个智能体，希望它一开始就了解情况。
- **实时** —— 一个负责实现，另一个负责评审、写文档或盯测试。
- **双向** —— 两个智能体分担一个功能，不能彼此走偏。

关闭连接就停止转发；已经送达的内容会留在接收方的对话里。
