---
title: 编排器
description: 查看智能体把工作分给子智能体、按波次推进的过程，并连接会话以共享上下文。
---

**⇧⌘F** 打开编排器。（在文件编辑器中，⇧⌘F 是搜索项目文件；编排器也可以从 **视图** 菜单打开。）它有两个标签页：**工作流** 显示一个会话的工作如何拆分、进展到哪里，**会话连接** 把会话连起来共享上下文。

## 工作流

左边是线程列表：Agentty 中正在运行的每个智能体会话，带有表示状态颜色的圆点，以及智能体用 `agentty tasks` 启动的并行任务。选中一个即可看到它的工作流：

- 顶部：你最后交给它的任务（`$ …`）和会话名称。
- 编排器一行：主智能体的状态、波次数、已完成的子智能体数、正在使用的模型数。**打开** 跳到它的面板，**消息** 像在面板里输入一样发送一行，**中断** 停止当前回合（等同于在面板中按 Esc）。
- 图：先是编排器，然后是按波次排列的子智能体。一起启动的子智能体为一个波次，正在工作的波次带下划线。每张卡片显示运行中、已完成或等待中以及用时、智能体类型和模型，以及当前步骤或最后一句话。通向运行中波次的线会流动。点击卡片打开该子智能体的记录。
- 底部：子智能体的最新步骤实时滚动。

并行任务以一个波次显示其任务，每个任务带有分支（或文件夹）和面板状态；点击即可跳到该面板。

## 会话连接

从一个会话拉一条线到另一个，接收方就会得到发送方的上下文 —— 它在做什么、决定了什么、进展到哪里。这在 Claude Code 与 Codex 之间同样有效。

两个 Claude Code 会话之间的连接是直接的，无论是在这里画线，还是用终端的链接按钮选择窗格：两个会话会互相发消息。发起连接的会话会被告知，把属于对方项目的工作交给对方，而不是自己做；对方完成后会汇报结果。刚启动或仍在恢复中的会话会等待几秒；如果两者仍无法互相发消息，就只单向传递对话内容，并提示你。

会话较多时可以移动视图：滚动或拖动空白处即可平移，**⌘** + 滚动以指针为中心缩放。右下角的按钮可以缩小、放大、恢复 100%，以及让所有会话都显示在视图中。

### 连接方式

| 方式 | 行为 |
|---|---|
| 一次 | 在画线的那一刻发送上下文 |
| **实时** | 发送方每产生一轮新对话就转发给接收方 |
| 双向 | 双方互相转发 —— 一条上下文隧道 |

实时连接让第二个智能体保持同步，而你不用复制任何东西。双向连接让两个智能体各做同一问题的一半，同时知道对方刚做了什么。

### 发送的是什么

对话的摘要，写入 `~/.agentty/handoffs/` 并作为文件交给目标智能体。不会逐轮重放提示词与回复。

### 何时用哪种

- **一次** —— 你要为相关工作启动第二个智能体，希望它一开始就了解情况。
- **实时** —— 一个负责实现，另一个负责评审、写文档或盯测试。
- **双向** —— 两个智能体分担一个功能，不能彼此走偏。

关闭连接就停止转发；已经送达的内容会留在接收方的对话里。
