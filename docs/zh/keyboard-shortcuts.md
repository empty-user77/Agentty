完整列表也在**设置 → 键盘快捷键**中，按你所在平台的表示法显示。

## Windows 与 Linux

快捷键以 macOS 为准定义再做转换，好让 Ctrl+字母始终交给 shell：

| macOS | Windows / Linux |
|---|---|
| ⌘X | Ctrl+Shift+X |
| ⇧⌘X | Ctrl+Alt+Shift+X |
| ⌥⌘X | Ctrl+Alt+X |
| ⌘1…⌘9 | Alt+1…Alt+9 |
| ⌘= / ⌘- / ⌘0 | Ctrl+= / Ctrl+- / Ctrl+0 |
| ⌘-点击 | Ctrl-点击 |

文本输入框、文件编辑器及其表格视图、聊天中的文字和 diff 使用普通的 Ctrl（Ctrl+C / V / X / A / Z、Ctrl+S、Ctrl+Y、按词移动的 Ctrl+←/→、Ctrl+Home / End）。

### 复制与粘贴

| 位置 | 复制 | 粘贴 |
|---|---|---|
| 终端（macOS） | ⌘C | ⌘V |
| 终端（Windows） | Ctrl+Shift+C，或在选中文字时按 Ctrl+C | Ctrl+Shift+V 或 Ctrl+V |
| 终端（Linux） | Ctrl+Shift+C | Ctrl+Shift+V |
| 文本输入框、文件编辑器、表格 | ⌘C / Ctrl+C | ⌘V / Ctrl+V |
| 聊天中的文字 | ⌘C / Ctrl+C（Ctrl+Shift+C 也可以） | ⌘V / Ctrl+V：进入消息框 |
| diff | ⌘C / Ctrl+C（Ctrl+Shift+C 也可以） | |

- 在 Windows 和 Linux 上，任何地方都可以用 **Ctrl+Insert** 复制、**Shift+Insert** 粘贴。文本输入框也接受终端的 Ctrl+Shift+C / Ctrl+Shift+V。
- **右键点击**终端、文件编辑器中的文字或 diff，会出现复制、粘贴、全选中适用于该处的项。无法选中的文字（错误、日志行、路径、提交信息、查询结果）用右键 → **复制**。
- 在聊天的文字中按 **⌘A / Ctrl+A** 会选中目前已显示的全部文字。在自己读取鼠标的程序（vim、tmux）中，右键和中键交给该程序；按住 **Shift** 点击则使用 Agentty 的菜单和粘贴。
- **Linux**：用指针选中的文字，可在终端、文本输入框和文件编辑器中用鼠标中键粘贴。
- 把复制的文件或图片粘贴到终端会输入其路径，粘贴到聊天的消息框则作为附件。

## 美式以外的键盘布局

快捷键跟随当前的键盘布局，切换布局时一起改变：

- **macOS 快捷键**：在你的布局中只能按 Option 才能打出的键上的快捷键，会移到 macOS 自己的菜单所移到的位置。德语布局中，⌘[ / ⌘] 变为 ⌘Ö / ⌘Ä，⇧⌘[ / ⇧⌘] 变为 ⇧⌘Ö / ⇧⌘Ä。菜单和 **设置 → 键盘快捷键** 显示你的布局对应的键。
- **终端中的 Option**（macOS）：即使开启了 **将 Option 用作 Meta 键**（设置 → 终端），在布局用 Option 打出所需字符的键上，仍会输入该字符：`[ ] { } @ | \ ~` 等代码字符（葡萄牙语 ⌥8 为 `[`，德语 ⌥L 为 `@`），以及该语言的字母（波兰语 Pro ⌥A 为 `ą`，土耳其语 Q ⌥S 为 `ş`）。其余 Option 键仍是 Meta，美式布局中所有 Option 键都是 Meta。
- **Windows 的 AltGr**：在 AltGr 会用该键打出字符的布局中（克罗地亚语 AltGr+B 为 `{`），同一键上的 Ctrl+Alt 快捷键会被去掉，让字符正常输入。

在提问对话框中（新建 worktree 还是用同一个、继续会话等），**↩** 选择蓝色的回答，**Esc** 关闭对话框；红色的回答不会被 ↩ 选中。**Esc** 也会关闭已打开的右键菜单。

## 你自己的命令

命令面板（**⇧⌘P**）也会列出你在项目 `agentty.json` 或 `~/.agentty/commands.json` 中定义的条目。保留词同样有效 —— 在终端里输入 `claude yolo` 会展开为 `claude --dangerously-skip-permissions`。
