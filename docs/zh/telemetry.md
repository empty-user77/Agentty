title: 使用统计
description: Agentty 关于自身究竟发送了什么，以及如何关闭。
---

发布版会向 Google Analytics 发送少量匿名使用事件，以便我们了解大致有多少人在用 Agentty、哪些功能值得继续投入。

其中不包含任何与你的工作有关的内容。路径、文件名、命令、提示词、AI 输出、对话内容、仓库与分支名称、环境变量值和凭据都不会发送 —— 应用在发送前会用允许列表核对每个事件，不在列表上的一律丢弃。

## 事件

| 事件 | 属性 |
|---|---|
| `app_launched` | 启动时打开了多少窗口 |
| `window_opened` | — |
| `pane_opened` | 哪种窗格：`shell`、`claude`、`codex`、`gemini` 等 |
| `agent_turn_finished` | 哪种智能体结束了一轮 |
| `feature_used` | 使用了哪个区域：`agentgit`、`flow`、`usage`、`settings`、`extensions`、`mini`、`browser_api` |

每个事件还带有应用版本、操作系统及其版本、Agentty 显示所用的语言、系统区域设置中的国家/地区，以及保存在 `~/.agentty/install_id` 的随机安装标识符。国家/地区仅从该设置读取 — 不使用 IP 地址，也不使用任何其他位置信息；该设置不会被保存，每次上传时重新读取。该标识符在首次使用时由随机字节生成，不由任何关于你的信息推导而来，删除该文件即可重置。

事件在本地汇总，最多每分钟发送一次。

## 如何关闭

**设置 → 常规 → 同意收集匿名使用统计。** 默认开启；关闭后立即停止收集，并丢弃尚未发送的内容。

设置环境变量 **`DO_NOT_TRACK=1`** 可无视该设置直接关闭。

在官方发布流水线之外制作的构建没有分析凭据，任何情况下都不会发送任何内容。

## 这条通道同样不会带走的东西

你的对话、代码和文件根本不会通过 Agentty 离开你的电脑。这是应用本身的性质，与这项设置无关。你运行的智能体 CLI 直接与各自的提供方通信，受那些提供方的条款约束。
