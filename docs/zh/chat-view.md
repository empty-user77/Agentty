---
title: 聊天视图
description: 在 CLI 继续运行的同时，把智能体窗格显示为桌面应用式的聊天。
---

聊天视图把 Claude Code、Codex、Antigravity 或 Gemini CLI 窗格画成桌面聊天应用的样子。CLI 仍在窗格中运行，因此在聊天和终端之间切换时，会话和其中的内容都保持不变。

## 打开

- 点击窗格标题栏中的气泡，选择**视图 → 聊天视图**，或按 **⇧⌘J**。它们都只切换当前窗格。
- 在**设置 → AI 设置 → 智能体的打开方式**中选择新智能体启动时的模式（终端或聊天）。引导流程中也可以选择。上一个智能体退出后在同一窗格重新启动的智能体，也以此模式打开。

## 对话

- 回复带格式显示，代码块、命令和文件读取使用编辑器的语法颜色。
- 工具步骤折叠成向下展开的卡片，待办列表显示为清单。
- 带编号选项的批准和问题可以直接在聊天中回答。智能体显示自己的菜单或设置界面时，终端会暂时到前面来。
- 可以跨段落和代码选择文本，用 **⌘C** 复制。选区上方的工具条（或右键菜单）可以引用后回复，或就此开始侧边对话。
- 用 **+** 或拖放附加文件，文件显示为缩略图和标签。
- **停止**会中断正在进行的回合。停止后智能体放回输入框的消息会回到编辑框。

## 开始界面

新会话会显示智能体和模型、文件夹（打开文件面板）、分支（打开 Git）、几种只填入编辑框而不发送的开始方式，以及该智能体在此文件夹中的历史会话，点击即可继续。
