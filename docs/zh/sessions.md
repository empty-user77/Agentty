---
title: 会话
description: 浏览、搜索并恢复你电脑上已有的 Claude Code 与 Codex 会话，并在智能体之间迁移对话。
---

智能体 CLI 会把对话写到你的磁盘上。Agentty 读取这些文件，因此你运行过的每一个会话都可浏览 —— 包括在 Agentty 之外开始的那些。

这些文件是 JSONL（每行一个事件），由 Claude Code 和 Codex 在工作时写出。Agentty 解析它们来生成列表、搜索索引和用量数字，从不写入。

## 浏览

**⇧⌘S** 打开会话列表：`~/.claude` 和 `~/.codex` 中的全部内容，按时间倒序，带标题、文件夹和智能体。

- 点击会话打开它，或在新标签页中恢复。
- **⇧⌘O** 按标题、对话内容或路径搜索。
- 加星可把会话固定到顶部。

## 从上次的位置继续

`cd` 进入含有早先会话的文件夹，终端上方会出现一条提示，问你要不要就地继续。不需要的话可在**设置 → 常规**中关闭。

## 在智能体之间迁移对话

对话可以从 Claude Code 交给 Codex，或反过来。Agentty 会把一份上下文文档 —— 这段对话关于什么、做了哪些决定、还剩什么 —— 写入 `~/.agentty/handoffs/`，并用它启动另一个智能体。

这是摘要，而不是逐轮重放：新的智能体在同一个文件夹里带着这份上下文重新开始。

## 文件在哪里

| 路径 | 内容 |
|---|---|
| `~/.claude` | Claude Code 自己的会话 |
| `~/.codex` | Codex 自己的会话 |
| `~/.agentty/handoffs/` | Agentty 生成的上下文文档 |

前两者只读。在那里删除会话，列表中也会消失。
