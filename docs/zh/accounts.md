---
title: 多个账户
description: 登录多个 Claude Code 和 Codex 账户，每个账户在自己的窗口中同时运行。
---

你可以同时登录多个 Claude Code 或 Codex 账户。每个账户在自己的窗口中运行，有各自的会话、用量和套餐限额，多个账户可以同时运行。可以用来区分工作账户和个人账户，或在一个账户用完限额时换另一个账户继续。

## 添加账户

点击设置上方的账户图标打开账户菜单。**添加账户** 用来登录另一个 Claude Code 或 Codex 账户，每个账户的登录各自保留。

原来在 `~/.claude` 和 `~/.codex` 中的登录会作为 **基础账户** 列出，保持不变。

## 每个账户一个窗口

在账户菜单中点击某个账户，会把它的窗口调到前面，没有的话就新开一个。

| 每个账户各自独立 | 所有账户共享 |
|---|---|
| 窗口及其中的工作区 | 设置 |
| 会话记录 | 技能、规则和钩子 |
| 用量和套餐限额 | MCP 服务器 |
| 同步仓库 | |

## 选择用哪个账户启动

启动有多个账户的智能体时，每次都会询问用哪个账户。默认选中当前窗口的账户，每个账户都会显示套餐和用量。

- 在新标签页中打开 Claude Code 或 Codex 时会询问。
- 在终端（包括分屏窗格）中直接输入 `claude` 或 `codex` 也会同样询问，并用所选账户运行。按 **Esc** 关闭则不启动。
- 只有一个账户时不会询问。

## 用其他账户运行的窗格

窗格所用账户与窗口账户不同时，状态栏开头会用蓝色圆圈显示该账户的首字母，状态栏下方有一条蓝线。点击圆圈可以看到该账户的套餐、5 小时和每周限额及重置时间，以及最近 7 天的用量。

关闭状态栏并以 [聊天视图](/docs/chat-view) 显示时，同样的圆圈会出现在输入框下方。

## 套餐和登录状态

套餐以 Pro、Max 或 Ultra 显示在账户菜单、设置、用量页面和菜单栏中。已退出登录或登录将在两天内过期的账户会标出来，旁边有 **重新登录**。当某个登录已退出或将在两天内到期时，设置上方的账户图标会带上警告标记。

## 把工作区移到其他窗口

打开了多个窗口时（包括其他账户的窗口），可以把工作区或整个分组移到另一个窗口：

- 工作区菜单中的 **移到其他窗口**
- 分组菜单中的 **将分组移到窗口**

移动后终端继续运行，智能体仍以启动时的账户留在自己的会话中，因此移到其他账户窗口的窗格会带上上面的蓝色圆圈。

工作区选项、侧边栏宽度和侧面板宽度可以按窗口不同。在主窗口中修改会应用到所有窗口；某个窗口单独修改后，会一直使用自己的值，直到点击 **跟随主窗口**。

## 设置 → 账户

按智能体分组列出所有登录。展开某个登录会显示：

- 它的文件夹（**打开**、**复制**）
- 让智能体使用该文件夹的环境变量
- 登录信息保存的位置
- **重新登录** 和 **删除**

删除账户会退出登录，并删除这台电脑上该账户的会话；有窗格正在用该账户运行时无法删除。基础账户不能删除，可以用 **重新登录** 换成另一个登录。

## 同步

[同步](/docs/settings#同步) 也按账户进行。窗口按其 Claude Code 账户（没有则按 Codex 账户）同步到专用仓库，两个账户不能共用一个仓库。该窗口中其他账户的会话不会同步到这个仓库。

## 在手机上

[远程访问](/docs/remote-access) 页面会显示每个工作区的账户，新建工作区时可以在已打开窗口的账户中选择。
