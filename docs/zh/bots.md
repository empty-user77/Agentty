---
title: 机器人
description: 带有指令和记忆的具名代理。它们可以互相转交工作、按时启动，并接收来自 Telegram、Slack 或 Discord 的消息。
---

机器人是带有名称、用途和记忆的代理。它在你的电脑上以 Claude Code 或 Codex 运行，使用你已有的订阅。你可以在聊天中与它对话，其他机器人可以按名称把工作交给它，它也可以在设定的时间或收到 Telegram、Slack、Discord 消息时自行开始工作。在手机上也能查看机器人的状态、开启或关闭它、交给它工作并接收报告。

机器人只在 Agentty 打开时工作。关闭 Agentty 后不会运行任何任务。最近 24 小时内错过的定时任务会在再次打开时补运行一次。

## 创建机器人

1. 在侧边栏底部的 **机器人**（工作区列表下方）旁点击 **+**。
2. 选择模板，或点击 **从零开始**。模板分为日常类（日常聊天伙伴、我的电脑助手、邮件助手、会议助手、今日计划）、调研与学习类（新闻简报、调研员、写作助手、学习教练、比价助手）和开发类（评审员、Bug 猎手、CI 守望）。模板会填好机器人的提示词、规则和技能，有些还带有让它自行开始的时间或监视项。
3. 选择角色和颜色，确认名称、标识、运行它的代理以及它工作的项目文件夹，然后点击 **创建**。

每个机器人都有一个角色，在侧边栏、对话、房间、动态等所有出现机器人的地方都会显示。角色和颜色之后可以在机器人的设置中更改，也可以在设置和 **新建机器人** 中改用自己的图片（PNG、JPEG、WebP 或 GIF，不超过 5MB）。

如果不想使用机器人，在侧边栏的选项菜单中关闭 **使用机器人功能**：机器人区域会消失，定时任务和频道也会停止。机器人本身会保留。

标识是写在 `@` 后面的名字，只能使用小写字母、数字和连字符，之后不能更改。

侧边栏中机器人的那一行显示它正在做什么，点击即可打开与它的聊天：你写的在右边，机器人说的在左边，中间显示让它自行开始的原因（定时任务、监视、其他机器人）。在底部的输入框中写消息发送。聊天保存在机器人的文件夹中，重启后仍然保留。顶部的齿轮显示机器人何时自行开始、它记住的事以及设置；旁边的按钮打开机器人工作所在的代理会话，这是一个以聊天形式显示的普通会话，可以使用附件、审批和背后的终端。该会话是机器人专属的工作区，不会出现在工作区列表中。

## 机器人页面

点击侧边栏的 **机器人** 栏可折叠该区域。旁边的按钮会打开包含所有机器人、动态、房间和模板的页面。

- **交给工作**：在页面顶部选择机器人，写下要做的事并按 Enter。以 `@标识` 开头的消息会发给那个机器人。
- **每一行**显示机器人正在做什么、在等待什么或它最后的回答，以及下一次自行开始的时间。
- **动态**按从新到旧列出谁把什么交给了谁：你、定时任务、频道、其他机器人。点击一行会打开对应的对话。

机器人聊天和房间里的消息可以像普通聊天一样选择和复制：拖动选中后按 **⌘C**，或用选区上方的栏把它引用到回复中。右键点击可复制整条消息。

## 机器人的构成

打开机器人的聊天并点击顶部的齿轮，会以四张卡片显示机器人的构成：

| 卡片 | 内容 | 文件 |
| --- | --- | --- |
| **提示词** | 机器人负责什么、该怎么回答 | `SOUL.md` |
| **规则** | 无论谁来要求都必须遵守的事：必须做的和不能做的 | `RULES.md` |
| **背景** | 它需要了解的背景：你是谁、在做什么。机器人自己写下的记忆也一并显示 | `CONTEXT.md`、`MEMORY.md` |
| **工具** | 它能做什么（权限）以及工作时用的技能 | `skills/` |

点击卡片上的 **编写** 或 **编辑** 就地修改，然后点击 **保存**。修改从机器人的下一次对话开始生效：代理在对话开始时读取这些内容。

每个机器人是一个文件夹，里面是可以阅读和编辑的文件，位于 Agentty 数据文件夹的 `bots/<句柄>/` 下。除上述文件外，还有 `bot.json`（机器人定义）和 `chat.json`（聊天记录），这两个由 Agentty 写入。

机器人学到值得保留的东西时会写入记忆。传给它的是记忆的前 16 KB；文件超过这个大小时，Agentty 会让机器人整理，并把整理前的文件保留为 `MEMORY.before-tidy.md`。

## 替你使用电脑的机器人

**我的电脑助手** 模板会创建一个替你操作这台电脑的机器人。它打开并使用应用，阅读即时消息（KakaoTalk、信息、Slack、Telegram）并代你发送回复，通过 Mac 的 iPhone 镜像应用操作 iPhone，查找文件并管理提醒。它自带 **操作电脑**、**收发即时消息** 和 **iPhone 镜像** 三个技能，这些技能也可以在技能中心给其他机器人。

- **工作方式**：代理查看屏幕（窗口的文字或屏幕图片），执行一步（点击、输入、快捷键），然后再看一次。代理有电脑操作工具时用它，否则用系统自带的脚本功能。
- **macOS 会询问什么**：第一次时，macOS 会询问是否允许 Agentty 控制电脑。在 系统设置 > 隐私与安全性 > **辅助功能** 中打开 Agentty，并为屏幕图片打开 **屏幕与系统音频录制**。没有这些权限时，机器人会说明缺少什么并停止。
- **没有要求就不会做的事**：发送消息前，它会给你看准确的文字和收件人，并且每次都等你同意。它从不输入密码、锁屏密码或支付信息，而是请你自己完成那一步。
- **iPhone**：需要 macOS 15 或更高版本，并且 iPhone 处于锁定状态且在 Mac 附近。镜像时无法使用相机和麦克风。

机器人操作应用时，键盘和指针由它使用：在它说完成之前不要动。

## 技能中心

技能是把一类工作的做法写下来：如何分拣收件箱、如何带来源地调研、如何评审改动。点击 **工具** 卡片上的 **技能中心**，给机器人添加或移除技能。

- **内置**：Agentty 自带的 19 个技能，涵盖电脑操作、日常、工作、调研、学习和开发。
- **我的技能**：这台电脑上你的代理已有的技能（`~/.claude/skills`、`~/.codex/skills`、`~/.agents/skills`）。添加后会复制到机器人的文件夹，原件保持不变。

可以按名称搜索，或在左侧选择类别。机器人会被告知自己技能的名称，并在做相应工作前先阅读该技能。技能只说明怎么做，不会扩大机器人被允许做的事。

## 权限

| 模式 | 机器人可以做什么 |
| --- | --- |
| **先询问** | 代理自身的审批流程。它提问，你回答。 |
| **只读** | 读取并运行判断工作所需的内容，不修改文件。 |
| **仅文件** | 读写自己文件夹中的文件。不能使用终端、网络或其他工具。 |

无论普通标签页如何设置，机器人都不会以跳过权限确认的方式启动。只有机器人的设置可以更改其权限，任何消息都不能。

## 机器人协作

机器人在自己的终端里把工作交给另一个机器人：

```sh
agentty bot list
agentty bot send reviewer --prompt "Review the parser branch and list what must change."
agentty bot result reviewer
agentty bot status
```

`send` 会立即返回。对方的回答稍后会以 `[Agentty]` 开头的消息出现在发送方的对话中。Agentty 中的任何代理会话都可以使用这个命令，不限于机器人。

### 房间

房间是多个机器人共用的一场对话。选择 **新建房间**，填写名称并选择成员。

- 你写的内容会发给用 `@标识` 指定的机器人；未指定时发给第一个成员。
- 机器人的回答里如果有其他成员的 `@标识`，下一轮就交给那个机器人；没有指定任何人时，轮到你。
- 轮到的机器人会看到自己上一轮之后房间里说过的内容。

### 限制

| 限制 | 数值 |
| --- | --- |
| 你没有发言时机器人之间的连续转交 | 8 次 |
| 单个机器人等待处理的消息 | 32 条 |
| 同时工作的机器人 | 4 个 |

达到转交上限的流程会停止，并显示在 **需要你处理** 中。

## 监视

机器人可以在有事发生时自行开始工作，无需你开口。在机器人设置的 **监视** 中打开要留意的内容：

- 机器人文件夹中仓库的 **新 Issue**、**新的拉取请求** 和 **CI 失败**。需要已安装并登录 GitHub CLI（`gh`）。
- **远程的新提交**：远程默认分支有了新提交。
- **文件夹中的新文件**：机器人文件夹下直接出现了新的文件或文件夹。

Agentty 每五分钟用固定的 `gh` 或 `git` 命令或通过读取文件夹来查看。只有出现新内容时才会启动代理，所以安静的仓库不产生开销。第一次查看只记录已有的内容。如果无法查看（没有 `gh`、未登录、不是仓库），机器人的设置中会说明原因。

Bug 猎手、评审员和 CI 守望模板创建时就已打开监视。

## 定时任务

在机器人的设置中添加时间和要做的事。可以选择 **每小时**、**每天**、**工作日** 或 **每周**，也可以填写 `0 9 * * 1-5` 这样的五段 cron 表达式。两次运行至少间隔 15 分钟。

## Telegram、Slack 和 Discord

由你的电脑主动连接服务并等待消息。不会开放端口，也没有中继服务器。

频道只接收列表中发送者的消息。其他人的消息会被丢弃，并记录在机器人的 `audit.log` 中。发送者列表为空的频道处于关闭状态。

### Telegram

1. 用 [@BotFather](https://t.me/BotFather) 创建机器人并复制令牌。
2. 在机器人设置的 **Telegram** 中粘贴令牌并保存。令牌保存在系统钥匙串中。
3. 在 **允许的发送者** 中填入你的 Telegram 数字 ID 并保存。

如果有多个机器人使用 Telegram，请以 `/标识` 开头来选择机器人。

### Slack

1. 创建一个开启 **Socket Mode** 的 Slack 应用，生成具有 `connections:write` 的应用令牌（`xapp-…`），以及具有 `app_mentions:read`、`chat:write` 和 `im:history` 的机器人令牌（`xoxb-…`）。订阅 `app_mention` 和 `message.im` 事件。
2. 在 **Slack** 中粘贴两个令牌并保存。
3. 在 **允许的发送者** 中填入允许发消息的 Slack 成员 ID（`U…`）。

提及应用并写上机器人的标识（`@应用名 reviewer check the PR`），或直接给应用发消息。回答会发到该消息的串中。

### Discord

1. 在 [Discord 开发者门户](https://discord.com/developers/applications) 创建应用，为它添加机器人并复制机器人令牌。把机器人邀请到你的服务器，或打开与它的私信。
2. 在 **Discord** 下粘贴令牌并保存。
3. 在 **允许的发送者** 中填写你的 Discord 用户 ID（在 Discord 中打开开发者模式，然后在个人资料上选择 **复制用户 ID**）。

直接给机器人发消息，或在服务器中提及它（`@机器人名 reviewer check the PR`）。只会读取私信和提及机器人的消息。

### 在频道中管理机器人

在机器人发送者名单上的人，也可以就这些机器人直接询问 Agentty。只发送下面的词即可，前面加不加 `/` 或 `!` 都可以。

| 消息 | 作用 |
| --- | --- |
| `bots` | 所有机器人的状态 |
| `status <机器人>` | 某个机器人的状态和最后的回答 |
| `on <机器人>` / `off <机器人>` | 开启 / 关闭。关闭的机器人不接收工作，可以在同一对话中重新开启 |
| `stop <机器人>` | 停止当前工作 |
| `/<机器人> <消息>` | 把工作交给该机器人。频道里只有一个机器人时，直接发消息即可 |
| `help` | 这份列表 |

无论消息来自哪里，机器人都以你在 Agentty 中给它的权限在这台电脑上工作。代理停在审批或提问处时，对话中会收到它问的内容和带编号的选项：只发送编号来回答（`1`），有多个机器人时发送 `/<机器人> 1`。消息内容无法扩大机器人的权限。

编号只在收到该提问的对话中有效，并且屏幕上的选项须与收到的一致。“不再询问”这类持续生效的选项不会出现在频道里，需在 Agentty 中选择。Agentty 未运行期间发送的编号和 `on` / `off` / `stop` 之后不会被执行。

### 工作报告

机器人的回答会发回消息所在的对话。它自行完成的工作（定时任务、监视、其他机器人交回的工作），在该频道的 **自行完成的工作也报告到这里** 开启时，会报告到你最后一次与它单聊的对话。不会向群聊报告。把发送者从名单中移除后，报告的去处也会被忘记。

## 需要你处理

机器人页面顶部会列出所有停在审批或提问处的机器人，以及被停止的流程。点击 **回复** 会打开正在提问的会话。

## 在手机上

远程页面的工作区列表下方会列出机器人，每个都有开关，可以直接开启或关闭。点击机器人会打开它的聊天：发给它的消息、它的回答、它自行完成工作的报告，以及下方用来交给它工作的输入框。工作时会显示它在做什么；停在审批或提问处时，点击 **回答** 会进入正在提问的会话。对话位于已排除在远程访问之外的工作区中的机器人不会列出。

创建机器人，以及修改提示词、规则、技能、权限和频道，只能在 Agentty 中进行。
