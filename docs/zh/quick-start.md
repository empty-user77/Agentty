description: 从空窗口到两个智能体并行工作 —— 与 Agentty 相处的最初十分钟。

本页按顺序走一遍第一次使用：打开项目、启动智能体、在旁边再跑一个，并在它们工作时熟悉各处。

快捷键以 macOS 为准。在 Windows 和 Linux 上，⌘ 对应 Ctrl+Shift，⇧⌘ 对应 Ctrl+Alt+Shift，⌥⌘ 对应 Ctrl+Alt，⌘1…9 对应 Alt+1…9。详见[键盘快捷键](/docs/keyboard-shortcuts)。

## 1. 打开项目

按 **⌘N** 新建工作区并选择一个文件夹。该文件夹成为工作区的基准，之后在其中打开的所有标签页都从那里开始。

侧边栏（**⌘B** 切换）列出你的工作区。拖动可重新排序，把一个拖到另一个上可分组，双击名称可重命名。下次启动时一切都会恢复原样。

> [!TIP]
> 如果某个项目你已经在终端里做过，`cd` 进入含有早先 Claude Code 或 Codex 会话的文件夹，会出现就地继续的提示。

## 2. 启动智能体

使用标签栏的 **+** 菜单，或用快捷键。

| 标签页 | 快捷键 |
|---|---|
| 终端 | ⌘T |
| Claude Code | ⌥⌘C |
| Codex | ⌥⌘X |

菜单会列出可启动的模型（Claude Code 为 Opus、Sonnet、Haiku；Codex 为你最近用过的模型），以及在你机器上发现的其他智能体 CLI。

智能体的运行方式与在你自己的终端中完全相同：同样的工具、同样的配置、同样的提供方。输入需求交给它即可。

## 3. 不盯着也能掌握

智能体工作时，你不需要一直把窗口放在前面。

- 侧边栏的工作区行会显示**工作中**、**已完成**或**等待输入**。
- 智能体向你提问时，对应窗格的边框会亮起，直到你点击它。
- 智能体完成或需要回答时会收到通知，点击通知即可打开该窗格。
- **⇧⌘U** 跳转到最新的未读窗格。
- **⌃⌘M** 把窗口折叠成屏幕边缘的小型置顶面板。完成的智能体会以气泡弹出，点击即可恢复完整窗口。

每个智能体窗格上方的状态栏会显示模型、上下文窗口、用量限额、分支和文件夹。

## 4. 安全地加入第二个智能体

在同一项目中用 **+** 菜单再开一个 AI 会话。Agentty 会在从项目默认分支切出的**新分支的独立 git 工作树**中启动它，因此两个智能体不会改到同一批文件。

**文件面板**（**⌥⌘B**）显示项目树、所有工作树、每个工作树里谁在工作以及改了什么。右键点击工作树可在其中打开终端、复制路径，或在分支合并后将其移除。

你也可以让智能体自己拆分工作——“并行做 A、B、C”。它会向 Agentty 提出请求，你确认一次，每个任务就会在各自的分屏窗格和独立工作树中开始。

> [!NOTE]
> 只有当*第二个*会话进入已在进行中的项目时才会涉及工作树 —— Agentty 会询问是新建工作树还是打开现有的。你独自工作时仍停留在打开的文件夹里。

## 5. 整理窗口

| 操作 | 快捷键 |
|---|---|
| 向右 / 向下分屏 | ⌘D / ⇧⌘D |
| 下一个 / 上一个窗格 | ⌘] / ⌘[ |
| 下一个 / 上一个标签页 | ⇧⌘] / ⇧⌘[ |
| 跳到工作区 / 标签页 1–9 | ⌘1…⌘9 / ⌃1…⌃9 |
| 关闭窗格 / 标签页 | ⌘W / ⇧⌘W |

终端旁停靠的面板（文件、浏览器、插件、Docker）都可以拖动边缘调整宽度。

## 6. 检查结果

按 **⇧⌘G** 打开 git 页面：切换仓库与分支，fetch、pull、push，逐个文件查看差异，暂存并提交你选中的内容，浏览历史，合并分支。点击任意窗格标题中的分支名可切换分支、pull、push 或复制名称。

在文件面板中点击文件，会在终端旁的编辑器中打开：语法高亮、撤销与重做、**⌘S** 保存、**⇧⌥F** 用你已安装的格式化工具整理。智能体改动过的文件会自动重新加载。

## 7. 查看花费

按 **⌥⌘U** 打开监控：费用、调用次数、缓存命中率、令牌、模型、项目和工具，全部由磁盘上已有的会话记录计算得出。同一页面还会列出运行中的 AI 进程，以及显示各标签页通信对象的抓取代理。

## 值得早点知道的

- **⇧⌘P** —— 命令面板。包括你在 `agentty.json` 中定义的自定义命令，全都在这里。
- **⇧⌘O** —— 按标题、内容或路径搜索本地会话。
- **⇧⌘B** —— 终端旁的内置浏览器。开发服务器会显示为 `:端口` 标签，一旦响应就在这里打开。
- **⇧⌘X** —— 扩展：技能、子智能体、命令、插件和 MCP 服务器。
- **⌘,** —— 设置：语言（English、한국어、日本語、中文）、主题、字体，以及上述一切的行为。
