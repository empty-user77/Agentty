# UI Gallery

Every element a plugin panel can show, live, with the code that draws it.

- **Layout · Data · Inputs · Feedback** — each element in a card, with what it is for. Turn on
  **Show the code** to see the `ui.*` call under each example: it is the code that drew it.
- **Recipes** — whole screens (list + detail, a settings form, a dashboard, a running job, empty
  and error states) to start a plugin from. Copy one into your `main.mjs` and change the words.

Clicking a button shows which event the plugin received, so you can see what your own handlers
would get.

The full reference is the [plugin UI guide](https://www.agentty.run/docs/plugin-ui-guide).
